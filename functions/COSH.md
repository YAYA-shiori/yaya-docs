# COSH

**Category:** 数学関数

## Signature

```
COSH(rad)
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| rad | ラジアン単位の角度値 |

## Returns

成功時：ハイパボリック・コサイン（双曲線関数）の値を表す実数
失敗時：0.0

ハイパボリック・コサイン（双曲線関数）を返す。引数の単位はラジアン。

## Description

ハイパボリック・コサイン（双曲線関数）を返す。引数の単位はラジアン。

ラジアンは角度の単位のひとつで、180 度が π ラジアン（π は約 3.14159265358）にあたる。度からラジアンにするには `度 * 3.14159265358 / 180` と計算する（90 度なら約 1.5708）。

## Example

```
_rad = 60 * 3.14159265358 / 180  // 60° をラジアンに変換
COSH(_rad)  // 約 1.600287 を返す
```
