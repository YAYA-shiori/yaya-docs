# ARRAYDEDUP

**Category:** 配列操作

## Signature

```
ARRAYDEDUP(_array_)
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| array | 汎用配列 |

## Returns

重複要素を排除した汎用配列を返す。

## Description

同じとみなした要素は最初のものが残る。結果の並びは元の順ではなく、[ハッシュのキー](../grammar/12-hash.md#並び順)と同じ順になる。

Tc600-3以降では、要素の一致と並び順はハッシュのキーと同じ規則になった。

- 整数・実数・正規形の整数を表す文字列は、値が同じなら同じ要素とみなす（`1`、`1.0`、`"1"` は同じ）
- 数値 < 文字列 の順に並ぶ
- 配列やハッシュの要素は内容で比べる。同じ内容のハッシュは1つにまとまり、内容の違うハッシュは残る
- VOID 同士は同じ要素とみなす

型のそろった配列（整数だけ、実数だけ、文字列だけ）の結果は、それ以前と変わらない。

## Example

```
ARRAYDEDUP((3, 1, 2, 1))                    // 1,2,3
ARRAYDEDUP((10, "9", 9, "a", 1.0, 1, "1"))  // 1.000000,9,10,a （Tc600-3以降）
```

## Compatibility

- YAYA: Tc568-1 以降
- Tc600-3: 型の混ざった配列で結果が並び方しだいになっていたのを修正し、ハッシュのキーと同じ規則で比べるようにした
