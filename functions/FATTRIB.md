# FATTRIB

**Category:** ファイル操作

## Signature

```
FATTRIB( path )
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| path | 各種情報を取得したいファイルまたはディレクトリのパス。フルパス指定可能。相対パスの場合は DLL の load で渡された位置が基準 |

## Returns

11要素の汎用配列を返す。失敗した場合は `-1` を返す。

| インデックス | 内容 |
|-------------|------|
| `[0]` | アーカイブ可能（Windows のみ）= 1、その他 = 0 |
| `[1]` | 圧縮（Windows のみ）= 1、その他 = 0 |
| `[2]` | ディレクトリ = 1、その他 = 0 |
| `[3]` | 隠しファイル（Windows のみ）= 1、その他 = 0 |
| `[4]` | ふつうのファイル = 1、その他 = 0 |
| `[5]` | オフラインファイル（Windows のみ）= 1、その他 = 0 |
| `[6]` | 読み取り専用（Windows のみ）= 1、その他 = 0 |
| `[7]` | システムファイル（Windows のみ）= 1、その他 = 0 |
| `[8]` | 一時ファイル（Windows のみ）= 1、その他 = 0 |
| `[9]` | ファイル作成日時。UNIX の場合は inode 更新日時 |
| `[10]` | ファイルの最終更新日時 |

日時の単位は、1970/1/1 0 時を基準とした秒数（epoch）。ふつうの日付情報に直したい場合は、`GETTIME(_attrib[10])` のようにする。

## Description

ファイルやディレクトリの各種情報を取得する。フルパス指定もできる。相対パスの場合は、DLL の load で渡された位置（多くの場合、DLL のある位置）が基準となる。

## Example

```
_attrib = FATTRIB('hoge.txt')
_attrib[10]          // 最終更新日時（エポック秒）
GETTIME(_attrib[10]) // 読みやすい形式に変換
```

## Compatibility

- YAYA: 初版より対応
- AYA: 5.8以降（ただし5.8より前のバージョンでは [9]〜[10] は使用不可）
