# LOGGING
**Category:** デバッグ

## Signature
```
LOGGING(var)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| var | ログに書き込む値。任意の型を指定可能 |

## Returns
VOID（戻り値なし）

## Description
指定した値をログファイルに書き込み、同時にデバッグツール「玉」にも表示します。任意のデータ型を受け付けます。

簡易配列は各値をカンマで結合した形式で出力されます。

## 出力形式

引数が複数あるときや配列を渡したときは、各値をカンマで区切って1行に書き出します。文字列は `"` で囲みます。

```
LOGGING('a', 1, 2.5)   // "a",1,2.500000
```

値が配列やハッシュを含むとき（Tc602-8以降）は、配列を `( )`、ハッシュを `{ }` で囲み、ハッシュの要素は `キー=値` の形で書き出します。入れ子の内側も同じ規則で書き出すので、どこまでが内側なのかがわかります。

```
_h = PARSEJSON('{"l":[1,2],"m":{"x":"a"}}')
LOGGING(_h)                           // {"l"=(1,2),"m"={"x"="a"}}
LOGGING(PARSEJSON('[[1,[2,"s"]],3]'))  // (1,(2,"s")),3
```

いちばん外側の配列は引数として展開されるので、括弧で囲まれません。

## Compatibility
- YAYA: 初期バージョンより使用可能
- AYA: バージョン5.8以降で使用可能
- Tc602-8: 入れ子の配列を `( )`、ハッシュを `{ }` で囲んで出力するようにした（それまでは内側も `,` や `=` でつながれ、ハッシュのキーや値の文字列は `"` で囲まれなかった）
