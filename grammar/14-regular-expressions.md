# 正規表現

`RE_` で始まるシステム関数は、正規表現で文字列を検索・分割・置換する。このページでは、YAYA から正規表現を使うときの基本と、Tc606-6 以降で使えるサブルーチン呼び出しをまとめる。

正規表現エンジンは、Tc606-6 以降は伺か共用の正規表現エンジン [uka_regexp](https://github.com/ukatech/uka_regexp) を使う。構文と意味は PCRE2（Perl 互換）に近い。**構文の細かい部分（先読み・後読み、Unicode プロパティ、再帰、制御動詞など）は [uka_regexp の README](https://github.com/ukatech/uka_regexp/blob/main/README.md) を参照。** このページに書いてある基本的な書き方は、従来どおり使える。

## 関数の使い分け

| 知りたいこと | 関数 |
|---|---|
| 文字列のどこかにマッチする部分があるか | [RE_SEARCH](../functions/RE_SEARCH.md) |
| 文字列全体がマッチするか | [RE_MATCH](../functions/RE_MATCH.md) |
| マッチする部分をすべて探す | [RE_GREP](../functions/RE_GREP.md) |
| マッチした部分で文字列を分割する | [RE_SPLIT](../functions/RE_SPLIT.md) |
| マッチした部分を置換する | [RE_REPLACE](../functions/RE_REPLACE.md)（`$1` などは使えない）、[RE_REPLACEEX](../functions/RE_REPLACEEX.md)（使える） |
| 配列の中からマッチする要素を探す | [RE_ASEARCH](../functions/RE_ASEARCH.md)（最初の 1 つ）、[RE_ASEARCHEX](../functions/RE_ASEARCHEX.md)（すべて） |
| マッチした内容・位置・長さを調べる | [RE_GETSTR](../functions/RE_GETSTR.md)、[RE_GETPOS](../functions/RE_GETPOS.md)、[RE_GETLEN](../functions/RE_GETLEN.md) |
| マッチの条件を変える | [RE_OPTION](../functions/RE_OPTION.md) |

```
if RE_SEARCH(reference[0], 'こんに?ち[はわ]') {
  "こんにちは"
}
```

## パターンの書き方

パターンは文字列で渡す。**シングルクォートで囲むのがおすすめ**。ダブルクォートの文字列では `%(...)` などが埋め込みとして展開されるが、シングルクォートなら展開されない。`\` はどちらでもそのまま正規表現に渡るので、`\d` と書ける。

```
RE_SEARCH("abc123", '\d+')    // 1
```

### 基本の構文

| 書き方 | 意味 |
|---|---|
| `abc`、`あ` | その文字そのもの。特別な意味の記号（`.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `^` `$` `\|` `\`）は、前に `\` を付けると記号そのものになる |
| `.` | 改行以外の任意の 1 文字 |
| `[abc]`、`[a-z]`、`[^abc]` | 文字の集まり、範囲、それ以外 |
| `\d` `\w` `\s` | 数字（`0-9`）、単語の文字（`A-Za-z0-9_`）、空白（スペース・タブ・改行など） |
| `\D` `\W` `\S` | `\d` `\w` `\s` 以外 |
| `^`、`$` | 文字列の先頭、末尾（`m` オプションなら行頭、行末） |
| `\b` | 単語の境界 |
| `*`、`+`、`?` | 0 回以上、1 回以上、0 回か 1 回の繰り返し |
| `{3}`、`{2,4}`、`{2,}` | 3 回、2〜4 回、2 回以上の繰り返し |
| `*?`、`+?`、`??` | できるだけ短くマッチする繰り返し（最短一致） |
| `a\|b` | `a` または `b` |
| `(...)` | グループ。マッチした内容を取り出したり、置換文字列で使ったりできる |
| `(?:...)` | 取り出さないグループ |
| `(?<name>...)` | 名前付きグループ |

!!! note "`\d` `\w` `\s` `\b` は ASCII だけ"
    `\d` は全角の数字に、`\w` は日本語の文字にマッチしない。日本語を判定するときは、Unicode のプロパティを使う。ひらがなは `\p{Hiragana}`、カタカナは `\p{Katakana}`、漢字は `\p{Han}`。

    ```
    RE_SEARCH("あ", '\p{Hiragana}')            // 1
    RE_SEARCH("２０２４", '^\d+$')            // 0（全角の数字）
    RE_REPLACEEX("ひらがなカタカナ", '\p{Katakana}+', '[$0]')   // ひらがな[カタカナ]
    ```

使える構文はこれだけではない。先読み `(?=...)`・後読み `(?<=...)`、所有量指定子、アトミックグループ、`\Q...\E` などの詳細は uka_regexp の README を参照。

### オプション

[RE_OPTION](../functions/RE_OPTION.md) で、以降の正規表現関数に効くオプションを設定する。**既定ではオプションなし。**

| 文字 | 意味 |
|---|---|
| `i` | 大文字と小文字を区別しない |
| `m` | `^` `$` を行頭・行末にマッチさせる（複数行として扱う） |
| `s` | `.` を改行にもマッチさせる |
| `x` | パターン中の空白を無視し、`#` から行末までをコメントにする |

```
RE_OPTION("im")
```

オプションはパターンの中でも指定できる。`(?i)` はそこから先を、`(?i:...)` はかっこの中だけを、大文字小文字を区別しない指定にする。`(?-i)` で解除する。

```
RE_SEARCH("ABC", '(?i)abc')       // 1
RE_SEARCH("ABC", '(?i:a)BC')      // 1
```

改行として扱うのは既定では LF（`\n`）だけ。CR LF も改行として扱いたいときは、パターンの先頭に `(*ANYCRLF)` を書く。

## マッチした内容を調べる

マッチしたら、[RE_GETSTR](../functions/RE_GETSTR.md)・[RE_GETPOS](../functions/RE_GETPOS.md)・[RE_GETLEN](../functions/RE_GETLEN.md) で内容・位置（0 始まり）・長さを配列で取得できる。次に正規表現の関数を呼ぶと上書きされる。

```
_r = RE_SEARCH("abc123def", '(\d+)')
_s = RE_GETSTR()      // ("123", "123")
_p = RE_GETPOS()      // (3, 3)
_l = RE_GETLEN()      // (3, 3)
```

- 配列の 0 番目は、パターン全体にマッチした部分。1 番目以降は、グループ（`(...)`）にマッチした部分。名前付きグループも番号順に並ぶ
- **マッチに参加しなかったグループは配列に入らない**ので、後ろの番号が前に詰まる。`(a)|(b)` を `"a"` に当てると、要素は 1 つだけ増える（全体と `(a)` の 2 つ）
- [RE_GREP](../functions/RE_GREP.md) と [RE_SPLIT](../functions/RE_SPLIT.md) では、マッチした部分ごとに 1 要素ずつ入る。RE_GREP の戻り値はマッチした個数

```
_n = RE_GREP("a1b22c333", '\d+')   // 3
_s = RE_GETSTR()                   // ("1", "22", "333")
```

!!! warning "戻り値を捨てると出力候補になる"
    `RE_SEARCH(...)` のように戻り値を使わずに書くと、その値が関数の出力候補に混ざる。結果を調べるだけのときは `_r = RE_SEARCH(...)` のように変数に代入する。

## 置換

[RE_REPLACE](../functions/RE_REPLACE.md) は、置換文字列をそのまま使う。[RE_REPLACEEX](../functions/RE_REPLACEEX.md) の置換文字列では、次の書き方が使える。

| 書き方 | 意味 |
|---|---|
| `$0`、`$&` | マッチした部分全体 |
| `$1`、`$2`、… | 1 番目、2 番目、…のグループ。`$10` 以上は、その数のグループがあるときだけ 2 桁として読む |
| `${1}`、`${name}` | 番号・名前で指定する（後ろに数字が続くときに便利） |
| `` $` ``、`$'` | マッチした部分より前、後ろの文字列 |
| `$+` | マッチしたグループのうち、番号が最も大きいもの |
| `$_` | 元の文字列全体 |
| `$$` | `$` という文字 |
| `\1`〜`\9` | `$1`〜`$9` と同じ |
| `\\` `\n` `\r` `\t` `\a` `\e` `\f` `\v` | バックスラッシュ、改行、復帰、タブなどの制御文字 |

マッチに参加しなかったグループは、空文字列になる。

```
RE_REPLACEEX("2024-05-17", '(\d+)-(\d+)-(\d+)', '$3/$2/$1')    // 17/05/2024
RE_REPLACEEX("abc", '(?<first>a)', '${first}-')               // a-bc
RE_REPLACEEX("aaaa", 'a', 'b', 2)                             // bbaa（2 回まで置換）
```

## サブルーチン呼び出し（Tc606-6以降）

正規表現の中の部品を名前で呼び出せる。パターンの中に `(?<date>...)` のような定義がなくても、その名前を **YAYA の変数や関数から探して、パターンとして取り込む**。

呼び出しの書き方は、次のどれでもよい（意味は同じ）。

- `(?&name)`
- `(?P>name)`
- `\g<name>`、`\g'name'`
- `(?R<name>)`、`(?R'name')`

`'` を含む書き方は、シングルクォートの文字列の中では `''` と 2 回続けて書く（`'^\g''name''$'`）か、ダブルクォートの文字列に書く。

```
_date = '\d{4}-\d{2}-\d{2}'
_r = RE_SEARCH("今日は2024-05-17です", '(?&date)')     // 1
```

### 名前の探し方

パターンの中に定義のない名前 `name` は、次の順で探す。最初に見つかった、使える値が部品になる。

1. ローカル変数 `_name`（名前が `_` で始まるときは、その名前のローカル変数）
2. グローバル変数 `name`
3. 関数 `name`（引数なしで実行した戻り値）

- 使える値は**文字列と数値**。VOID・配列・ハッシュは使えないので、次の候補を探す
- どれも見つからないとき、取り込んだ値がパターンとして不正なときは、正規表現の誤り（W0016）になる
- 変数が見つからなければ、同名の関数が実行される。意図せず関数が実行されないよう、**部品用の名前は、他の関数や変数と重ならないものにする**
- 部品の中から、さらに別の部品を呼び出してよい。自分自身を呼び出す再帰もできる
- 変数や関数の値は、正規表現関数を呼ぶたびに読み直す。関数は毎回実行されるので、乱数で内容が変わる関数を使えば、毎回違うパターンにもできる
- パターンの中で定義した名前付きグループ（`(?<name>...)`）と同じ名前は、定義のほうが使われ、変数や関数は探さない

```
// 部品を関数で用意する
Digits4 { '\d{4}' }
Digits2 { '\d{2}' }

IsDate
{
  RE_MATCH(reference[0], '(?&Digits4)-(?&Digits2)-(?&Digits2)')
}
```

部品を組み立てて、長いパターンを読みやすくできる。

```
_y = '\d{4}'
_m = '\d{2}'
_date = '(?&y)-(?&m)-(?&m)'
_r = RE_MATCH("2024-05-17", '(?&date)')     // 1
```

再帰を使えば、入れ子の構造にもマッチする。次は、かっこの対応が取れている文字列にマッチする例。

```
_paren = '\((?:[^()]++|(?&paren))*\)'
_r = RE_MATCH("(a(b)c)", '(?&paren)')     // 1
```

!!! note "部品の中のグループ"
    部品の中に書いた `(...)` は、呼び出しから戻ると結果から消える。[RE_GETSTR](../functions/RE_GETSTR.md) などで取り出せるのは、呼び出し元のパターンのグループだけ。また、部品の中では、呼び出し元のパターンの `(?i)` などのオプションは引き継がれない。[RE_OPTION](../functions/RE_OPTION.md) で設定したオプションから始まる。

## エラー

| 状況 | 結果 |
|---|---|
| パターンの構文が不正、サブルーチンの名前を解決できない | 警告 W0016。マッチしなかったものとして扱う（`GETLASTERROR` は 16） |
| 繰り返しが入れ子になっているなどでバックトラックの回数が上限を超えた、メモリが足りない | 警告 W0017。マッチしなかったものとして扱う（`GETLASTERROR` は 17） |

`(a+)+$` のようにバックトラックが指数的に増えるパターンは、長い文字列に当てると上限に達する。上限に達したときは、W0017 でマッチしなかったことになる。
