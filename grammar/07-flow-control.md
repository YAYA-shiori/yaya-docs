# フロー制御

## 条件分岐

### if / elseif / else 構文

式の結果が真であれば `{ }` ブロックが実行される。複数の `elseif` を連結でき、末尾に `else` を付けられる。ネストした if 文以外では、ブロックが1文の場合は波括弧を省略できる：

```
if 条件式
{
  // 真の場合
}
elseif 別の条件式
{
  // 別の条件が真の場合
}
else
{
  // すべて偽の場合
}
```

### case / when 構文

ラベルベースの分岐。`case` 文が式を評価し `when` ラベルにマッチする。1つの `when` にコンマ区切りで複数の値を指定できる。範囲指定はマイナス記法（例：`"value1"-"value5"`）。`others` 節でマッチしなかったケースを処理する。ラベル値はリテラルのみで、変数や式は使えない：

```
case 式
{
  when 値1
  {
    // 値1の場合
  }
  when 値2, 値3
  {
    // 値2または値3の場合
  }
  others
  {
    // どれにもマッチしない場合
  }
}
```

`when` と `others` は、`case 式` に続く `{ }` の中に書く。`case 式` の直後に `{` がなく `when` が続く書き方は、読み込み時にエラー（E0051 `case`に続く`{`がありません）になる。`case 式 {` のように `{` を同じ行に書いてもよい。

### switch 構文

位置（0始まり）で出力候補を選択する。`{ }` の中の候補は1行に1つ書く。`switch 1 { "a" "b" "c" }`（各候補を行に分けて書く）は `"b"` になる。

`{ }` を候補の数だけ並べて、ブロックごとに位置を対応させる書き方もできる。この場合、位置に対応するブロックの中の候補からランダムに選ばれる：

```
switch _n
{
  "ゼロ番目"
}
{
  "一番目"
}
```

出力確認マーカー（`--`）で候補のグループを指定し位置を正確に制御できる（[関数](02-functions.md)）。

## ループ構造

### while ループ

式が真である間 `{ }` ブロックを繰り返す。条件式はカッコで囲んでも囲まなくてもよい（`while (_i < 3)` と `while _i < 3` は同じ動作になる）：

```
while 条件式
{
  // 処理
}
```

### for ループ

初期化・条件・インクリメントの3つのパートを持つ。C言語と異なり、すべてのパートが必須。`for ( ; ; )` のような無限ループは使えない：

```
for 初期化 ; 条件 ; インクリメント
{
  // 処理
}
```

Tc603-6以降では、ヘッダ全体を括弧で囲んでもよい。`foreach` も同じ。

```
for (_i = 0; _i < 3; _i++) { ... }
foreach (_a; _k, _v) { ... }
```

- ヘッダを複数行に分けてもよい。`for (` のように `(` だけで終わる行や、`) {` のように `)` から始まる行も書ける
- 文ごとに括弧を閉じる書き方（`for (_i = 0); (_i < 3); (_i++)`）や、括弧なしの書き方は、これまでどおり使える
- `for (_i = 0; _i < 3); _i++` のように、最後の文より手前で括弧を閉じる書き方は、これまでどおりエラーになる
- `for (; _i < 3; _i++)` や `foreach (_a; )` のように、括弧を外すと空になる部分があるときは、E0027 だけが出る（後続の連鎖エラーは出ない）

Tc603-5 までは、ヘッダ全体を囲む括弧が別々の文に分かれて、E0019 などのエラーになっていた。

### foreach ループ

配列要素（簡易配列・汎用配列いずれも）を順番にイテレートする。`SETDELIM` で設定したカスタムデリミタを認識する：

```
foreach 配列 ; 変数
{
  // 変数に要素が格納されて実行
}
```

Tc600-3以降では、ハッシュも foreach で回せる。変数には値がキーの順に入る。値が配列やハッシュなら、変数も配列やハッシュになる。

#### 2変数の foreach（Tc600-3以降）

変数をコンマで区切って2つ書くと、1つ目にキー、2つ目に値が入る。配列と簡易配列でも使え、その場合の1つ目には 0 から始まるインデックス（整数）が入る：

```
foreach 配列またはハッシュ ; キー変数, 値変数
{
  // 処理
}
```

```
_h = IHASH("a", 1, "b", 2)
foreach _h ; _k, _v { _s += _k + '=' + _v + ' ' }   // "a=1 b=2 "
foreach ("p", "q") ; _i, _v { ... }                  // _i = 0, 1
foreach "x,y" ; _i, _v { ... }                       // 簡易配列も同じ
```

変数にはローカル変数とグローバル変数のどちらも書ける。変数が3つ以上のとき（`_a, _b, _c`）や、変数でないものを書いたとき（`_k, 1`、`_a + _b`）はエラー E0043 になる。

### break / continue

- `break`: 現在のループを即座に抜ける
- `continue`: 次のループ反復にジャンプする
- ループ上限は設定可能。超過すると `shiori.OnLoopLimit()` が呼ばれる

## 関数の戻り値

`return` で関数実行を即座に終了する。出力はそれまでに蓄積された候補から抽出される。

### 引数つき return（Tc573-1以降）

`return 式` の形で戻り値を明示できる。引数には定数だけでなく数式も書ける：

```
to_rad
{
    if GETTYPE(_argv[0]) == 3 {
        return -1
    }
    return _argv[0]*2.0*3.14/360.0
}
```

引数つきの `return` は、それまでに蓄積した候補を**すべて破棄**して指定した値に置き換える。以下の例では返り値は必ず `"D"` になり、`"A"` `"B"` `"C"` は破棄される：

```
test_func
{
    "A"
    "B"
    "C"
    return "D"
}
```
