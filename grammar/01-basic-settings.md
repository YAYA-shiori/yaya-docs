# 基礎設定

## 概要

YAYAはDLL名に `.txt` を付加した設定ファイル（デフォルト: `yaya.txt`）を読み込む。このファイルはASCIIエンコーディングを使用し、コンマ区切りのコマンドとパラメータで構成される。

設定ファイルが無い場合や、読み込む辞書がひとつも無い場合は、[シェルモード](#シェルモード)で動作する（Tc574-7 / Tc602-12以降。それまでは設定ファイルが無いとエラー E0005 で動作を止めていた）。

**コメント:** `//` 以降の行および `/*` ～ `*/` 間の内容は無視される。

## 設定例

```
dic, basis.dic
charset, UTF-8
charset.dic, Shift_JIS
log, executelog.txt
```

## 文字コード設定

`charset` でデフォルトエンコーディングを指定する（Shift_JIS / UTF-8 / OSデフォルト）。

| 設定キー | 説明 |
|---------|------|
| `charset` | デフォルト文字コード |
| `charset.dic` | 辞書ファイルの文字コード |
| `charset.setting` | 設定ファイルの文字コード |
| `charset.output` | request関数のI/O文字コード |
| `charset.log` | ログファイルの文字コード |
| `charset.file` | ファイルI/Oの文字コード |
| `charset.save` | グローバル変数保存ファイルの文字コード |
| `charset.extension` | 外部DLL通信の文字コード |

## 辞書ファイルの読み込み

辞書ファイルはプログラム動作を定義するスクリプトソースファイル。

| コマンド | 説明 |
|---------|------|
| `dic, ファイル名` | 辞書を読み込む |
| `dicif, ファイル名` | ファイルが存在する場合のみ読み込む |
| `dicdir, ディレクトリ名` | 指定ディレクトリ内のすべてのファイルを読み込む |

これらの指定が無い場合や、`dicif` の対象がすべて存在しない、`dicdir` のディレクトリが空、などで読み込む辞書がひとつも無い場合は、[シェルモード](#シェルモード)で動作する（Tc574-7 / Tc602-12以降）。

## ログ・デバッグ設定

| 設定キー | 説明 |
|---------|------|
| `log, ファイル名` | 実行ログを有効化 |
| `iolog, [on\|off]` | I/Oログの制御（デフォルト: on） |
| `iolog.filter.keyword` | 指定キーワードに一致するリクエストをログから除外 |
| `fncdepth, [深さ]` | 関数呼び出し深さの上限（デフォルト: 32） |
| `looplimit, [回数]` | ループ繰り返し回数の上限（デフォルト: 10000） |

## その他の設定

| 設定キー | 説明 |
|---------|------|
| `basepath, ディレクトリ` | ファイル操作のベースディレクトリ |
| `include, ファイル名` | 外部設定ファイルのインクルード |
| `save.encode, [on\|off]` | セーブファイルの暗号化 |
| `save.auto, [on\|off]` | 変数の自動保存を有効化 |
| `embed.lazy, [on\|off]` | 文字列のカッコなし `%` 埋め込みの名前を実行時に探す（デフォルト: on）。off で辞書の読み込み時に確定する（Tc604-1以降。[詳細](06-string-embedding.md#名前を読み込み時に確定する)） |
| `maxlognum, [数]` | エラーログの最大エントリ数（デフォルト: 256） |

## 緊急設定

バージョン Tc555-1+ では、辞書読み込み失敗時のフォールバック設定をサポート。辞書読み込みが失敗すると、nullを返す前に `yaya_emerg.txt` の読み込みを試みる。

`yaya_emerg.txt` による緊急モードは[シェルモード](#シェルモード)にはならない。`yaya_emerg.txt` が無ければ、これまでどおり動作を止める。

## シェルモード

Tc574-7 / Tc602-12以降。設定ファイルが無いか、読み込む辞書がひとつも無い場合、YAYAは次の辞書だけを読み込んだものとして動作する。

```c
load { }
unload { }
request { EVAL(_argv[0]) }
```

requestに渡された文字列をそのまま [EVAL](../functions/EVAL.md) し、その結果を返す。式ひとつのほか、`;` や改行で区切った文の並びや制御文も書ける。ゴースト一式や辞書を用意しなくても、YAYAの式や関数の動作を手早く確かめられる。

| request の入力 | 返値 |
|---------------|------|
| `1+2` | `3` |
| `_a = 3; _a * 5` | `15` |
| `'hello' + ' world'` | `hello world` |
| `X = 10` | 空文字列（グローバル変数 `X` に 10 が入る） |
| `X` | `10` |

- グローバル変数は同じセッションの間は保持される
- 設定ファイルが無い場合は、変数の自動保存・復元（`yaya_variable.cfg`）を行わない。設定ファイルはあって辞書の指定だけが無い場合は、`save.auto` などの設定に従う
- シェルモードに入ると、ログに注記 N0002 が出る
- `dic` で指定した辞書ファイルが存在しない、辞書に文法エラーがある、`include` の対象が無い、といったエラーの場合はシェルモードにはならない
- SHIORIのリクエストもそのまま EVAL されるため、ゴーストとして使うためのものではない。YAYA の実行ファイル版（`yaya.exe`）で、空のディレクトリを `load` してから式を `request` で送る、といった使い方を想定している
