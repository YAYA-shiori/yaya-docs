# 分岐処理

## 概要

式が正しいか正しくないかで、処理を分けることができる。ほぼ必ず[論理演算子](operators.md#論理演算子)と一緒に使われる。

## if〜else〜 文

```
if (式)
{
  "正しい"
}
else
{
  "正しくない"
}
```

「式」が正しいと手前の `{}` の処理が、正しくないと `else` のあとの `{}` が実行される。式の中には `_name == "さくら"` のような比較を書く。

```
_name = "さくら"
if (_name == "さくら")
{
  "さくらです"
}
else
{
  "さくらじゃない！"
}
```

## case〜when 文

ラベルベースの分岐。`case` の式の値が `when` の値と一致したブロックが実行される。

```
case _value
{
  when 1
  {
    // _value が 1 の場合
  }
  when 2, 3
  {
    // _value が 2 または 3 の場合
  }
  others
  {
    // どれにもマッチしない場合
  }
}
```

## switch 文

位置（0始まり）で出力候補を選択する。

```
switch _n
{
  "ゼロ番目"
}
{
  "一番目"
}
{
  "二番目"
}
```
