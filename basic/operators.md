# 演算子

計算をするためのもの。

## 算術演算子

いわゆる、足す、引く、かける、割る。

| 演算子 | 説明 | 例 |
|--------|------|-----|
| `x + y` | x と y を足す | `1+1` → `2` |
| `x - y` | x から y を引く | `2-1` → `1` |
| `x * y` | x と y を掛ける | `6*2` → `12` |
| `x / y` | x を y で割る。余りは切り捨て | `4/3` → `1` |
| `x % y` | x を y で割った余りを得る | `4%3` → `1` |

`x % 2` を計算して 0 なら偶数、1 なら奇数、という使い方ができる。

## 論理演算子

等しい、等しくない、○○より大きい、○○より小さいなど。「真」か「偽」か（正しいか正しくないか）を判定する。ほとんどは `if` 文や `for` 文などの後に使って、分岐や繰り返しの条件にする。分岐処理によって、切り替え元のゴースト名や起動累計時間などでトークを変えられる。

| 演算子 | 説明 |
|--------|------|
| `x == y` | x と y が同じなら真 |
| `x != y` | x と y が同じでないなら真 |
| `x && y` | x かつ y なら真。`&&` の前後の両方が真なら真（AND） |
| `x \|\| y` | x または y なら真。`\|\|` の前後のどちらか一方が真なら真（OR） |
| `x > y` | x が y より大きいなら真。同じ値は含まない。`10 > 1` は真、`10 > 100` と `10 > 10` は偽 |
| `x >= y` | x が y 以上なら真。同じ値も含む。`10 >= 1` と `10 >= 10` は真、`10 >= 100` は偽 |
| `x < y` | `>` の逆。x が y より小さいなら真 |
| `x <= y` | `>=` の逆。x が y 以下なら真 |
| `!x` | x でない（否定）。`!(1==1)` は偽。この例なら `1!=1` と書くほうが普通 |
| `y _in_ x` | 文字列 x の中に y があれば真。`"さくら" _in_ "あさくら"` は真。順序に注意 |
| `y !_in_ x` | 文字列 x の中に y がなければ真。`"さくら" !_in_ "あさくら"` は偽。順序に注意 |

## 文字列演算

`+` で文字をつなげる。

```
_c = "さくら" + "と" + "うにゅう"
// 結果: "さくらとうにゅう"
```

## 配列操作

`,` で x と y の配列になる。

```
_array = (_hoge, _fuga, _gonyo)
```

`_array` の中に三つの値が入る。
