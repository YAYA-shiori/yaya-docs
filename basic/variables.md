# 変数

## 概要

変数は、数値や文字（文字列）を保存しておける箱のようなもの。箱なので中身を入れないといけないが、入れると元の中身は消える。

**注意:** 変数宣言は関数の中でのみ行える。

## 基本的な使い方

```
_a = 1
_b = 2
```

`_a` に 1 を、`_b` に 2 を入れる。中身を入れた後であれば、使うことができる。

```
_c = _a + _b
```

こうすると、1 + 2 の結果である 3 が `_c` の中に入る。

## 文字列変数

変数には文字も入る。

```
_a = "紅茶"
_b = "ケーキ"
```

文字も `+` で足せる。なので、

```
_c = _a + "と" + _b
```

とすると、`_c` の中は `"紅茶とケーキ"` になる。

## さくらスクリプトの扱い

さくらスクリプトは文字列として記述されないと実行されない。たとえば

```
\![open,inputbox,OnTest,60000]
```

のように書いても正常に動作しない。これは

```
"\![open,inputbox,OnTest,60000]"
```

とする必要がある。

## 変数の展開

トーク中に変数の中身を表示するには `%(変数名)` と記述する。

```
_hoge = "紅茶"
"\0\s[0]飲み物なら%(_hoge)をどうぞ\e"
```

とすると、「飲み物なら紅茶をどうぞ」と表示される。
