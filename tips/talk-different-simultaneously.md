# 同時に違うことを喋る

> [AYAYA Wiki](https://emily.shillest.net/ayayaold/) より転載

同時に同じことをしゃべるのは`\_s`でできますが、違うことを同時はどうするか？

### SAORIを使う方法

[parallel](http://www.geocities.jp/poskoma/)というSAORIがあります。

### 文のみ

文のスクリプトのみで実現したサンプルです。&new{2005-4-22};

[すぐに使える辞書ファイル](../attachment/aya_parallel.txt)

### 喋る文章があらかじめ決まっている場合

SAORIも関数もわからん、できるだけ簡単にやりたい、という方向け。

<http://63factory.jp/~klat/bottle/soft.html>

のBottle Toolの「ぱたぱたさん」が利用できます。<br>
名前が示す通り、SSTP Bottle用特殊スクリプト編集ツールですが、ふつうのゴーストに利用しても全く問題ありません。

### 上記は、以下の質問文に答えたものです。

```
Tipsとは違いますが。

他の栞の場合、\0と\1で違うことを同時に喋らせることができますが
文ではできないのでしょうか?

現状では、\_qと\_w[20]前後を用いて擬似的に処理していますが、かなり面倒なので。


どなたかご存じでしたら、このページの編集をお願いいたします。
```
