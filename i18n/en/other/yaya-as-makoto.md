# YAYA as MAKOTO

> Reposted from [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

### Overview

A module created by Setsuri that calls YAYA as MAKOTO.

You can create a “MAKOTO” translator that converts talk and Sakura Script using YAYA syntax.
You can also use YAYA system functions and SAORI.<br>
It can be used from both the ghost and shell sides, but there is currently little reason to use it from the ghost side.
It is mainly intended for additional shells that perform special behaviors.

#### What kinds of shells can you make?

- A shell whose speech style changes randomly
- A shell whose speech style or surface changes depending on the time of day or number of times it has been launched
- A shell that can sit on a window
- And various others

If you only need to convert speech style or Sakura Script, other MAKOTO implementations are sufficient and run more lightly.
