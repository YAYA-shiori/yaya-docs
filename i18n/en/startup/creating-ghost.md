# Creating a Ghost with YAYA

## 1. Choose a template ghost

First, choose a template you like and try modifying it.

| Template | Description |
|-----------|------|
| [Hello YAYA World (Konnoyayame)](http://ms.shillest.net/yayame.xhtml) | A template ghost that can also be enjoyed as a ghost on its own |
| [SimpleYAYA Template](../other/simple-yaya-template.md) | For those who want a simpler template |
| [Konno Lilith](http://ms.shillest.net/yayalilith.xhtml) | Its defining feature is a complete set of powerful development support functions that are unlike YAYA. The ultimate goal is the strongest development environment, with the baseware author's full cooperation, combining ease of use on a par with Satori and powerful extensibility |

### Debugger

Although it is not a template, we recommend installing “tama (debugger for aya)” from the [Tama distribution site](http://umeici.onjn.jp/) as a debugger. For instructions on how to use it, see [Checking dictionary errors with Tama](../tips/tama-error-check.md) and other resources.

### Note

Before editing in earnest, files may be changed by a network update. If you use Konnoyayame or Konno Lilith, disable `homeurl` in `yaya_string.txt`.

## 2. Read the manual

If you want to try something that is not in the template, or you are unsure how to modify the template, read the manual.

- This [manual](../INDEX.md)

Information such as Sakura Script and SHIORI Events, which you need when writing dictionaries, is not included in this manual. Refer to these as well (all are external sites).

- [CROW/SSP Reference](http://crow.aqrs.jp/reference/all/)
- [UKADOC Project TOP](https://ssp.shillest.net/ukadoc/manual/index.html)
- [Disc-2 Ghost Creation](http://disc2.s56.xrea.com/manual/)

If you have used another SHIORI before, reading these pages will make migration easier.

- [Migrating from AYA](migration-from-aya.md)
- [Migrating from Satori](migration-from-satolili.md)
