# ISREALSTR
**Category:** 文字列操作

## Signature
```
ISREALSTR(string)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| string | String to check |

## Returns
- 1: Can be interpreted as a real number
- 0: Cannot be interpreted as a real number

## Description
Checks whether the given string can be interpreted as a real number.

## Compatibility
- YAYA: Available from the initial version
- AYA: Available from version 5.8 onward
