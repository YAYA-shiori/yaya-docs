# LOG
**Category:** 数学関数

## Signature
```
LOG(val)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| val | Real number whose natural logarithm is to be calculated |

## Returns
- Success: The natural logarithm of val (real number)
- Failure: 0.0

## Description
Returns the natural logarithm (base e).

## Compatibility
- YAYA: Available since the initial version
- AYA: Available from version 5.8 onward
