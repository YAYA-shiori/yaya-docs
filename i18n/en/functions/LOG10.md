# LOG10
**Category:** 数学関数

## Signature
```
LOG10(val)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| val | Real number whose common logarithm is to be calculated |

## Returns
- Success: The common logarithm of val (base 10, real number)
- Failure: 0.0

## Description
Returns the common logarithm (base 10).

## Compatibility
- YAYA: Available since the initial version
- AYA: Available from version 5.8 onward
