# GETDELIM
**Category:** 配列操作

## Signature
```
GETDELIM( var )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| var | The simple array variable whose delimiter to check |

## Returns
The delimiter string set for the specified variable.

## Description
Gets the delimiter set for a variable (the separator used in a simple array). The default delimiter is a comma (`,`).

Use this function to check a delimiter changed by SETDELIM.

## Compatibility
- YAYA: Available since the initial version
- AYA: Version 5.8 and later
