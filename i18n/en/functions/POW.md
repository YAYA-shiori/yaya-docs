# POW
**Category:** 数学関数

## Signature
```
POW(x, y)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| x | Base (real number) |
| y | Exponent (real number) |

## Returns
- Success: x to the power of y (real number)
- Failure: 0.0

## Description
Returns x to the power of y.

## Compatibility
- YAYA: Available since the initial release
- AYA: Available since version 5.8
