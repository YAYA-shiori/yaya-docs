# GETCALLSTACK
**Category:** デバッグ

## Signature
```
GETCALLSTACK
GETCALLSTACK()
```

## Parameters
None

## Returns
A generic array representing the call stack. Each element is the name of a user-defined function (a string).

## Description
Returns the call history (call stack) of user-defined functions as a generic array, with each element representing a function name.

## Compatibility
- YAYA: Available since the initial release
