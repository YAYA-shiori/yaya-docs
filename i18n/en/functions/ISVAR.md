# ISVAR
**Category:** 型取得/変換

## Signature
```
ISVAR(string)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| string | String containing the variable name to check for existence |

## Returns
- 0: Variable does not exist
- 1: Global variable exists
- 2: Local variable exists

## Description
Checks whether a variable with the specified name exists.

## Compatibility
- YAYA: Available from the initial version
- AYA: Available from version 5.8 onward
