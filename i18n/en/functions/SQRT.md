# SQRT
**Category:** 数学関数

## Signature
```
SQRT(val)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| val | Real value whose square root is to be calculated |

## Returns
- On success: The square root of val (real number)
- On failure: 0.0

## Description
Returns the square root of the specified value.

## Compatibility
- YAYA: Available since the initial version
- AYA: 5.8 or later
