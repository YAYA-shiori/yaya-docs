# SETTAMAHWND
**Category:** デバッグ

## Signature
```
SETTAMAHWND( hwnd )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| hwnd | Window handle of the debugging tool "Tama" (numeric value) |

## Returns
None (VOID)

## Description
Sets the window handle of the debugging tool "Tama". After it is set, debug messages are output to that window.

## Compatibility
- YAYA: Tc562-1 and later
