# ISGLOBALDEFINE
**Category:** メタ操作・特殊関数

## Signature
```
ISGLOBALDEFINE( define )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| define | Name to check for a definition made with `#globaldefine` |

## Returns
- 1: Definition exists
- 0: Definition does not exist

## Description
Checks whether a name defined with the `#globaldefine` directive exists.

## Compatibility
- YAYA: Tc562-1 and later
