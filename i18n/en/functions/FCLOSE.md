# FCLOSE

**Category:** ファイル操作

## Signature

```
FCLOSE( path )
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| path | Relative file path from yaya.dll, as specified in FOPEN |

## Returns

No return value (VOID).

## Description

Closes a file opened with FOPEN.

## Compatibility

- YAYA: Supported since the initial release
- AYA: 5.8 and later
