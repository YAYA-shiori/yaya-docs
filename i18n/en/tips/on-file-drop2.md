# How to Use OnFileDrop2

> Reposted from [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

When you drag and drop a file onto a ghost, the OnFileDrop2 event occurs.<br>

You can use this to change the wallpaper or play music files.

[A ready-to-use sample is available here.](../attachment/OnFileDrop2.txt)

<span style="color:Red">※This example writes the OnChoiceSelect choices directly as independent functions. See [Writing choices directly as independent functions](independent-choice-function.md).</span>

This uses the functions described in [Playing sounds](play-sound.md), so refer to that page as well.<br>

Also, obtain the SAORI listed below in advance and place it in the same directory as the script DLL (aya.dll, aya5.dll, etc.).<br>
MCIAudioR by umeici [MCIAudioR](http://umeici.hp.infoseek.co.jp/etcetera/)<br>
set_wallpaper by Yagihama Yagi [set_wallpaper](http://www.geocities.co.jp/SiliconValley-Cupertino/8536/)<br>
PROXY.DLL by Komei Hashimoto [PROXY.DLL](http://homepage3.nifty.com/khsoft/cbs/)
