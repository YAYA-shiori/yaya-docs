# Saying Different Things at the Same Time

> Reposted from [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

You can make both characters say the same thing at the same time with `\_s`, but how can you make them say different things simultaneously?

### Using a SAORI

There is a SAORI called [parallel](http://www.geocities.jp/poskoma/).

### Text only

A sample that does this using only a text script. &new{2005-4-22};

[A ready-to-use dictionary file](../attachment/aya_parallel.txt)

### When the lines to be spoken are predetermined

For those who do not know SAORI or functions and want to do this as simply as possible.

<http://63factory.jp/~klat/bottle/soft.html>

You can use "Pata Pata-san" from Bottle Tool.<br>
As its name suggests, it is a special script editing tool for SSTP Bottle, but there is no problem using it with ordinary ghosts.
