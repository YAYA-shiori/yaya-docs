# Check for Duplicate Folder Names

> Reposted from [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

This is a necessary tip, although it is not directly related to the text.

You have created a ghost and written install.txt, but is its installation folder name really unique among other ghosts?
...If you have ever wondered about this, there is a tool that uses the large number of ghost data registered with [Nani-ka Ghost Center](http://ngc.aqrs.jp/) over the years to check whether the name is already in use.

<http://ghosttown.mikage.jp/cgi-bin/check/gd_checker.cgi>
