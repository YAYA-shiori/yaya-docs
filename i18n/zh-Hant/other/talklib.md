# 對話純文字撰寫支援函式庫「Ayariris EX」

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

每次都要寫等待標籤，很麻煩嗎？

寫 `\s[]` 之類的東西，會不會花太多時間？

用 SakuraScript 寫文章，之後很難修改，讓你很困擾嗎？

……那就用這個吧。

### 概要

> "`\u\s[10]\0\s[2]`…`\w5`…`\w5`…`\w5`…`\w5`…`\w5\w9\w9\1`なんや、`\w5`アホみたいな顔してからに。`\w9\w9\0\s[7]\n\n`バッテリーがヘタりかけてるのに、`\w9\n`休止状態で放置しないでください！`\w9\n`ばかになるでしょ！`\w9\w9\1\n\n`…`\w5`…`\w5`もともと賢い事ないがな。`\w9\w9\0\s[26]\n\n`…`\w5`…`\w5`…`\w5`…`\w5\e`"

這樣的辭典……

```
<<"
ま０５：分かりました！分かりましたよ！２０年モノのパソコンがどうなるのか！
し１０：スクラップやのうて？
ま　　：付喪神っていう便利な言葉が、世の中にはあるんですよ！
し１１：…まあ、ゴーストにはなったがな？
">>
```

就會變成這樣。

**即使導入本函式庫，以一般 SakuraScript 單行寫成的對話也會直接通過（也可以只調整標點符號處的等待時間等設定）。**

**文章中的 SakuraScript 會照常執行。若要進行細部調整，或是在途中呼叫單純說話以外的功能，請直接撰寫 SakuraScript。**

### 準備工作

1. 由於會大量使用最新的系統辭典與最新的 YAYA 功能，請覆蓋 yaya.dll 和「系統辭典」。
1. 請下載 [aya_lilith_ex.dic](http://ms.shillest.net/ghost/mobilemaster/ghost/master/aya_lilith_ex.dic) 和 [aya_lilith_ex_config.dic](http://ms.shillest.net/ghost/mobilemaster/ghost/master/aya_lilith_ex_config.dic)，並放入 ghost/master 底下。
1. 請在 yaya.txt 的 **include, system_config.txt** 後方附近，追加
dic, aya_lilith_ex.dic<br>
dic, aya_lilith_ex_config.dic<br>
。

請開啟 **aya_lilith_ex_config.dic**，並適當設定 **あやりりすEXヘッダ0** 和 **あやりりすEXヘッダ1**。設定方式記載於辭典內的註解；通常只要寫下想使用的多個單字元候選，並像 [まマ] 這樣用方括號括起來即可。

※進階：此處可以使用正規表示式。若想使用兩個以上的字元，請自行嘗試不同寫法。

### 使用方法

使用 YAYA 較新版本新增的多行文字描述功能（Here Document）。

以 " " 括住的文字

```
<<"
">>
```

與以 ' ' 括住的文字

```
<<'
'>>
```

效果相同。這兩種寫法的差別只有後者可以逐行直接書寫。

使用這項功能，基本上可如下撰寫。

```
<<"
ま０５：分かりました！分かりましたよ！２０年モノのパソコンがどうなるのか！
し１０：スクラップやのうて？
ま　　：付喪神っていう便利な言葉が、世の中にはあるんですよ！
し１１：…まあ、ゴーストにはなったがな？
">>
```

開頭的 1 個字元「ま」「し」，請分別改成在 aya_lilith_ex_config.dic 中設定的字元。

後面的全形數字是 Surface 編號（表情 ID）。使用半形數字也可以。

標點符號以及換行時的停頓等會自動適當插入。通常直接照原樣書寫即可。

如果要做一些特殊處理，可以直接使用 Sakura Script。也能和以往一樣，與包含 Sakura Script 的單行文字共存。

### 語法

```
ま０５：てすとてすと
```

「：」前面是定義表情及其他選項的部分，後面則是說話文字。

基本形式為：設定的1個字元＋表面編號：文字。表面編號（表情ID）可以使用半形或全形；保持在日文輸入模式下使用全形輸入會比較方便。

```
ま０５「かぎかっこでもいけるよ」
```

也可以用引號括住文字，但請務必將引號閉合。

```
ま消：きゃー消えちゃった―
```

以「消」代替編號，就會讓視窗消失（角色會隱藏起來）。

```
ま　：さっきの表情のままね
```

如果什麼都不寫，就會維持前一個表情。空格（不論全形或半形）都會被忽略。

```
二人：バルス！
```

寫上「二人」就會讓兩人同時說話。

```
ま０７し１１二人：バルス！
```

這種寫法也可以將多個選項串接起來。以上例子中，會先將兩個角色分別切換為第7號和第11號表情，然後讓兩人同時說話。

```
待ち無しま０５：あまり待たない
待ちゼロま０５：ぜんぜん待たない
待ち多めま０５：ふつうより長めに待つ
```

需要立刻吐槽，或想演出思考較久的情況時，可以像這樣控制開始說話前的等待時間。另外，**即使完全不寫，系統也會適時加入預設的等待時間**。

```
クリック待ちま０７：クリック待ってる
```

寫上「クリック待ち」，就會在開始說話前等待使用者點擊對話方塊。

```
改行無しま０５：改行しないよ
```

寫上「改行無し」，就可以不換行，直接從前面說過的內容接續下去，只變更表情。

```
改行多めま０８：改行しまくり！
```

會稍微多換幾行，適合用於分隔段落等情況。

```
ま００：（ユーザ）さん！
```

會在文字中插入使用者名稱。這只適用於「：」之後的說話文字部分。

```
ま０５：（チョコ｜菓子パン｜ケーキ）食べよう！
```

以｜分隔並寫上字串，再用括號括起來，就會隨機選取其中一個。

```
＃コメントなので無視
```

以＃開頭的行會完全被忽略。

```
＠設定：パッシブモード
＠設定：クイックセクション
＠設定：タイムアウト1000「時間切れ」
```

以「＠設定：」開頭的行是與後續對話相關的選項設定。上面的範例如下：

- 被動模式（忽略所有滑鼠反應以外的事件）
- 快速區段（忽略所有字元的等待，一瞬間顯示全文）
- 逾時（等待後續數字所指定的毫秒數，等待結束後呼叫以「」括住名稱的函式）

以上就是這些設定。

```
＠メニュー：さんぷる１｜Sample1Execute
＠半分メニュー：さんぷる２｜さんぷる２実行
＠改行多めメニュー：さんぷる３｜OnTest3Exec｜R0
＠クリック待ちメニュー：さんぷる４｜さんぷる4実行
```

以「＠～メニュー：」開頭的行是用來顯示選單的。<br>
半版選單會在標準尺寸的對話方塊中，每列並排顯示兩個項目。<br>
加上「多換行」會讓一個換行變成一行半。可用於分隔選項等情況。<br>
加上「等待點擊」會在顯示選單後立即進入等待點擊（`\x`）狀態。

後續內容以｜分隔。第一個項目是要顯示的文字，第二個項目起則是要執行的函式／事件。

另外，**選單內會自動成為快速區段**，所有內容都會一口氣顯示，不會等待。

### 自動接續對話與隨機選擇

```
ま０５：ちぇいんてすと。
し１０：うまくいくやろか。
=====
ま０５：ちぇいん2-Aにきたよ。
し１０：成功やね。
-----
ま０５：ちぇいん2-Bにきたよ。
し１０：ここはランダムや。
```

以 =====（5 個以上的 =）分隔時會成為接續對話，以 -----（5 個以上的 -）分隔時則會成為隨機選擇。

例如上述範例中，說完第一個 ===== 之前的內容後會暫時結束；到了下次要說隨機對話的時機，則會從第 2 個和第 3 個對話中隨機選擇一個來說。
