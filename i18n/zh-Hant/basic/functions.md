# 函式

函式名稱也可以使用全形字元。

## 基本的函式定義

```
Test{
  "Hello World!"
}
```

這個 `Test` 函式會輸出字串 `"Hello World!"`。YAYA 的特色之一是，只要存在非指派運算式的單純變數或字串（此例中的 `"Hello World!"`），就會將其視為傳回值。

也就是說

```
Test{
  _A = 10
  _B = 11+32
  "Hello World!"
}
```

即使如此，傳回值仍會是 `"Hello World!"`。

大括號也可以寫成以下形式。

```
Test
{
  "Hello World!"
  "Hallo Welt!"
}
```

## 多個傳回值候選項目

有多個傳回值候選項目時，會從中隨機選出一個。

```
Test{
  A = 10
  "Hello World!"
  "Hallo Welt!"
  10
  11+32
}
```

此例會傳回 `"Hello World!"`、`"Hallo Welt!"`、`10` 或 `43` 其中之一。

## 引數

可以將引數傳入函式。收到的引數會存放在區域變數陣列 `_argv` 中，而引數數量（`_argv` 的大小）則會存放在 `_argc` 中。

```
てすと{
  "入力は「" + _argv[0] + "」だよ"
}
```

定義上述函式後，

```
てすと("うかがか")
```

像這樣執行時，會輸出 `"入力は「うかがか」だよ"`。

## 自身的函式名稱

區域變數 `_FUNC_NAME_` 中會存放目前正在執行的函式名稱。這個變數是為了提升便利性而新增，並隨著各種動態定義指令（例如 [APPEND_RUNTIME_DIC](../functions/APPEND_RUNTIME_DIC.md)）的擴充而加入。

## 變數的定義

可以在函式內自由宣告變數。變數只能在函式內定義，無論是區域變數或全域變數皆然。名稱以 `_` 開頭的變數會視為區域變數，其餘則會視為全域變數。

| 種類 | 名稱 | 範圍 |
|------|------|---------|
| 區域變數 | 以 `_` 開頭 | 僅限定義所在的大括號內 |
| 全域變數 | 不以 `_` 開頭 | 函式執行並定義一次後，即可在任何地方使用。結束人格後仍會保留 |

若要刪除全域變數，必須使用 [ERASEVAR](../functions/ERASEVAR.md) 函式。

```
テスト2{
  _aa = 200  // これはローカル
  bb = 200   // これはグローバル
}
```

像是只會在該函式中使用的變數，最好盡量使用區域變數，這樣較不容易產生錯誤。例如，迴圈處理的計數器應像下方這樣使用區域變數（`_i`）。

```
テスト2{
  for _i = 0; _i < 10; _i++
  {
    _i + "\n"
  }
}
```

## 呼叫次數限制

可以在[基礎設定檔的 `fncdepth`](../grammar/01-basic-settings.md) 中設定函式呼叫深度（不是呼叫次數）。預設為 32 層。

達到限制時會呼叫 [shiori.OnCallLimit](../system/shiori-OnCallLimit.md)（函式名稱、行）。執行期間記憶體耗盡時會呼叫 [shiori.OnMemoryLimit](../system/shiori-OnMemoryLimit.md)()，但無法攔截堆疊溢位。
