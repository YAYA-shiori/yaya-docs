# 運算子

用來進行計算的項目。

## 算術運算子

也就是加、減、乘、除。

| 運算子 | 說明 | 範例 |
|--------|------|-----|
| `x + y` | 將 x 和 y 相加 | `1+1` → `2` |
| `x - y` | 從 x 減去 y | `2-1` → `1` |
| `x * y` | 將 x 乘以 y | `6*2` → `12` |
| `x / y` | 將 x 除以 y。小數部分無條件捨去 | `4/3` → `1` |
| `x % y` | 取得 x 除以 y 的餘數 | `4%3` → `1` |

計算 `x % 2`，若結果為 0 就是偶數，若為 1 就是奇數，可以用這種方式判斷。

## 邏輯運算子

判斷是否相等、不相等、大於或小於某個值等。「真」或「假」（正確或不正確）。大多會接在 `if` 陳述式或 `for` 陳述式等之後，作為分支或迴圈的條件。透過條件分支，可以根據切換前的人格名稱或啟動累計時間等來改變對話。

| 運算子 | 說明 |
|--------|------|
| `x == y` | 若 x 和 y 相同則為真 |
| `x != y` | 若 x 和 y 不同則為真 |
| `x && y` | 若 x 且 y 為真則為真。`&&` 前後兩側都為真時為真（AND） |
| `x \|\| y` | 若 x 或 y 為真則為真。`\|\|` 前後任一側為真時為真（OR） |
| `x > y` | 若 x 大於 y 則為真。不包含相同的值。`10 > 1` 為真，`10 > 100` 和 `10 > 10` 為假 |
| `x >= y` | 若 x 大於或等於 y 則為真。包含相同的值。`10 >= 1` 和 `10 >= 10` 為真，`10 >= 100` 為假 |
| `x < y` | 與 `>` 相反。若 x 小於 y 則為真 |
| `x <= y` | 與 `>=` 相反。若 x 小於或等於 y 則為真 |
| `!x` | x 為假（否定）。`!(1==1)` 為假。在這個例子中，一般會寫成 `1!=1` |
| `y _in_ x` | 若字串 x 中包含 y 則為真。`"さくら" _in_ "あさくら"` 為真。請注意順序 |
| `y !_in_ x` | 若字串 x 中不包含 y 則為真。`"さくら" !_in_ "あさくら"` 為假。請注意順序 |

## 字串運算

使用 `+` 串接字元。

```
_c = "さくら" + "と" + "うにゅう"
// 結果: "さくらとうにゅう"
```

## 陣列操作

使用 `,` 將 x 和 y 組成陣列。

```
_array = (_hoge, _fuga, _gonyo)
```

`_array` 中會有三個值。
