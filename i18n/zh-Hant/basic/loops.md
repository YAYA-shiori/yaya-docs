# 重複

## for 迴圈

`for` 陳述式的寫法如下。

```
for 初期条件 ; 終了条件 ; 各ループの最後に実行される処理
{
  ...
}
```

例如，若要重複 10 次，

```
for _i = 0 ; _i < 10 ; _i = _i + 1
{
  _i + "回目\n"
}
```

可以這樣寫。第 0 次、第 1 次、…、第 9 次會逐行輸出。請注意，每次迴圈最後執行的處理（`_i = _i + 1`），會在該迴圈的處理，也就是 `_i + "回目\n"` 輸出後執行。

在這個範例中，輸出 `"9回目\n"` 後，`_i` 會 +1 變成 10，判定條件為偽，因此迴圈結束。從 0 到 9，總共會迴圈 10 次。

迴圈陳述式中常用的運算子有 `++`、`--`、`+=`、`-=` 等。

| 運算子 | 意義 |
|--------|------|
| `a++` | `a = a+1` |
| `a--` | `a = a-1` |
| `a+=b` | `a = a+b` |
| `a-=b` | `a = a-b` |

因此，上述的 `for` 陳述式也可以寫成：

```
for _i = 0 ; _i < 10 ; _i++
{
  _i + "回目\n"
}
```

**注意:** 基本寫法是不以括號括住條件運算式，但也可以像 `while (_i < 10)` 一樣加上括號。像 `for (_i = 0; _i < 10; _i++)` 這樣以括號括住整個標頭的寫法，可在 Tc603-6 以後的版本使用（Tc603-5 以前會發生錯誤）。

## while 迴圈

除了 `for` 陳述式，也可以使用 `while` 陳述式編寫迴圈。

```
while ループ継続条件
{
  ...
}
```

前述的 `for` 陳述式可以改寫如下。

```
_i = 0
while _i < 10
{
  _i + "回目\n"
  _i++
}
```

若 `while` 陳述式的判定運算式永遠為真，就會形成無限迴圈，導致處理無法結束。

```
while 1 == 1
{
  ...
}
```

`1 == 1` 是恆真式，因此永遠成立，會形成無限迴圈。此外，在 YAYA 中，bool 值（布林值）是以數值是否為 0 來判定，因此以下寫法也會形成無限迴圈。

```
while 1
{
  ...
}
```

## break 陳述式

若要在 `for` 陳述式或 `while` 陳述式執行途中跳出迴圈，請使用 `break`。

```
_i = 0
while 1
{
  if _i >= 10
  {
    break
  }
  _i + "回目\n"
  _i++
}
```

這段處理看起來像是無限迴圈，因為 `while` 陳述式的條件運算式永遠為真；不過，由於其中包含「當 `_i` 大於或等於 10 時執行 `break`」的處理，因此實際效果與前述重複 10 次的陳述式相同。
