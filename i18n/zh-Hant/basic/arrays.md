# 陣列

## 概要

陣列就像是一組變數。

如果只使用一般變數，

```
_a = 1
_b = 2
_c = 3
_d = 4
_e = 5

_sum = _a + _b + _c + _d + _e
```

而使用陣列則可以寫成

```
_a = (1,2,3,4,5)

_sum = _a[0] + _a[1] + _a[2] + _a[3] + _a[4]
```

請注意，索引從 0 開始，因此最後一個索引是 4。

陣列搭配重複處理使用時，才能真正發揮威力。不必像剛才那樣逐一寫出 `_a[0]`、`_a[1]`、`_a[2]`、……，也可以改寫如下。

```
_a = (1,2,3,4,5)

_sum = 0
for _i = 0 ; _i < 5 ; _i++
{
  _sum += _a[_i]
}
```

使用變數 `_i`，就能依序取得 `_a` 中的各個值，而不必逐一寫出 `_a[0]`、`_a[1]`、`_a[2]`、……。在 `for` 迴圈中，`_i` 的值會在小於 5 時每次加 1，因此會依序查看 `_a[0]`、`_a[1]`、`_a[2]`、……。

## 使用 ARRAYSIZE 動態取得大小

在上面的範例中，必須事先知道陣列的大小是 5 才能寫出程式。改成如下寫法後，就不必在意陣列的大小。

```
_a = (1,2,3,4,5)

_sum = 0
for _i = 0 ; _i < ARRAYSIZE(_a) ; _i++
{
  _sum += _a[_i]
}
```

[ARRAYSIZE](../functions/ARRAYSIZE.md) 會判定 `_a` 陣列的大小並傳回 5。只要 `_a` 是陣列，大小是多少都可以。

陣列中也可以放入文字。

```
_sweets = ("プリン", "チョコレート", "クレープ", "甘口いちごスパ")
_talk = ""
for _i = 0 ; _i < ARRAYSIZE(_sweets) ; _i++
{
  _talk += _sweets[_i] + "に"
}
"\1\s[10]\0\s[0]" + _talk + "・・・今日は全部食べちゃうよ！\1なんかまざっとる！\e"
```

## foreach 迴圈（最簡單的方法）

使用 `foreach` 時，不需要 `_i = 0`、`ARRAYSIZE` 或 `_i++`。只要寫出對應於 `_a[_i]` 的項目（此處為 `_var`）即可。

```
_a = (1,2,3,4,5)

_sum = 0
foreach _a ; _var
{
  _sum += _var
}
```

`_a` 中的內容會依序放入 `_var`。到達陣列末尾時，迴圈會自動結束。
