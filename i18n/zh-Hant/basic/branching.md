# 分支處理

## 概要

可以根據運算式是否成立來分流處理。幾乎一定會搭配[邏輯運算子](operators.md#論理演算子)使用。

## if～else～ 陳述式

```
if (式)
{
  "正しい"
}
else
{
  "正しくない"
}
```

「運算式」成立時會執行前面的 `{}` 中的處理，不成立時則會執行 `else` 後面的 `{}`。運算式中可以寫入 `_name == "さくら"` 這類比較。

```
_name = "さくら"
if (_name == "さくら")
{
  "さくらです"
}
else
{
  "さくらじゃない！"
}
```

## case～when 陳述式

以標籤為基礎的分支處理。會執行 `case` 運算式的值與 `when` 的值相符的區塊。

```
case _value
{
  when 1
  {
    // _value が 1 の場合
  }
  when 2, 3
  {
    // _value が 2 または 3 の場合
  }
  others
  {
    // どれにもマッチしない場合
  }
}
```

## switch 陳述式

依位置（從 0 開始）選擇輸出候選項目。

```
switch _n
{
  "ゼロ番目"
}
{
  "一番目"
}
{
  "二番目"
}
```
