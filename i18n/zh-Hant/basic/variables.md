# 變數

## 概述

變數就像一個可以儲存數值或文字（字串）的箱子。既然是箱子，就必須放入內容；放入新內容後，原本的內容會消失。

**注意：** 變數宣告只能在函式中進行。

## 基本用法

```
_a = 1
_b = 2
```

將 1 放入 `_a`，將 2 放入 `_b`。放入內容後，就可以使用變數。

```
_c = _a + _b
```

這樣一來，1 + 2 的結果 3 就會放入 `_c`。

## 字串變數

變數也可以存放文字。

```
_a = "紅茶"
_b = "ケーキ"
```

文字也可以用 `+` 相加。因此，

```
_c = _a + "と" + _b
```

這樣設定後，`_c` 的內容就會是 `"紅茶とケーキ"`。

## Sakura Script 的處理方式

Sakura Script 必須以字串的形式記述，才會執行。例如，

```
\![open,inputbox,OnTest,60000]
```

像這樣書寫並不會正常運作。這是因為

```
"\![open,inputbox,OnTest,60000]"
```

必須如此設定。

## 展開變數

若要在對話中顯示變數的內容，請記述為 `%(変数名)`。

```
_hoge = "紅茶"
"\0\s[0]飲み物なら%(_hoge)をどうぞ\e"
```

這樣一來，就會顯示「飲み物なら紅茶をどうぞ」。
