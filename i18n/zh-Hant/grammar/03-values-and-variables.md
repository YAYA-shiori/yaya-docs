# 值與變數

## 即值

YAYA 可處理的值有整數、實數、字串 3 種。

### 整數 (int)

帶正負號的 64 位元整數（Tc566-1 起擴充，此前為 32 位元）。十進位數值可直接記述。在開頭加上 `0b` 可記述二進位數值，在開頭加上 `0x` 則可記述十六進位數值。

接下來的函式 `int10` 會傳回整數 10。以下 3 種寫法在十進位中都是 10。

```
int10
{
    10
    0b1010
    0xa
}
```

### 實數 (double)

帶正負號的 64 位元浮點數。當數值有小數位，或想處理非常大的數值（即使精度降低也無妨）時使用。

整數與實數的區別在於有無小數點；YAYA 找到數值中的小數點時，會將其視為實數。例如：

```
Test
{
    3/4*100
}
```

這樣寫時，結果會是 0，而不是 75。這是因為評估 `3/4` 時會將其解讀為 int，並捨去小數點以下的部分（運算子會由左至右依序評估）。若要得到預期的結果，必須寫成：

```
Test
{
    3.0/4*100
}
```

評估 `3.0` 時會將其解讀為 double 型別，因此結果會是實數 `75.0`。將實數轉換為字串時，小數點以下會保留 6 位，輸出為 `75.000000`。若要轉換為整數，請使用 [TOINT](../functions/TOINT.md) 函式。

若要在變數運算中達成此效果，必須在宣告時指派實數，或使用 [TOREAL](../functions/TOREAL.md) 函式。

```
Test
{
    _A = 3
    _B = 4
    TOREAL(_A)/_B*100
}
```

無論 OS 地區設定為何，小數點一律使用 `.`；從字串轉換為實數，以及在辭典中記述實數時，也都使用 `.`（即使是德語等以 `,` 作為小數點的地區設定亦同）。

### 字串

以雙引號（`"`）括住的值是字串，會展開變數或函式（[展開字串中的嵌入元素](06-string-embedding.md)）。

在行末寫上 `/`，即可記述包含換行的字串。

```
"こん\n/
なかんじに\n/
書いてもＯＫ\n/"
```

也可以使用下文介紹的 Here Document 來記述包含換行的字串。Sakura Script 必須以字串形式記述才能運作。

在 Tc569-8 之前的版本中，字串內不能包含雙引號。在 Tc569-8 之後的版本中，連續寫兩個雙引號即可在字串內加入雙引號。

```
"1""2"
```

這會定義字串 `1"2`。

### 字串（不展開）

以單引號（`'`）括住的值是單純字串，不會展開。YAYA 可以在字串中嵌入變數或函式，但只有以雙引號括住的字串才會展開這些內容。

在 Tc569-8 之前的版本中，字串內不能包含單引號。在 Tc569-8 之後的版本中，連續寫兩個單引號即可在字串內加入單引號。

```
'1''2'
```

這會定義字串 `1'2`。

雖然不建議使用太複雜的寫法，以免日後難以閱讀，但以下是同時使用單引號和雙引號的例子：

```
'1''2"3'
"1'2""3"
```

這兩種寫法都等同於定義字串 `1'2"3`。

### Here Document

可跨多行記述的字串即值。從 Tc535-1 起可使用。

```
<<"
行1
行2
">>
```

這會成為可展開的字串，

```
<<'
行1
行2
'>>
```

這會成為不展開的字串。雖然可在 Here Document 前後記述各種運算式，但此功能僅支援於辭典檔案中，即使使用 [EVAL](../functions/EVAL.md) 也會發生錯誤。

## 陣列與雜湊

除了即值之外，也有用來整體處理多個值的型別：**通用陣列**（[陣列](05-arrays.md)）。從 Tc600-3 起也能使用**雜湊**（關聯陣列，[雜湊](12-hash.md)）。

從 Tc600-3 起，也可以將陣列或雜湊放入陣列或雜湊的元素中（巢狀結構）（[值的巢狀結構與多維指派](13-nesting.md)）。

## 變數

變數是用來儲存值的區域。一個變數可以儲存：

- 整數、實數、字串
- 通用陣列（每個元素都可以儲存上述任一型別）
- 雜湊（Tc600-3 之後）

只要不違反以下禁止事項，變數名稱可自由命名。

- 以數字 0〜9 開頭
- 包含以下字元：空白　`!`　`"`　`#`　`$`　`%`　`&`　`(`　`)`　`*`　`+`　`,`　`-`　`/`　`:`　`;`　`<`　`=`　`>`　`?`　`@`　`[`　`]`　`` ` ``　`{`　`|`　`}`　`~`
- 與保留字完全相同
- 與函式名稱完全相同

值的儲存（指派）使用指派運算子 `=`。若要輸出內容，寫出變數名稱即可，與函式相同。

```
request
{
    str = "こんにちは"

    str
}
```

以上是簡單的例子，會將字串儲存至變數 `str`，並直接輸出。

尚未指派值的變數會成為一種特殊型別，稱為「未定義型別」。請注意，這並不代表「不輸出任何內容」。

```
request
{
    "Hello World"
    i
}
```

在此例中，因為 `i` 不存在，所以會成為「未定義型別」。「未定義型別」在與數值運算時會視為 0，與字串運算時則會視為 `''`（空字串）。在上述例子中，會以 1/2 的機率傳回「未定義型別」或字串 `"Hello World"`。

## 範圍與生命週期

變數依照範圍的不同分為 2 種。

- 全域變數：可在所有函式中共用的變數。除非以 [ERASEVAR](../functions/ERASEVAR.md) 刪除，否則會永遠存在
- 區域變數：只能在目前的 `{ }` 及更深層的巢狀階層中使用的變數。離開對應的 `{ }` 時，生命週期便結束

兩者以變數名稱區分；名稱開頭為底線（`_`）的變數會視為區域變數。善用只在「需要的範圍內有效」的區域變數，可讓程式更容易理解。

```
request
{
    _i = "3*2は"

    _j = multi(3)

    _i + _j + "です"
}

multi
{
    _i = _argv[0]
    _i * 2
}
```

`request` 和 `multi` 使用了相同名稱的變數 `_i`，但會被視為完全不同的變數，彼此不會破壞對方的值。用來處理函式引數的變數 `_argc` 和 `_argv` 實際上也是區域變數，因為每個函式都會各自儲存不同的值。

請注意，區域變數並非「可在目前函式內使用的變數」，而是「只能在目前的 `{ }` 及更深層的巢狀階層中使用的變數」。

```
request
{
    {
        _str = "Hello World"
    }

    _str
}
```

這個程式不會如預期運作。`_str` 只在 `{ }` 內有效，因此在嘗試取出輸出內容的位置時，變數已經消失。所以函式 `request` 會輸出空字串。

全域變數和區域變數的另一項差異是生命週期。如上所述，區域變數離開使用它的 `{ }` 後就會消失。相較之下，全域變數可在任何地方使用，而且其值會在 `unload` 時自動儲存至檔案，並在 `load` 時還原。

若要刪除全域變數，必須使用 [ERASEVAR](../functions/ERASEVAR.md) 函式。此外，基於全域變數的特性，建議在啟動時最先執行的函式（例如 `OnBoot`）中初始化全域變數。
