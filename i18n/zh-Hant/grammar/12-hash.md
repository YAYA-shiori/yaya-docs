# 雜湊（Tc600-3 以降）

Tc600-3 以後，值的型別新增了**雜湊**（關聯陣列）。

雜湊的值或鍵可以放入陣列或雜湊（巢狀）。巢狀讀寫與多維指派請參閱[巢狀值與多維指派](13-nesting.md)。

關於從 500 系列起的相容性變更，請參閱[600 的變更項目](../other/changes-600.md)。

## 建立

使用 [IHASH](../functions/IHASH.md) 建立雜湊。鍵和值交替排列。`IHASH()` 會建立空的雜湊。

```
_h = IHASH("name", "さくら", "age", 16)
_e = IHASH()
```

從字串建立時，請使用 [HASH_SPLIT](../functions/HASH_SPLIT.md)。

```
_h = HASH_SPLIT("a=1,b=2", ",", "=")
```

雜湊變數必須先透過 IHASH 等方式建立為雜湊。即使對未定義的變數寫入 `_x["a"] = 1`，也會被當成通用陣列，而不是雜湊（`"a"` 會被解讀為數值 0，也就是第 0 個元素）。

## 參照・指派元素

使用 `h[鍵]` 讀取值，並使用 `h[鍵] = 值` 新增或覆寫值。

```
_h = IHASH()
_h["name"] = "さくら"
_h["name"]       // "さくら"
_h["none"]       // VOID （キーが無いときは未定義の変数と同じ）
_h["age"] += 1   // 複合代入も使える
```

- 沒有鍵時，會和未定義的變數一樣傳回 **VOID**（Tc603-1 以後。Tc602-13 以前會傳回空字串）。由於會以空字串作為字串、以 0 作為數值處理，因此 `_h["none"] == ""` 的結果為 1，`_h["none"] + 1` 則會得到整數 1（[超出範圍的元素](05-arrays.md#範囲外の要素)）
- 複合指派（`+=` `-=` `*=` `/=` `%=`）的左側鍵不存在時，也會以 VOID 計算（Tc602-10 以後）。可使用 `_count[_name] += 1` 計數。若鍵存在但值為空字串，則和以往相同，會以空字串計算（`"" + 1` 為 `"1"`）
- 若要區分「沒有鍵」和「值為空字串或 VOID」，請使用 [HASH_EXIST](../functions/HASH_EXIST.md)
- 值也可以放入陣列或雜湊（[巢狀](13-nesting.md)）
- 第二個及之後的索引（範圍指定或分隔符號）會被忽略。讀取帶有範圍的 `h[a, b]` 會得到空字串

## 鍵的相等判定

純量鍵會分成「數值」和「字串」來比較。

- 視為數值的項目：整數、實數、表示**正規形式整數的字串**（例如 `"9"`、`"-3"`）
  - `"09"`、`"-0"`、`"+1"`、`" 1"`、無法容納於 64 位元的數字字串會視為字串
- 數值之間依數值比較。整數和實數也能無誤差地比較
- 字串之間依字串比較。VOID 會成為與空字串相同的鍵

因此，`h[1]`、`h["1"]`、`h[1.0]` 都會成為**相同的鍵**。另一方面，`h[1.5]` 和 `h["1.5"]`、`h[0]` 和 `h["-0"]` 則是不同的鍵。

將多個被視為相同鍵的值傳入 IHASH 時，會保留第一個鍵和值。

```
IHASH(9, "i9", "9", "s9")   // 9=i9 だけ
```

## 排序

雜湊的元素會依**鍵的順序**排列，而非依插入順序。[HASH_KEYS](../functions/HASH_KEYS.md)、[HASH_VALUES](../functions/HASH_VALUES.md)、字串化、foreach、存檔檔案中的排列順序都相同。

- 依數值 < 字串的順序排列。數值之間依數值排序，字串之間依字串排序
- 鍵為陣列或雜湊時，會依純量 < 陣列 < 雜湊的順序排列，陣列彼此之間、雜湊彼此之間則從第一個元素開始依序比較

```
_h = IHASH(10,1, 9,1, 100,1, -1,1, "b",1, "B",1, 2.5,1)
HASH_KEYS(_h)   // -1,2.5,9,10,100,B,b
```

## 作為值時的行為

| 操作 | 結果 |
|---|---|
| 真偽 | 有一個以上的元素時為真，空雜湊時為假 |
| `GETTYPE` / `GETTYPEEX` | 5 |
| 字串化（`TOSTR` 或與字串串接） | 以 `,` 串接 `鍵=值`。例如 `a=1,b=x` |
| 數值化 | 0 |
| `h1 == h2` | 元素數、鍵和值全部相同時為真。值有巢狀內容時會比較到內部內容 |
| 雜湊與非雜湊的 `==` | 一律為假（即使字串化後的結果相同也為假） |
| `+`（另一方為純量或雜湊） | 將雙方轉為字串後串接 |
| `+`（另一方為陣列） | 將雜湊與字串逐一串接至陣列的各元素 |
| `-` `*` `/` `%` | 會發出警告 W0024（如下所述） |

```
_h = IHASH("a", 1)
_h + 1        // "a=11"
'z' + _h      // "za=1"
_h + _h       // "a=1a=1"
(1,2) + _h    // ("1a=1","2a=1")
```

`-` `*` `/` `%`（包括複合指派）其中一方為雜湊時，會發出警告 W0024。結果方面，若另一方是純量，會直接傳回右側的值（`h - 1` 為 `1`，`1 * h` 為 `h`）；若另一方是陣列，則會逐一對其元素進行計算。由於結果沒有實際意義，請勿使用。此外，陣列元素為雜湊時（`(h, 1) - 1`），不會發出 W0024。

## 函式引數與 `,` 運算子

通用陣列會在引數或 `,` 運算子中展開，但雜湊不會展開，而是直接成為一個元素。

```
_a = (0, _h, 2)   // 要素数 3。_a[1] はハッシュ
func(_h)          // func の中で _argv[0] がハッシュになる
```

## foreach

雜湊也可以使用 foreach 迴圈。在只有一個變數的形式中，會依鍵的順序將值放入變數。

```
_h = IHASH("a", 1, "b", 2)
foreach _h ; _v
{
  // _v = 1, 2
}
```

寫入兩個變數時，第一個會取得鍵，第二個會取得值。這種形式也適用於陣列和簡易陣列，第一個變數會取得從 0 開始的索引。

```
foreach _h ; _k, _v { _s += _k + '=' + _v + ' ' }   // "a=1 b=2 "
foreach ("p", "q") ; _i, _v { ... }                  // _i = 0, 1
foreach "x,y" ; _i, _v { ... }                       // 簡易配列も同じ
```

詳細資訊請參閱[流程控制](07-flow-control.md#foreach-ループ)。
