# 正規表示式

以 `RE_` 開頭的系統函式會使用正規表示式搜尋、分割及取代字串。本頁整理從 YAYA 使用正規表示式的基本方法，以及 Tc606-6 以後可使用的子常式呼叫。

Tc606-6 以後，正規表示式引擎使用 伺か 共用的正規表示式引擎 [uka_regexp](https://github.com/ukatech/uka_regexp)。其語法和意義與 PCRE2（Perl 相容）相近。**語法細節（前瞻、後顧、Unicode 屬性、遞迴、控制動詞等）請參閱 [uka_regexp 的 README](https://github.com/ukatech/uka_regexp/blob/main/README.md)。** 本頁介紹的基本寫法仍可照常使用。

## 函式的選用方式

| 想知道的資訊 | 函式 |
|---|---|
| 字串中是否有任何部分符合 | [RE_SEARCH](../functions/RE_SEARCH.md) |
| 整個字串是否符合 | [RE_MATCH](../functions/RE_MATCH.md) |
| 搜尋所有符合的部分 | [RE_GREP](../functions/RE_GREP.md) |
| 以符合的部分分割字串 | [RE_SPLIT](../functions/RE_SPLIT.md) |
| 取代符合的部分 | [RE_REPLACE](../functions/RE_REPLACE.md)（無法使用 `$1` 等）、[RE_REPLACEEX](../functions/RE_REPLACEEX.md)（可以使用） |
| 在陣列中搜尋符合的元素 | [RE_ASEARCH](../functions/RE_ASEARCH.md)（第一個）、[RE_ASEARCHEX](../functions/RE_ASEARCHEX.md)（全部） |
| 查詢符合的內容、位置及長度 | [RE_GETSTR](../functions/RE_GETSTR.md)、[RE_GETPOS](../functions/RE_GETPOS.md)、[RE_GETLEN](../functions/RE_GETLEN.md) |
| 變更符合條件 | [RE_OPTION](../functions/RE_OPTION.md) |

```
if RE_SEARCH(reference[0], 'こんに?ち[はわ]') {
  "こんにちは"
}
```

## 模式的寫法

模式以字串傳入。**建議使用單引號括住**。雙引號字串中的 `%(...)` 等會展開為內嵌內容，但單引號字串不會展開。`\` 在兩種字串中都會原樣傳遞給正規表示式，因此可以寫成 `\d`。

```
RE_SEARCH("abc123", '\d+')    // 1
```

### 基本語法

| 寫法 | 意義 |
|---|---|
| `abc`、`あ` | 該字元本身。具有特殊意義的符號（`.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `^` `$` `\|` `\`），在前面加上 `\` 就會變成符號本身 |
| `.` | 任意一個非換行字元 |
| `[abc]`、`[a-z]`、`[^abc]` | 字元集合、範圍，以及集合以外的字元 |
| `\d` `\w` `\s` | 數字（`0-9`）、單字字元（`A-Za-z0-9_`）、空白（空格、定位字元、換行等） |
| `\D` `\W` `\S` | 不屬於 `\d` `\w` `\s` 的字元 |
| `^`、`$` | 字串開頭、結尾（使用 `m` 選項時則為行首、行尾） |
| `\b` | 單字邊界 |
| `*`、`+`、`?` | 重複 0 次以上、1 次以上、0 次或 1 次 |
| `{3}`、`{2,4}`、`{2,}` | 重複 3 次、2～4 次、2 次以上 |
| `*?`、`+?`、`??` | 盡可能以最短方式符合的重複（最短匹配） |
| `a\|b` | `a` 或 `b` |
| `(...)` | 群組。可以擷取符合的內容，或在取代字串中使用 |
| `(?:...)` | 不擷取的群組 |
| `(?<name>...)` | 命名群組 |

!!! note "`\d` `\w` `\s` `\b` 僅適用於 ASCII"
    `\d` 不會符合全形數字，`\w` 不會符合日文字元。判斷日文時，請使用 Unicode 屬性。平假名使用 `\p{Hiragana}`、片假名使用 `\p{Katakana}`、漢字使用 `\p{Han}`。

    ```
    RE_SEARCH("あ", '\p{Hiragana}')            // 1
    RE_SEARCH("２０２４", '^\d+$')            // 0（全角の数字）
    RE_REPLACEEX("ひらがなカタカナ", '\p{Katakana}+', '[$0]')   // ひらがな[カタカナ]
    ```

可用的語法不只有這些。前瞻 `(?=...)`、後顧 `(?<=...)`、占有量詞、原子群組、`\Q...\E` 等詳細內容，請參閱 uka_regexp 的 README。

### 選項

使用 [RE_OPTION](../functions/RE_OPTION.md) 設定之後的正規表示式函式所適用的選項。**預設不啟用任何選項。**

| 字元 | 意義 |
|---|---|
| `i` | 不區分大小寫 |
| `m` | 讓 `^` `$` 符合行首與行尾（以多行模式處理） |
| `s` | 讓 `.` 也符合換行字元 |
| `x` | 忽略模式中的空白，並將 `#` 到行尾的內容視為註解 |

```
RE_OPTION("im")
```

也可以在模式中指定選項。`(?i)` 會讓後續部分不區分大小寫，`(?i:...)` 則只讓括號內的部分不區分大小寫。使用 `(?-i)` 可取消設定。

```
RE_SEARCH("ABC", '(?i)abc')       // 1
RE_SEARCH("ABC", '(?i:a)BC')      // 1
```

預設只將 LF（`\n`）視為換行。若要讓 CR LF 也視為換行，請在模式開頭寫上 `(*ANYCRLF)`。

## 查詢符合的內容

符合時，可以使用 [RE_GETSTR](../functions/RE_GETSTR.md)、[RE_GETPOS](../functions/RE_GETPOS.md)、[RE_GETLEN](../functions/RE_GETLEN.md)，以陣列取得內容、位置（從 0 開始）及長度。呼叫下一個正規表示式函式時，這些結果會被覆寫。

```
_r = RE_SEARCH("abc123def", '(\d+)')
_s = RE_GETSTR()      // ("123", "123")
_p = RE_GETPOS()      // (3, 3)
_l = RE_GETLEN()      // (3, 3)
```

- 陣列的第 0 個元素是符合整個模式的部分。第 1 個以後的元素是符合群組（`(...)`）的部分。命名群組也會依編號排列
- **未參與符合的群組不會放入陣列**，因此後面的編號會往前遞補。以 `"a"` 比對 `(a)|(b)` 時，只會增加 1 個元素（整體符合部分和 `(a)` 兩個）
- 在 [RE_GREP](../functions/RE_GREP.md) 和 [RE_SPLIT](../functions/RE_SPLIT.md) 中，每個符合的部分會各自放入一個元素。RE_GREP 的傳回值是符合的個數

```
_n = RE_GREP("a1b22c333", '\d+')   // 3
_s = RE_GETSTR()                   // ("1", "22", "333")
```

!!! warning "捨棄傳回值會成為輸出候選"
    若像 `RE_SEARCH(...)` 一樣不使用傳回值，該值會混入函式的輸出候選中。只想查詢結果時，請將值指派給變數，例如 `_r = RE_SEARCH(...)`。

## 取代

[RE_REPLACE](../functions/RE_REPLACE.md) 會直接使用取代字串。[RE_REPLACEEX](../functions/RE_REPLACEEX.md) 的取代字串則可使用以下寫法。

| 寫法 | 意義 |
|---|---|
| `$0`、`$&` | 整個符合的部分 |
| `$1`、`$2`、… | 第 1 個、第 2 個……群組。只有在存在該編號的群組時，`$10` 以上才會視為兩位數 |
| `${1}`、`${name}` | 以編號或名稱指定（後面接著數字時很方便） |
| `` $` ``、`$'` | 符合部分之前、之後的字串 |
| `$+` | 符合的群組中編號最大的群組 |
| `$_` | 整個原始字串 |
| `$$` | `$` 字元 |
| `\1`～`\9` | 與 `$1`～`$9` 相同 |
| `\\` `\n` `\r` `\t` `\a` `\e` `\f` `\v` | 反斜線、換行、歸位、定位字元等控制字元 |

未參與符合的群組會變成空字串。

```
RE_REPLACEEX("2024-05-17", '(\d+)-(\d+)-(\d+)', '$3/$2/$1')    // 17/05/2024
RE_REPLACEEX("abc", '(?<first>a)', '${first}-')               // a-bc
RE_REPLACEEX("aaaa", 'a', 'b', 2)                             // bbaa（2 回まで置換）
```

## 子常式呼叫（Tc606-6以後）

可以依名稱呼叫正規表示式中的部分。即使模式中沒有 `(?<date>...)` 這類定義，**也會從 YAYA 的變數或函式中尋找該名稱，並將其內容當作模式使用**。

呼叫方式可以使用以下任一種（意義相同）。

- `(?&name)`
- `(?P>name)`
- `\g<name>`、`\g'name'`
- `(?R<name>)`、`(?R'name')`

包含 `'` 的寫法若用在單引號字串中，請連續寫兩次 `''`（`'^\g''name''$'`），或改寫在雙引號字串中。

```
_date = '\d{4}-\d{2}-\d{2}'
_r = RE_SEARCH("今日は2024-05-17です", '(?&date)')     // 1
```

### 名稱的搜尋方式

模式中沒有定義的名稱 `name` 會依照以下順序搜尋。第一個找到且可用的值會成為組成部分。

1. 區域變數 `_name`（名稱以 `_` 開頭時，會使用該名稱的區域變數）
2. 全域變數 `name`
3. 函式 `name`（不帶引數執行時的傳回值）

- **字串和數值**是可用的值。VOID、陣列、雜湊都不能使用，因此會繼續搜尋下一個候選項目
- 若都找不到，或取用的值不是有效的模式，就會發生正規表示式錯誤（W0016）
- 若找不到變數，就會執行同名函式。為避免意外執行函式，**組成部分的名稱應避免與其他函式或變數重複**
- 組成部分中可以再呼叫其他組成部分，也可以呼叫自己進行遞迴
- 每次呼叫正規表示式函式時，都會重新讀取變數或函式的值。函式每次都會執行，因此使用會因亂數而改變內容的函式，也能讓模式每次都不同
- 若模式中定義的命名群組（`(?<name>...)`）與名稱相同，會使用該定義，不會搜尋變數或函式

```
// 部品を関数で用意する
Digits4 { '\d{4}' }
Digits2 { '\d{2}' }

IsDate
{
  RE_MATCH(reference[0], '(?&Digits4)-(?&Digits2)-(?&Digits2)')
}
```

可以組合各個組成部分，讓長模式更易於閱讀。

```
_y = '\d{4}'
_m = '\d{2}'
_date = '(?&y)-(?&m)-(?&m)'
_r = RE_MATCH("2024-05-17", '(?&date)')     // 1
```

使用遞迴即可比對巢狀結構。以下是符合括號成對字串的範例。

```
_paren = '\((?:[^()]++|(?&paren))*\)'
_r = RE_MATCH("(a(b)c)", '(?&paren)')     // 1
```

!!! note "組成部分中的群組"
    寫在組成部分中的 `(...)` 在呼叫返回後會從結果中消失。使用 [RE_GETSTR](../functions/RE_GETSTR.md) 等函式只能取得呼叫端模式中的群組。此外，組成部分不會繼承呼叫端模式中的 `(?i)` 等選項，而是從 [RE_OPTION](../functions/RE_OPTION.md) 設定的選項開始。

## 錯誤

| 狀況 | 結果 |
|---|---|
| 模式語法錯誤，或無法解析子常式名稱 | 警告 W0016。視為不符合（`GETLASTERROR` 為 16） |
| 因重複結構巢狀等原因，回溯次數超過上限，或記憶體不足 | 警告 W0017。視為不符合（`GETLASTERROR` 為 17） |

像 `(a+)+$` 這種會讓回溯次數呈指數增加的模式，若用於很長的字串，就會達到上限。達到上限時，會發生 W0017，並視為不符合。
