# 字串內嵌入元素的展開

## 概要

可以在字串中嵌入變數或函式，並將其執行結果插入該位置。嵌入方式有「範圍指定展開」和「名稱最長匹配展開」兩種。

## 範圍指定展開

以 `%( )` 括住元素來嵌入。

```
request
{
    _i = "pen"
    "This is a %(_i)."
}
```

執行 `request` 時，會輸出 `"This is a pen."`。`%( )` 的運作方式類似所謂的 eval（將字串解讀為指令碼程式碼並執行）。除了單一函式或變數，也可以嵌入數學運算式。

```
request
{
    "1+2+3は%(1+2+3)です。"
}
```

`request` 會輸出 `"1+2+3は6です。"`。

`%( )` 內不能包含雙引號。因此，無法嵌入包含字串的數學運算式。以下範例會發生錯誤。

```
request
{
    "This is a %(_i = "pen")."
}
```

這種情況下，不要使用嵌入，而是像一般數學運算式一樣進行串接。

```
request
{
    "This is a " + (_i = "pen") + "."
}
```

使用括號 `( )` 控制運算順序的方式，在範圍指定展開中也相同。請看以下範例。

```
request
{
    "遊星「%(_i = planet)」は遠い。この遊星は%(color(_i))色をしている。"
}

planet
{
    "mars"
    "saturn"
    "pluto"
}

color
{
    case _argv[0] {
    when "mars";   "red"
    when "saturn"; "yerrow"
    when "pluto";  "blue"
    others;        "unknown"
    }
}
```

最深層的 `( )` 位於 `color(_i)` 的引數，因此會在 `_i = planet` 之前呼叫 `color`，而此時 `_i` 仍為空值，所以結果會是 `"unknown"`。可以多加幾層括號來調整運算順序。

```
"遊星「%((_i = planet))」は遠い。この遊星は%(color(_i))色をしている。"
```

如此便能得到一致的字串。

**特點:**

- 支援複雜的運算式和數學運算
- 字串內不能包含雙引號
- 由於會在載入辭典時靜態解析，因此不會辨識透過 [DICLOAD](../functions/DICLOAD.md) 等方式事後定義的函式。若一定要這樣使用，請考慮使用 [EVAL](../functions/EVAL.md)

## 名稱最長匹配展開

即使不加上 `( )`，只使用 `%` 也可以進行嵌入展開。

```
request
{
   o      = "pen"
   obj    = "eraser"
   object = "world"
   "This is a %object."
}

obje
{
    "television"
}
```

展開對象是變數／函式中，名稱與 `%` 之後的字串最長匹配者。在上述範例中，最符合的是變數 `object`，因此會採用它。結果會是 `"This is a world."`。

由於變數會隨時建立或刪除，展開對象也會依情況而變化。這是範圍指定展開沒有的特性。

```
request
{
   val   = "red"
   trans
   --
   value = "blue"
   trans
}

trans
{
    "%value"
}
```

`trans` 會執行兩次，但第一次和第二次的 `"%value"` 會有不同的運作方式。第一次會解讀為變數 `val` + `"ue"`，第二次則會解讀為變數 `value`。`request` 的輸出會是 `"redueblue"`。

### 重複使用展開結果

可以使用 `%[ ]` 這種格式，重複使用先前的展開結果。

```
request
{
    "「%planet」は遠い。「%city」も遠い。もっとも%[1]になら行けなくもない。"
}

planet
{
    "mars"
    "saturn"
    "pluto"
}

city
{
    "newyork"
    "moscow"
    "madrid"
}
```

`%[i]` 會取得第 i 個展開結果，索引從 0 開始。在上述範例中，`%[0]` 表示 `%planet` 的展開結果，`%[1]` 表示 `%city` 的展開結果。

`%[ ]` 無法用於範圍指定展開。若要在範圍指定展開中重複使用先前的結果，請先將它存入變數。

### 速度

名稱最長匹配展開每次執行時都會重新搜尋展開對象，因此速度遠比範圍指定展開慢。除非確有需要，通常請使用範圍指定展開。

### 在載入時確定名稱

名稱最長匹配展開會在執行時，根據當時存在的變數搜尋名稱。因此，含有 `%` 的字串（例如 URL）可能會從某個時間點開始突然被替換。

```
"https://example.com/?p=100%off"  // 変数 o や of が作られると、その値に置き換わる
```

在設定檔中加入 `embed.lazy, off`，即可在載入辭典時確定無括號的 `%` 後方名稱（Tc604-1 以後）。

- 名稱會根據使用者自訂函式、系統函式，以及名稱寫在辭典運算式中的全域變數，採用最長匹配來決定（也包含透過 `EVAL` 等方式執行的運算式）。僅從存檔檔案還原的變數，以及僅透過 `LETTONAME` 建立的變數，不列入對象。嵌入這類變數時，請寫成 `%(名稱)`
- 已確定的變數若尚未有值，會變成空字串（不會維持 `%名稱` 的形式）
- 若與任何名稱都不匹配，則會將包含 `%` 的內容原樣視為字串。以英文字母或全形字元開頭的內容會顯示警告 W0031。像 `%E3` 這樣的 2 位十六進位數（URL 編碼），或以數字、符號開頭的內容則不會顯示警告
- 區域變數（`%_name`）仍會依照以往的方式，在執行時搜尋名稱
- `%[i]` 的編號會將保留為原字串的內容也算作一項（`embed.lazy` 的設定不會改變編號）
