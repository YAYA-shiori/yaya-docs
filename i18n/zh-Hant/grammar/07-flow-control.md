# 流程控制

## 條件分支

### if / elseif / else 語法

如果運算式的結果為真，就會處理後續 `{ }` 內的內容。條件運算式也可以用 `( )` 括住。

```
request
{
    if !i {
        "iは0である。"
    }
}
```

可以緊接著附加 `elseif` 子句。只有在 `if` 的判斷結果為假時，才會處理此子句。可以串接任意數量的子句。此外，也可以在 `if`～`elseif` 的最後加上 `else` 子句。只有在前面的 `if` 和 `elseif` 判斷結果全為假時，才會處理此子句。

```
request
{
    if !i {
        "iは0である。"
    }
    elseif i == 5 {
        "iは5である。"
    }
    elseif "A" _in_ TOUPPER(i) {
        "iは文字列で、aもしくはAを含んでいる。"
    }
    else {
        "iは0でも5でもaを含む文字列でもない何物かである。"
    }
}
```

如果 `if`、`elseif`、`else` 所處理的 `{ }` 內只有一個指令，就可以省略 `{ }`。因此，上面的範例可以改寫如下。

```
request
{
    if !i
        "iは0である。"
    elseif i == 5
        "iは5である。"
    elseif "A" _in_ TOUPPER(i)
        "iは文字列で、aもしくはAを含んでいる。"
    else
        "iは0でも5でもaを含む文字列でもない何物かである。"
}
```

但如果 `if` 有巢狀結構，就不能省略 `{ }`。以下寫法在 C 語言中正確，但在 YAYA 中錯誤（載入時會發生錯誤）。

```
if i == 0
    if j == 0
        "iとjはともに0である。"
```

必須像下面這樣使用 `{ }`。

```
if i == 0 {
    if j == 0
        "iとjはともに0である。"
}
```

### case / when 語法

以標籤為基礎的分支。`case` 陳述式會評估運算式，並執行標籤值符合的 `when` 子句。

```
request
{
    case i {
    when 0 {
        "iは0である。"
    }
    when "A"
        "iは文字列Aである。"
    others {
        "iは0でもAでもない。"
    }
    }
}
```

`others` 子句是在所有標籤都不符合時執行的部分。`others` 可以省略；省略時則不會執行任何動作。

要比對的標籤值可以用逗號列出。也可以用減號指定比對範圍（例如：`"value1"-"value5"`）。

```
request
{
    case name+(i+1) {
    when "Pentium3","Pentium4"
        "Pen!!!は1999年、Pen4は2000年発売発売。"
    when "Pentium5"-"PentiumX" {
        "まだ無い。"
    }
    others
        "分からない。"
    }
}
```

`when` 中指定的標籤值必須是立即值。不能寫入變數、函式或包含運算子的數學運算式。如果 `when`、`others` 所處理的 `{ }` 內只有一個指令，就可以和 `if` 一樣省略 `{ }`。

一般形式如下。

```
case 式
{
  when 値1
  {
    // 値1の場合
  }
  when 値2, 値3
  {
    // 値2または値3の場合
  }
  others
  {
    // どれにもマッチしない場合
  }
}
```

`when` 和 `others` 要寫在接續於 `case 式` 的 `{ }` 內。如果在 `case 式` 後面沒有 `{`，而是直接接著寫 `when`，載入時就會發生錯誤（E0051 `case`に続く`{`がありません）。也可以像 `case 式 {` 一樣，把 `{` 寫在同一行。

### switch 語法

`{ }` 內的候選輸出會隨機選出；使用 `switch` 時，則可以依位置指定要選擇的候選項目。

```
request
{
    switch id {
        "idは0である。"
        "idは1である。"
        {
            "idは2である。"
            "idはtwoである。"
        }
        "idは3である。"
    }
}
```

輸出的字串由變數 `id` 的值決定。位置從 0 開始計算。當 `id` 為 2 時，會輸出 `"idは2である。"` 或 `"idはtwoである。"`。在這個內含的 `{ }` 部分中，會隨機選擇。

如果 `{ }` 內沒有對應於 `switch` 所評估值的候選項目，就會輸出空字串。例如，在上面的範例中，如果 `id` 是 100，就會輸出空字串。

`{ }` 中的候選項目每行寫一個。`switch 1 { "a" "b" "c" }`（將各候選項目分行書寫）會得到 `"b"`。

也可以依候選項目的數量排列多個 `{ }`，讓每個區塊依位置互相對應。此時會從位置相對應的區塊中隨機選出候選項目。

```
switch _n
{
  "ゼロ番目"
}
{
  "一番目"
}
```

如果 `switch` 內有輸出確定子（`--`），就會選擇各區塊中位於相應位置的候選項目。

```
request
{
    switch 1 {
        "かわいい"
        "天才"
        "サル"
        --
        "とは言い難い"
        --
        "ですね。"
        "かもしれません。"
    }
}
```

`request` 的輸出會是 `"天才かもしれません。"`。請注意，中間的區塊在指定位置沒有候選項目，因此輸出會是空字串（[函式](02-functions.md#出力確定子)）。

## 迴圈結構

共有 `while`、`for`、`foreach` 三種迴圈結構。

可以在[基礎設定檔的 `looplimit`](01-basic-settings.md#looplimit-count) 中設定迴圈次數上限。如果上限不足，請調整設定。預設值為 1000000 次（Tc574-10 / Tc606-4 以後；在此之前為 10000 次）。達到上限時會呼叫 [shiori.OnLoopLimit](../system/shiori-OnLoopLimit.md)(函式名稱, 行)。

### while 迴圈

只要 `while` 評估的運算式為真，就會重複處理 `{ }` 內的內容。條件運算式可以加上括號，也可以不加（`while (_i < 3)` 和 `while _i < 3` 的動作相同）。

```
while 条件式
{
  // 処理
}
```

```
request
{
    _i = 1
    _j = 0
    while _i < 11 {
        _j += _i
        _i++
    }

    "1から10をすべて足すと%(_j)である。"
}
```

上面的範例簡單說明了 `while` 的功能。以下範例會產生 10 個不同的字串。`request` 的輸出會是回報 1～10 中某個數值平方根的字串。

```
request
{
    _i = 1
    while _i < 11 {
        "%(_i)の平方根は%(SQRT(_i))である。"
        _i++
    }
}
```

### for 迴圈

`for` 和 `while` 一樣，是先判定的迴圈結構，但優點是可以將初始化運算式、離開判定運算式，以及每次迴圈執行的運算式集中寫在同一處。與 C 語言不同，所有部分都是必填的。不能使用 `for ( ; ; )` 這類無限迴圈。

```
for 初期化 ; 条件 ; インクリメント
{
  // 処理
}
```

以下是將前面 `while` 範例中計算平方根的程式改寫為 `for` 的版本。

```
request
{
    for _i = 1; _i < 11; _i++ {
        "%(_i)の平方根は%(SQRT(_i))である。"
    }
}
```

`_i = 1` 會在迴圈開始前執行。`_i < 11` 是迴圈判定式，只要此式為真，迴圈就會繼續。`_i++` 則是在一次迴圈執行完畢、回到開頭時執行的運算式。

若要建立無限迴圈，可以使用 `for 1;1;1` 等寫法。不過，既然使用 `while 1` 就能達成相同效果，建立無限迴圈時，無論從可讀性或執行速度來看，都應使用 `while`。

Tc603-6 之後，也可以用括號括住整個標頭。`foreach` 也相同。

```
for (_i = 0; _i < 3; _i++) { ... }
foreach (_a; _k, _v) { ... }
```

- 標頭可以分成多行書寫。也可以寫成以 `(` 結尾的 `for (`，或以 `)` 開頭的 `) {`
- 逐一用括號括住各運算式的寫法（`for (_i = 0); (_i < 3); (_i++)`）以及不加括號的寫法，仍可照常使用
- 像 `for (_i = 0; _i < 3); _i++` 這樣在最後一個運算式之前就關閉括號的寫法，仍會照常產生錯誤
- 像 `for (; _i < 3; _i++)` 或 `foreach (_a; )` 這樣，移除括號後會有空白部分的寫法，只會出現 E0027（不會出現後續的連鎖錯誤）

在 Tc603-5 以前，括住整個標頭的括號若分散在不同的運算式中，會造成 E0019 等錯誤。用 `( )` 括住 `for` 和 `foreach` 的條件運算式會產生錯誤，是截至此版本為止的規格。

### foreach 迴圈

依序取出簡易陣列或通用陣列中的各個元素值（也能辨識透過 `SETDELIM` 設定的自訂分隔符號）。

```
foreach 配列 ; 変数
{
  // 変数に要素が格納されて実行
}
```

以下範例會取出簡易陣列中的元素值，將其轉換為數值，並計算總和。

```
request
{
    _str = "1,3,5,7,9"
    _t   = 0
    foreach _str; _i {
        _t += TOINT(_i)
    }
    _t
}
```

在 `foreach` 後面記述處理對象。以上範例指定了簡易陣列 `_str`。接著寫的 `_i` 是用來存放取出之元素值的變數，必須是變數。即使處理對象變數的分隔符號已透過 [SETDELIM](../functions/SETDELIM.md) 變更，`foreach` 也能辨識該分隔符號並正常運作。

`foreach` 也能處理通用陣列。

```
request
{
    _sent = ("I", "am", 31, "years", "old.")
    _t   = ""
    foreach _sent; _i {
        _t += (_i + " ")
    }
    _t
}
```

`request` 會輸出 `"I am 31 years old. "`。

在 `foreach` 迴圈中，可以改寫作為元素取出對象的簡易陣列或通用陣列。即使如此，列舉的對象仍是改寫前的資料。

Tc600-3 之後，也可以用 `foreach` 走訪雜湊。變數會依鍵的順序存入值。如果值是陣列或雜湊，變數也會是陣列或雜湊。

#### 雙變數 foreach（Tc600-3 之後）

以逗號分隔並寫入兩個變數時，第一個變數會存入鍵，第二個變數會存入值。陣列和簡易陣列也能使用；此時第一個變數會存入從 0 開始的索引（整數）。

```
foreach 配列またはハッシュ ; キー変数, 値変数
{
  // 処理
}
```

```
_h = IHASH("a", 1, "b", 2)
foreach _h ; _k, _v { _s += _k + '=' + _v + ' ' }   // "a=1 b=2 "
foreach ("p", "q") ; _i, _v { ... }                  // _i = 0, 1
foreach "x,y" ; _i, _v { ... }                       // 簡易配列も同じ
```

區域變數和全域變數都可以用作變數。變數有三個以上（`_a, _b, _c`），或是寫入非變數的內容（`_k, 1`、`_a + _b`）時，會發生錯誤 E0043。

### break

迴圈中出現 `break` 時，會跳出目前執行中的最內層迴圈。

```
request
{
    _j = 0
    for _i = 0; _i < 100; _i++ {
        _j = _i*_i
        if  _j >= 100
            break
    }
    _i - 1
}
```

在以上範例中，`for` 會嘗試執行迴圈，直到初始值為 0 的 `_i` 達到 100 為止。不過，迴圈內設有 `break`，當「`_i` 的平方結果大於或等於 100」時就會跳出迴圈。因此，實際上迴圈會在 `_i` = 10 時結束。`request` 會傳回 `_i` 減去 1 的值，因此這個函式會求出平方不超過 100 的最大整數（9）。

### continue

迴圈中出現 `continue` 時，會從該處立即返回迴圈開頭，並進入下一次迴圈反覆。

```
request
{
    _j = ""
    for _i = 0; _i < 3; _i++
    {
        _j += "go "
        if  _i > 0
            continue
        _j += "ahead "
    }
    _j
}
```

`_i` 會依序變成 0、1、2，但在 1 和 2 時會執行 `continue`，因此不會執行將 `"ahead "` 加到 `_j` 的運算式。所以 `request` 的輸出會是 `"go ahead go go "`。

## 函式的傳回值

### return

出現 `return` 時，該函式會立即結束執行。函式的輸出會從截至此時累積的候選值中選出。

```
to_rad
{
    if GETTYPE(_argv[0]) == 3 {
        -1
        return
    }
    _argv[0]*2.0*3.14/360.0
}
```

函式 `to_rad` 會將角度從度數轉換為弧度。如果引數是字串，程式會透過 `if` 判定發現這種情況，並傳回 -1。執行到 `return` 時，輸出候選值只有 -1，因此會輸出此值。

### 帶引數的 return（Tc573-1 以後）

可使用 `return 運算式` 的形式明確指定傳回值。引數不只能寫常數，也可以寫數學運算式。

```
to_rad
{
    if GETTYPE(_argv[0]) == 3 {
        return -1
    }
    return _argv[0]*2.0*3.14/360.0
}
```

帶引數的 `return` 會**捨棄所有**截至當時累積的候選值，並以指定的值取代。下例的傳回值必定是 `"D"`，`"A"` `"B"` `"C"` 都會被捨棄。

```
test_func
{
    "A"
    "B"
    "C"
    return "D"
}
```
