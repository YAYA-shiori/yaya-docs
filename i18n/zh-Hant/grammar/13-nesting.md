# 值的巢狀結構與多維指派（Tc600-3 以後）

Tc600-3 以後，可以將陣列或雜湊放入陣列元素、雜湊的值或雜湊的鍵中（**巢狀結構**）。要存取巢狀結構的內層，請連續寫出 `[ ]`。直接指派值給元素的元素，稱為**多維指派**。

在 500 系列中，陣列元素只能是純量，`a[x][y] = v` 會在讀取時發生錯誤 E0029。從 500 系列變更的內容，請參閱[600 的變更](../other/changes-600.md)。

關於雜湊本身，請參閱[雜湊](12-hash.md)。

## 建立巢狀結構

### 放入雜湊的值中

只要指派給雜湊元素，陣列或雜湊就會直接成為其值。

```
_h = IHASH()
_h["list"] = (1, 2, 3)        // 値に配列
_h["sub"] = IHASH("x", 1)     // 値にハッシュ
```

在 [IHASH](../functions/IHASH.md) 的引數中寫入陣列時，會和其他函式一樣展開。`IHASH("list", (1, 2, 3))` 會變成與 `IHASH("list", 1, 2, 3)` 相同，不會將陣列放入值中。若要讓值成為陣列，請像上面那樣事後指派。雜湊不會展開，因此可以寫成 `IHASH("sub", IHASH("x", 1))`。

### 將雜湊放入陣列元素

雜湊不會因為 `,` 運算子或指派給元素而展開，而是會成為一個元素。

```
_h = IHASH("x", 1)
_a = (0, _h, 2)     // 要素数 3。_a[1] はハッシュ
_a[2] = _h          // 同上
_a ,= _h            // 末尾に追加
```

### 將陣列放入陣列元素

沒有可將新陣列放入陣列中的語法。無論是 `,` 運算子、`,=`，或指派給元素（`_a[1] = (8, 9)`），右側的陣列都會**展開後插入**（與 500 系相同）。

```
_a = (1, 2)
_a[1] = (8, 9)      // 1,8,9 （要素数 3）
_a[1] = IARRAY()    // 1,9 （空の配列を差し込むと要素が消える）
```

但是，當指派目標元素原本已是陣列或雜湊時，不會展開，而是整個取代（Tc603-1 以後。[整個改寫內層陣列或雜湊](#内側の配列やハッシュを丸ごと書き換える)）。

陣列中含有陣列的值會由下列函式傳回。

- [HASH_VALUES](../functions/HASH_VALUES.md)：傳入值為陣列的雜湊時，會傳回一個將該陣列作為單一元素包含其中的陣列
- [PARSEJSON](../functions/PARSEJSON.md) / [PARSEYAML](../functions/PARSEYAML.md) / [PARSETOML](../functions/PARSETOML.md) / [PARSEXML](../functions/PARSEXML.md)，以及從檔案讀取的 [FREADJSON](../functions/FREADJSON.md) 等函式
- [RESTOREVAR](../functions/RESTOREVAR.md)：還原以巢狀形式儲存的變數

```
_v = PARSEJSON('[[1,2,3],[4]]')   // 要素数 2。_v[0] は配列 (1,2,3)
```

如此取得的陣列中所含的陣列，也能透過多維指派改寫（Tc602-7 以後。[各中間值的動作](#途中の値ごとの動作)）。

### 逐步組建

內層雜湊不會自動建立。請先使用 [IHASH](../functions/IHASH.md) 建立中間的雜湊，再指派值到其中。

```
_m = IHASH()
_m["a"] = IHASH()
_m["a"]["b"] = 1
_m["a"]["list"] = IARRAY()
_m["a"]["list"] ,= "p"
_m["a"]["list"] ,= "q"
DUMPJSON(_m)   // {"a":{"b":1,"list":["p","q"]}}
```

若未建立中間的雜湊就寫成 `_m["c"]["d"] = 1`，則 `_m["c"]` 會變成陣列 `(1)`，而非雜湊（[各種中間值的行為](#途中の値ごとの動作)）。

## 讀取

連續寫入 `[ ]` 時，會依序將第二個 `[ ]` 套用至第一個 `[ ]` 的結果，再將第三個套用至該結果……以此類推。

```
_h = IHASH()
_h["list"] = (1, 2, 3)
_h["sub"] = IHASH("x", 1)
_a = (0, _h, 2)

_h["sub"]["x"]      // 1
_h["list"][1]       // 2
_a[1]["sub"]["x"]   // 1
_a[1]["list"]       // (1,2,3) そのものが返る
```

每個 `[ ]` 會根據當下值的型別，以如下方式運作。在任何一個步驟中，若沒有符合條件的元素，就會像未定義的變數一樣變成 VOID，後續的 `[ ]` 也會是 VOID（不會發生錯誤。[超出範圍的元素](05-arrays.md#範囲外の要素)）。

| 值 | `[x]` 的結果 |
|---|---|
| 陣列 | 第 x 個元素。若元素是陣列或雜湊，則原樣傳回 |
| 雜湊 | 鍵 x 的值（[鍵的比對](12-hash.md#キーの一致)） |
| 字串 | 將字串視為簡易陣列，傳回第 x 個元素 |
| 數值 | 若 x 為 0，則傳回該值；否則為 VOID |
| VOID（例如未定義的變數） | VOID |

截至 Tc602-13，超出陣列範圍、雜湊中不存在的鍵，以及對 VOID 使用 `[ ]` 時，結果都是空字串（字串和數值超出範圍時原本就會是 VOID）。

也可以使用範圍指定。陣列的範圍指定 `[a, b]` 會傳回陣列，其中包含的巢狀元素會原樣保留。若超出範圍，則會傳回空陣列。雜湊的範圍指定會傳回空字串。

```
_v = PARSEJSON('[[1,2],[3,4],[5,6]]')
_v[0, 1]     // 要素数 2 の配列。どちらの要素も配列のまま
```

### 簡易陣列的分隔符

透過 [SETDELIM](../functions/SETDELIM.md) 設定給變數的分隔符，只會作用於直接附加在該變數上的第一層 `[ ]`。將巢狀結構中的字串讀取為簡易陣列時，必須在第二層以後的 `[ ]` 指定分隔符。

```
_s = "a|b"
SETDELIM(_s, "|")
_t = (_s, "c")
_t[0][1]         // VOID （2段目は "," で区切られるので範囲外）
_t[0][1, "|"]    // "b"
```

### 嵌入字串

在字串中也可以連續書寫 `[ ]`。

```
"値は %_h['sub']['x'] です"      // 値は 1 です
"値は %(_h['list'][1]) です"     // 値は 2 です
```

嵌入巢狀陣列或雜湊本身時，會得到[字串化](#文字列化と保存)後的結果。

## 函式引數與 `,` 運算子

函式引數與 `,` 運算子只會展開**最外層的陣列**，其中的陣列或雜湊不會展開，而是保留為單一元素。即使雜湊位於最外層，也不會展開。

```
_v = PARSEJSON('[[1,2,3],[4]]')

func(_v)        // _argc は 2。_argv[0] は配列 (1,2,3)
func(_v[0])     // _argc は 3。_argv は 1,2,3
func(_v, 9)     // _argc は 3。_argv[0] は配列 (1,2,3)
_c = (_v, 9)    // 要素数 3。_c[0] は配列 (1,2,3)

ARRAYSIZE(_v)      // 2
ARRAYSIZE(_v[0])   // 3
```

將巢狀陣列傳給函式時，最外層的陣列會成為 `_argv` 本身。接收端沒有辦法區分「單一陣列引數」和「多個引數」，因此將巢狀陣列傳給函式時，建議用雜湊包住，或逐一傳遞陣列元素。

將只有一個元素的陣列傳給 [GETTYPE](../functions/GETTYPE.md) 時，會傳回該元素的型別，而不是陣列型別（與 500 系相同）。在上述範例中，`GETTYPE(_v[1])` 會傳回 1，而不是 4。

## foreach

也可以用 foreach 逐一處理巢狀陣列或雜湊。迴圈變數會直接取得元素，因此若元素是陣列或雜湊，就可以再用 foreach 逐一處理，或使用 `[ ]` 讀取。

```
_h = PARSEJSON('{"a":{"x":1,"y":2},"b":{"x":3}}')
foreach _h ; _k, _sub {
  foreach _sub ; _k2, _v {
    // _k/_k2 = _v の順に a/x=1, a/y=2, b/x=3
  }
}

foreach _h["a"] ; _k, _v { ... }   // 内側だけを回す
```

雙變數 foreach 請參閱[雜湊](12-hash.md#foreach)與[流程控制](07-flow-control.md#foreach-ループ)。

## 值的複製

指派或傳遞引數時會複製值。包括巢狀結構在內，來源與目的地彼此不會互相影響。

```
_h = IHASH("a", 1)
_h["self"] = _h
_h["self"]["a"] = 2
_h["a"]             // 1 のまま
```

即使取出內層的值並加以修改，原本的值也不會改變。若要變更原本的值，請重新指派修改後的值，或使用多維指派。

```
_sub = _h["self"]
_sub["a"] = 3        // _h["self"]["a"] は 2 のまま
_h["self"] = _sub    // これで _h["self"]["a"] が 3 になる
```

## 比較

陣列之間、雜湊之間的 `==` 會比較其內容。巢狀結構中的值也會依相同規則遞迴比較。

- 陣列之間：元素數量相同，且各元素依序相等時為真
- 雜湊之間：元素數量、鍵與值全部相同時為真（[作為值時的行為](12-hash.md#値としての振る舞い)）

```
PARSEJSON('{"a":[1,2]}') == PARSEJSON('{"a":[1,2]}')   // 1
```

使用 [ASEARCH](../functions/ASEARCH.md) 搜尋元素為雜湊的陣列時，也會依相同規則比較。不過，若將陣列傳給要搜尋的值，陣列會展開為引數，因此無法搜尋陣列本身。

[ASORT](../functions/ASORT.md) 會將元素中的陣列或雜湊轉換為字串後排序（在 `int` / `double` 中視為 0）（[元素為陣列或雜湊時](../functions/ASORT.md#要素が配列やハッシュのときtc600-3以降)）。

## 多維指派

可以直接指派值給元素中的元素。除了 `=` 之外，`+=`、`,=` 等所有指派運算子也都可以使用。

```
_h["sub"]["x"] = 5
_h["list"][0] += 10
_h["list"] ,= 4               // 内側の配列の末尾に追加
_a[1]["sub"]["y"] = "new"
```

右側的值會與一維指派相同，放入最後一個 `[ ]` 的位置。因此，若該位置的元素是純量，右側的陣列就會展開後插入。若要整個替換內層陣列，請指派到前一層。

```
_h["list"] = (1, 2, 3)
_h["list"][0] = (7, 8)    // _h["list"] は 7,8,2,3
_h["list"] = (7, 8)       // _h["list"] を (7,8) に置き換える
```

範圍指定指派（`_h["list"][0, 1] = "R"`）也可以和一維指派一樣使用。

### 整個改寫內層陣列或雜湊

在非範圍指定的指派中，若目的元素目前是**陣列或雜湊**，右側的值不會展開，而是直接替換整個元素（Tc603-1 以後）。對陣列中的陣列，也可以用與指派到前一層相同的寫法進行替換、新增或逐一計算元素。

```
_v = PARSEJSON('[[1,2],[3,4]]')
_v[0] = (7, 8, 9)     // _v は (7,8,9),(3,4)   丸ごと置き換える
_v[0] ,= 5            // _v は (7,8,9,5),(3,4) 内側の末尾に追加する
_v[0] += 1            // _v は (8,9,10,6),(3,4) 内側の要素ごとに計算する
_v[0] = _v[0]         // 変わらない
_v[0] = IARRAY        // _v は (),(3,4)        空の配列に置き換える（要素は消えない）
_v[0, 0] = IARRAY     // _v は (3,4)           範囲指定なら展開して差し込む（要素を消す）
```

- 目的元素是純量或超出範圍（尚不存在）時，和以往相同，右側的陣列會展開後插入（例如插入 `_a[1] = (8, 9)`，以及刪除 `_a[1] = IARRAY`）
- 範圍指定指派不論元素型別為何，都會展開後插入（與 Python 的切片指派相同）。若要刪除內層陣列本身，請寫成 `_v[0, 0] = IARRAY`
- 根節點是雜湊時（`_h["list"] = ...`），原本就會整個替換
- 500 系沒有巢狀陣列，因此 500 系辭典的行為不會改變

截至 Tc602-13，根節點為陣列時，內層陣列會展開，導致巢狀結構崩解（`_v[0] = _v[0]` 會使 `_v` 變成 `1`、`2`、`(3,4)` 共 3 個元素；`_v[0] ,= 5` 會使其變成 `1`、`2`、`5`、`(3,4)` 共 4 個元素）。

### 各中間值的行為

多維指派會從最後一層往根變數的方向，改寫各層的值，再將其重新放回前一層。各層值的型別不同，行為如下。

| 中間值 | 行為 |
|---|---|
| 雜湊 | 新增或覆寫鍵的值 |
| 陣列 | 改寫元素。若超出範圍，會以 VOID 補足缺少的部分，再追加到末尾 |
| 字串 | 以簡易陣列的方式改寫 |
| 數值 | 轉換為陣列後改寫。第 0 個元素會是 VOID，原本的數值會遺失 |
| 不存在（超出範圍・沒有鍵） | 與未定義的變數相同，建立通用陣列後改寫 |

```
_a = ("p,q", 1)
_a[0][1] = "Q"        // _a[0] は "p,Q"

_h = IHASH("l", (1, 2))
_h["l"][4] = 9        // _h["l"] は 1,2,VOID,VOID,9

_n = (1, 2.5)
_n[1][2] = 9          // _n[1] は配列 (VOID,VOID,9)

_e = IHASH()
_e["n"]["x"] = 5      // _e["n"] は配列 (5) （ハッシュは作られない）
_e["m"][2] = 5        // _e["m"] は配列 (VOID,VOID,5)
```

`_e["n"]["x"] = 5` 會使 `_e["n"]` 成為 `(5)`，這是因為將鍵 `"x"` 解讀為陣列索引時，會得到第 0 個元素。結果與對未定義的變數執行 `_x["x"] = 5` 相同。

截至 Tc602-13，不存在的層會以空字串的簡易陣列方式改寫，因此 `_e["n"]` 會是字串 `"5"`，而 `_e["m"]` 會是字串 `",,5"`。

將改寫後的值放回前一層時，即使該值是陣列，也不會展開，而是作為單一元素替換。只有最後一層會展開右側的陣列，因此陣列中的陣列也能維持巢狀結構進行改寫。

```
_v = PARSEJSON('[[1,2],[3,4]]')
_v[0][0] = "A"        // _v は ("A",2),(3,4)
_v[1][0] = (7, 8)     // _v は ("A",2),(7,8,4)
```

不過，若中間層是範圍指定（`_v[0, 1][0] = 9`），會先改寫取出的範圍陣列，再展開後放回原範圍。

截至 Tc602-6，對陣列中的陣列進行多維指派時，改寫後的內層陣列會展開並放入外層陣列，導致巢狀結構崩解（以上述 `_v[0][0] = "A"` 為例，`_v` 會變成 `"A"`、`2`、`(3,4)` 共 3 個元素）。中間值為數值時，建立的陣列也會展開至外層。參照傳遞（`&_v[0][0]`）的回寫也相同。

### 指派的根部

指派的根部必須是變數。`(式)[0] = 1` 或 `func()[0] = 1` 等寫法會造成錯誤 E0029。

### 參照傳遞

使用[回饋運算子](04-arithmetic.md#フィードバック演算子)（參照傳遞）時，也可以傳遞元素的元素（Tc600-4 以後）。在 `func(&_h["sub"]["x"])` 中改寫 `_argv[0]`，`_h["sub"]["x"]` 就會改變。在 Tc600-3 中，前一個維度會被忽略，並寫入 `_h["x"]`。

## 字串化與儲存

將巢狀值轉換為字串時（[TOSTR](../functions/TOSTR.md)、與字串串接、嵌入等），內側的內容也會直接以 `,` 或 `=` 連接，因此會無法分辨內側內容的範圍。

```
_h = IHASH()
_h["l"] = (1, 2)
_h["m"] = IHASH("x", 1)
TOSTR(_h)    // "l=1,2,m=x=1"
```

若要在保留巢狀結構的情況下處理，請使用以下方法。

| 目的 | 方法 |
|---|---|
| 將變數儲存至檔案並還原 | [SAVEVAR](../functions/SAVEVAR.md) / [RESTOREVAR](../functions/RESTOREVAR.md)。巢狀結構會以 `IARRAY{...}` / `IHASH{...}` 的形式儲存（[儲存格式](../functions/SAVEVAR.md#保存形式)） |
| 確認內容 | [DUMPVAR](../functions/DUMPVAR.md)（Tc600-4 以後）。巢狀結構會以 `(array)[ ... ]` / `(hash){ ... }` 顯示。[LOGGING](../functions/LOGGING.md)（Tc602-8 以後）也會將巢狀陣列以 `( )`、雜湊以 `{ }` 括住後輸出 |
| 轉換為字串以傳遞 | [DUMPJSON](../functions/DUMPJSON.md) 和 [PARSEJSON](../functions/PARSEJSON.md)。但 JSON 無法表示的差異（整數鍵和字串鍵、VOID 和空字串等）會消失。若要保留這些差異，請使用 [SERIALIZEVAR](../functions/SERIALIZEVAR.md) 和 [DESERIALIZEVAR](../functions/DESERIALIZEVAR.md)（Tc607-3 以後）。這會產生與存檔檔案相同格式的字串 |

## 限制

- 以陣列作為鍵的雜湊，因為 `h[キー]` 的序數第 1 個元素會成為鍵，所以無法以陣列作為鍵來查找（可以透過 foreach 或 [HASH_KEYS](../functions/HASH_KEYS.md) 取出）。若以雜湊作為鍵，則可以使用 `h[キー]` 查找
