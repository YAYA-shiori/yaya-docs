# 陣列

## 概要

運算子 `[ ]` 是用來存取陣列元素的運算子。陣列分為 2 種：一種是將字串分割後視為陣列的**簡易陣列**，另一種是以逗號分隔列舉元素的**通用陣列**。

## 簡易陣列

將字串中的逗號解讀為分隔符（分隔字元），並以陣列的方式處理的功能。

```
request
{
    _a = "this,is,a,pen"
    _a[1]
}
```

`request` 會輸出 `"is"`。`[ ]` 運算子處理的對象不一定要是變數，也可以是常值或函式的傳回值。上面的範例也可以寫成下列形式，效果相同。

```
request
{
    "this,is,a,pen"[1]
}
```

### 自訂分隔符

在索引後方以逗號分隔指定分隔符，就可以使用其他字串而非逗號來分隔簡易陣列的元素。

```
request
{
    "This is a island."[2,"is"]
}
```

由於是以 `"is"` 分隔，字串會如下拆解。

| 索引 | 元素 |
|------|------|
| `[0]` | `"Th"` |
| `[1]` | `" "` |
| `[2]` | `" a "` |
| `[3]` | `"land."` |

因此 `request` 會傳回 `" a "`。

### 類似多維陣列的存取

善用分隔符指定，就能取出類似多維陣列的值。

```
request
{
    _ar = "taro|male,ayame|female,hotaru|female"

    _ar[2][1,"|"]
}
```

`_ar[2]` 會是 `"hotaru|female"`。接著將 `|` 解讀為分隔符並取出 `[1]`，結果會是 `"female"`。如此一來，只要在各層套用不重複的分隔符，就能輕易取出任意位置的值。

關於指定超出範圍的索引時會輸出什麼，請參閱[超出範圍的元素](#範囲外の要素)。

### 使用簡易陣列和通用陣列建立多維陣列

如果想以更直接的方式處理多維陣列，

```
Food = "うどん,ラーメン,おにぎり"
Color = "赤,青,黄"
```

先宣告簡易陣列，再使用通用陣列

```
Word = (Food, Color)
```

如此一來，就能透過 `Word[0][0]` 取得「うどん」，透過 `Word[1][2]` 取得「黄」。

### 指派

接下來介紹僅限變數使用的功能。可以指派值給元素。

```
request
{
    _a = "this,is,a,pen"
    _a[3] = "eraser"
    _a
}
```

這會將 `"pen"` 改寫為 `"eraser"`，`request` 的執行結果會是 `"this,is,a,eraser"`。即使指定分隔符也能正常運作。

```
request
{
    _s = "This is a island."
    _s[2,"is"] = " beautiful "
    _s
}
```

`request` 會輸出 `"This is beautiful island."`。

連接 `[ ]` 運算子來存取類似多維陣列的值時，可以進行指派的功能從 Tc600-3 之後的版本開始支援（[值的巢狀結構與多維指派](13-nesting.md)）。在更早的版本中，只能對一維陣列進行指派，以下操作會發生錯誤。

```
request
{
    _ar = "taro|male,ayame|female,hotaru|female"

    _ar[1][1,"|"] = "male"
}
```

即使指派至超出目前元素數量的位置也沒有問題。分隔符會自動新增，並擴充元素數量。

```
request
{
    _m = "fuji/asama/tanigawa"
    _m[5,"/"] = "daisen"
    _m
}
```

`request` 會輸出 `"fuji/asama/tanigawa///daisen"`。

### SETDELIM

使用 [SETDELIM](../functions/SETDELIM.md) 函式，可以將「預設分隔符」從逗號改為其他字串。以下示範使用 `SETDELIM` 改寫前面提過的範例。

```
request
{
    _m = "fuji/asama/tanigawa"
    SETDELIM(_m, "/")
    _m[5] = "daisen"
    _m
}
```

使用 `SETDELIM` 後，就能直接寫成 `_m[5]`。連接 `[ ]` 運算子來存取類似多維陣列的值時，`SETDELIM` 只會對第一個（第一維的）`[ ]` 生效。

## 通用陣列

通用陣列是一種可以混合儲存各種類型值的陣列結構。一般的存取速度比簡易陣列更快。

### 初始化

```
i = (100,"test",-1.5)
```

以逗號列舉元素。進行指派時，必須像上面那樣用 `( )` 括住一組元素。逗號運算子的優先順序低於指派，因此如果沒有括號，

```
i = 100,"test",-1.5
```

會被解讀為 `(i = 100),"test",-1.5`，只有 100 會存入 `i`。

若要以空陣列初始化，請使用名為 [IARRAY](../functions/IARRAY.md) 的函式。`IARRAY` 是傳回「空的通用陣列」的函式。

```
i = IARRAY
```

如果想在初始化時只指派一個元素，需要稍作處理。例如，單純寫成 `i = 100` 時，指派的是一般數值，而非陣列。請如下所示撰寫。

```
i = (IARRAY,100)
```

### 新增元素

```
i = (i,"add")
```

如此一來，`"add"` 會新增至陣列尾端。也可以新增陣列。

```
i = (i,("add",123,0.0))
```

就像 `a = a + 1` 可以簡寫為 `a += 1` 一樣，上面的範例也可以寫成下列形式。

```
i ,= ("add",123,0.0)
```

也可以用相同的格式插入至開頭。

```
i = ("first",i)
```

也可以插入至中間。

```
i = (100,200,300,400,500,600)
i[2] ,= "insertion"
```

`i` 會變成 `(100,200,300,"insertion",400,500,600)`。請注意，插入位置會是 `[3]`，而不是 `[2]`。若要插入至 `i[2]`，請如下所示撰寫。

```
i[2] = ("insertion",i[2])
```

### 刪除元素

將 `IARRAY` 指派給要刪除的元素。

```
i = (100,200,300,400,500,600)
i[2] = IARRAY
```

300 會被刪除，`i` 會變成 `(100,200,400,500,600)`。

### 更新值

可以直接指派值給元素。即使指派至超出目前元素數量的位置也沒有問題，元素數量會擴充至所需的數量。

### 取出值

與一般變數相同，只要指定索引即可直接輸出。關於指定超出範圍的索引時會輸出什麼，請參閱[超出範圍的元素](#範囲外の要素)。

```
i = (100,200,300,400,500,600)
i[4]
```

會輸出 500。`[ ]` 運算子處理的對象不必是變數，也可以是立即值或函式的傳回值。

```
(100,200,300,400,500,600)[4]
```

會輸出 500。也可以直接將通用陣列作為函式的輸出。

```
request
{
    river[2]
}

river
{
    ("tenryu","bandou-tarou","ishikari","shimanto")
}
```

`request` 會輸出 `"ishikari"`。

### 陣列中不能寫入陣列

寫在 `( )` 中的 `( )` 不會被視為次要陣列，而是會展開並直接串接。

```
(100,200,(300,400),500,600)
```

即使這樣寫，最後也會串接成以下內容。

```
(100,200,300,400,500,600)
```

若要將陣列或雜湊放入元素中，請參閱下文的「巢狀結構與多維指派」。

### 運算

可以照常逐一對元素進行運算。

通用陣列與單一值之間的運算會有特殊行為：「對所有元素套用單一值進行運算」。

```
pref = ("gunnma","ohsaka","hokkaido")
pref += "-ken"
```

`pref` 會變成 `"gunnma-ken","ohsaka-ken","hokkaido-ken"`。

```
answer = (2*(1,2,3))[1]
```

`answer` 會被指派為 4，因為 `2*(1,2,3)` 的計算結果會是 `(2,4,6)`。

通用陣列彼此運算時，會輸出所有可進行運算的組合。

```
pref1 = ("gunma","osaka","hokkai")
pref2 = ("-ken","-fu","-do")
pref3 = pref1 + pref2
```

`pref3` 會變成 `"gunma-ken","gunma-fu","gunma-do","osaka-ken","osaka-fu","osaka-do","hokkai-ken","hokkai-fu","hokkai-do"`。陣列中若包含數值（整數、實數），也可以進行減法、除法、乘法等其他運算。

### 比較元素

使用 `==` 比較陣列時，會逐一比較元素。Tc600-3 以後，即使元素**兩者都是 VOID**，也會視為相等（在此之前會視為假）。

### 函式的引數

在 YAYA 中，函式的引數是通用陣列。`_argv` 的內容是將呼叫端傳入的引數直接指派而成的通用陣列。也就是說，

```
func(1, 2, "test")
```

這樣呼叫函式，也可以寫成：

```
_i = (1,2,"test")
func(_i)
```

這種寫法非常取巧，但能如預期運作。請注意，改寫後的指令碼中，引數數量仍是 3 個，而不是 1 個。

善用這個結構，就能輕鬆將可變長度的引數傳遞給其他函式。

```
request
{
    total(1,2,3,4,5,6)
}

total
{
    calc_total(_argv)
}

calc_total
{
    _answer = 0
    foreach _argv; _val { _answer += _val }
    _answer
}
```

`total` 本身不做任何事，而是將所有引數原樣傳遞給 `calc_total`。這個例子只是單純地傳遞引數，當然也可以視需要先加工再傳遞。

若引數的指定方式較複雜，請務必留意。

```
_i = (1,2,"test")
func("sky", _i, "sun")
```

上面的呼叫等同於下列寫法。請記得，通用陣列無法多維化（會展開）。

```
func("sky", 1, 2, "test", "sun")
```

### 指定分隔符／取得數量

```
_i = (2,"is")
"This is a island."[_i]
```

簡易陣列中用來指定分隔符的部分也是通用陣列，因此也可以像上面那樣寫。這等同於以下寫法。

```
"This is a island."[2,"is"]
```

## 巢狀結構與多維指派（Tc600-3 以後）

可以將雜湊放入陣列元素，也可以將陣列放入雜湊的值中。讀取時可連續寫出 `[ ]`，例如 `_a[1]["x"]`；指派時則寫成 `_a[1]["x"] = 5`。

```
_a = (0, IHASH("x", 1), 2)
_a[1]["x"]        // 1
_a[1]["x"] = 5    // 多次元代入
```

進行多維指派時，若中間的元素是字串，會將它改寫為簡易陣列：

```
_a = ("p,q", "r")
_a[0][1] = "Q"    // _a[0] は "p,Q"
```

不過，沒有方法可以將新的通用陣列放入通用陣列中。`,` 運算子和 `_a[1] = (8,9)` 都會展開陣列後插入。只有在指派目標的元素已經是陣列或雜湊時，才會不展開而直接整個取代（Tc603-1 以後。[整個改寫內部的陣列或雜湊](13-nesting.md#内側の配列やハッシュを丸ごと書き換える)）。

詳細請參閱[值的巢狀結構與多維指派](13-nesting.md)。

## 指定範圍

簡易陣列和通用陣列都可以用範圍指定索引。可以取值，也可以指派。範圍以通用陣列指定。例如，`i[a,b]` 表示「`i` 的元素 a～b」。

```
name = ("さくら","せりこ","奈留","まゆら","毒子","美耳")
i = name[1,3]
name[3,4] = "奎子"
j = name
name[0,2] = IARRAY
k = name
```

- `i` 中會儲存 `("せりこ","奈留","まゆら")`
- `j` 會變成 `("さくら","せりこ","奈留","奎子","美耳")`
- `k` 會變成 `("奎子","美耳")`

即使對象是簡易陣列，寫法也相同。

```
name = "さくら,せりこ,奈留,まゆら,毒子,美耳"
i = name[1,3]
name[3,4] = "奎子"
j = name
```

`i` 會變成 `"せりこ,奈留,まゆら"`，`j` 會變成 `"さくら,せりこ,奈留,奎子,美耳"`。

也可以指定分隔符。請緊接在範圍指定之後指定。

```
animal = "くま！うさぎ！ねこ！いぬ！わに"
i = animal[0,2,"！"]
animal[2,4,"！"] = "ぶた"
j = animal
```

`i` 會變成 `"くま！うさぎ！ねこ"`，`j` 會變成 `"くま！うさぎ！ぶた"`。

### 範圍端點的處理方式

- 當 `a > b` 時（`i[3,1]`），會交換 a 和 b，因此範圍會與 `i[1,3]` 相同
- 超出末尾的一端會視為末尾。當 `n = (1,2,3,4)` 時，`n[2,9] = 9` 會將 `n` 改為 `(1,2,9)`
- 負索引會視為「超出末尾的大值」。不會截斷為 0，也不會當作超出範圍而忽略。因此，`n[-2,1]` 的範圍會與 `n[1,末尾]` 相同

```
n = (1,2,3,4)
i = n[-2,1]
n[-2,1] *= 5
```

`i` 會變成 `(2,3,4)`，`n` 會變成 `(1,10,15,20)`。若要從開頭開始計數，請像 `n[0,1]` 一樣使用 0 以上的值。

## 超出範圍的元素

讀取超出範圍的元素時，無論是簡易陣列還是通用陣列，都會和未定義的變數一樣變成 **VOID**（Tc574-8 / Tc603-1 以後）。範圍指定的讀取超出範圍時，會得到空範圍（簡易陣列為空字串，通用陣列為空陣列）。

```
_a = (1, 2)
_a[9]            // VOID
_a[9] == ""      // 1
_a[9] == 0       // 1
_a[9] + 1        // 1 （整数）
GETTYPE(_a[9])   // 0
_a[5, 6]         // 空の配列
"a,b"[5, 6]      // ""
```

- VOID 作為字串時會視為空字串，作為數值時會視為 0。`== ""` 或 `if _a[9]` 的結果，與值為空字串時相同
- 即使在函式的最後一行等處直接寫入超出範圍的元素，也不會成為輸出的候選值（與未定義的變數相同；值為空字串時，空字串會成為候選值）
- 數值加上 `[ ]`（`5[1]`）時，會視為只有一個元素的陣列。第 0 個元素是該數值，其餘元素都是 VOID
- 將值指派給超出末尾的元素時（`_a[9] = 1`），中間會以 VOID 填補。填補數量上限為 16,777,216 個，超過上限的指派（例如 `_a[2000000000] = 1`）會視為記憶體不足，並以 E0100 中斷執行，接著呼叫 `shiori.OnMemoryError`（Tc603-4 以後。在此之前沒有上限，可能會耗盡記憶體）
- 對超出範圍的元素進行複合指派（`_a[9] += 1`）時，也會以 VOID 計算，因此結果會是整數 1（600 系列從 Tc602-10 起；500 系列從 Tc574-8 起）
- 在 Tc574-7 / Tc602-13 以前，通用陣列的超出範圍元素會是空字串，簡易陣列的超出範圍元素則是 VOID，結果會因陣列種類而異。因此 `_a[9] == 0` 為假、`_a[9] + 1` 是字串 `"1"`，而 `GETTYPE(_a[9])` 是 3。簡易陣列的範圍指定超出範圍時會是 VOID，數值的範圍指定超出範圍時也會是 VOID

## 並列輸出

可以在所有運算式／值前面寫上 `parallel`。當輸出候選值是通用陣列時，`parallel` 會將各個元素分別設為輸出候選值。

```
foo0
{
    ("A","B","C")
    "地球"
}

foo1
{
    parallel ("A","B","C")
    "地球"
}
```

`foo0` 的輸出會是 `("A", "B", "C")` 或 `"地球"`。`foo1` 的輸出則會是 `"A"`、`"B"`、`"C"`、`"地球"` 其中之一。

對通用陣列以外的值使用 `parallel` 沒有作用，效果等同於不寫。例如，以下兩種寫法等價。

```
parallel STRLEN("earth")
STRLEN("earth")
```

使用選擇方式 `array` 和 `parallel`，可以互相轉換函式的輸出候選值與通用陣列。這可以應用在各種情境。例如，以下非常簡潔的函式 `cyclic` 會依照記述順序，從通用陣列取出元素值。

```
cyclic : sequential
{
    parallel _argv
}
```

相反地，在所有運算式／值前面寫上 `void`，也可以捨棄計算結果，不將其設為輸出候選值。
