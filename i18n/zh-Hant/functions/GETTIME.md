# GETTIME
**Category:** システム情報

## Signature
```
GETTIME( [ sec [, timezone ] ] )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| sec | （可省略）從 EPOCH（1970年1月1日 00:00:00 UTC）起經過的秒數（整數）。省略時傳回目前的系統時間 |
| timezone | （可省略）要取得日期與時間的時區。省略時使用 OS 的本地時間（[指定時區](#タイムゾーンの指定)） |

## Returns
傳回具有以下結構的通用陣列：

| 索引 | 值 | 詳細說明 |
|------------|---|------|
| 0 | 年 | 西元年 |
| 1 | 月 | 月 |
| 2 | 日 | 日 |
| 3 | 星期 | 0〜6（0=星期日） |
| 4 | 時 | 24 小時制 |
| 5 | 分 | 分 |
| 6 | 秒 | 秒 |
| 7 | 年內經過日數 | 從年初起經過的日數（1月1日為0） |
| 8 | 夏令時間旗標 | 0=標準時間 / 1=夏令時間 |

當 `sec` 超出可處理範圍（約 ±9 億年）時，會發出警告 W0012（[GETLASTERROR](GETLASTERROR.md) 為 12）並傳回 `-1`。

## Description
取得目前的日期與時間資訊。省略 `timezone` 時，會以與 C 語言的 `localtime` 函式相同的方式運作。

指定 `sec` 時，會將該秒數解讀為從 EPOCH 起經過的時間，並傳回相應的日期與時間資訊。可與 GETSECCOUNT 搭配使用，例如計算 10 天後的日期。

本地時間的夏令時間會依照 `sec` 所代表時刻的規則判定（而非判定目前時間是否為夏令時間）。

### 指定時區
`timezone` 可指定下列其中一項。

| 指定 | 意義 |
|------|------|
| 省略、`""`、`"local"` | OS 的本地時間 |
| `"UTC"`、`"GMT"`、`"Z"` | UTC |
| `"+09:00"`、`"+0900"`、`"+09"`、`"-5"` | 相對於 UTC 的固定偏移量（小時・分鐘。東方為正） |
| `"JST"`、`"EST"`、`"EDT"`、`"CST"`、`"CDT"`、`"MST"`、`"MDT"`、`"PST"`、`"PDT"` | 依名稱指定的固定偏移量 |
| 整數 | 相對於 UTC 的固定偏移量（**秒**，東方為正。`32400` 即 `+09:00`）。小於 ±24 小時 |

指定固定偏移量時不會考慮夏令時間，夏令時間旗標（索引 8）一律為 0。無法解讀的指定會發出警告 W0012（GETLASTERROR 為 12），並以本地時間處理。

## Example

目前時間的 `sec` 可透過 [GETSECCOUNT](GETSECCOUNT.md) 取得。善用這個值，就能輕鬆計算「從現在起○天後／前的時間」。

```
//10日後は何月何日？
_array = GETTIME()
"今は%(_array[0])年%(_array[1])月%(_array[2])日　%(_array[4])時%(_array[5])分%(_array[6])秒／"
--
_array = GETTIME(GETSECCOUNT(_array[0],_array[1],_array[2] + 10,0,_array[4],_array[5],_array[6]))
"10日後は%(_array[0])年%(_array[1])月%(_array[2])日　%(_array[4])時%(_array[5])分%(_array[6])秒\n"
```

```
// UTCでの日時
_utc = GETTIME(GETSECCOUNT(), 'UTC')

// 1970/1/1 00:00:00 UTC は、日本時間（+09:00）では 9時
_jst = GETTIME(0, '+09:00')      // 1970,1,1,4,9,0,0,0,0
```

## Compatibility
- YAYA：從初期版本起即可使用
  - Tc542-1 以後：新增年內經過日數（索引 7）與夏令時間旗標（索引 8）
  - Tc606-1 以後：新增 `timezone` 參數
- Tc606-1：修正 Windows 上年內經過日數原先以 1 月 1 日為 1 起算的問題，改為與 `localtime` 相同，從 0 起算。夏令時間旗標，以及夏令時間會因時期而異的時區之時間，現在會依 `sec` 所代表的時刻判定，而非依目前時間判定
- AYA 5.8：僅支援不帶引數的形式
