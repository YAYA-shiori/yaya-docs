# FENUM

**Category:** ファイル操作

## Signature

```
FENUM( path [ , delim ] )
```

## Parameters

| 引數 | 說明 |
|-----------|-------------|
| path | 要列舉的目錄路徑。可指定完整路徑。相對路徑以 DLL 載入位置為基準 |
| delim | 分隔字串（省略時為逗號） |

## Returns

- 成功時：以分隔字串連接檔案名稱與目錄名稱後傳回。目錄名稱前會加上反斜線前綴
- 失敗時：VOID（空）

## Description

列舉指定位置中的檔案名稱與目錄名稱，並以分隔字串連接後傳回。路徑可指定完整路徑。若為相對路徑，則以 DLL 載入時傳入的位置（通常是 DLL 所在位置）為基準。目錄名稱開頭會加上 `\`。

## Compatibility

- YAYA: 自首次釋出起即可使用
- AYA: 5.8 版以後
