# ISGLOBALDEFINE
**Category:** メタ操作・特殊関数

## Signature
```
ISGLOBALDEFINE( define )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| define | 要確認是否以 `#globaldefine` 定義的名稱 |

## Returns
- 1：定義存在
- 0：定義不存在

## Description
確認是否存在以 `#globaldefine` 指示詞定義的名稱。

## Compatibility
- YAYA: Tc562-1 以後
