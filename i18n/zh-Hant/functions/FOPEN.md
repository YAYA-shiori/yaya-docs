# FOPEN

**Category:** ファイル操作

## Signature

```
FOPEN(path, option)
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| path | 檔案名稱。可指定完整路徑。若為相對路徑，則以 DLL 的 load 傳入的位置為基準 |
| option | 指定檔案的開啟方式。指定下方「模式」或「別名」中的字串 |

### 文字存取

| 模式 | 別名 | 動作 | 檔案存在時 | 檔案不存在時 |
|--------|------|------|--------------------|--------------------|
| `"r"` | `"read"` | 讀取文字 | 成功 | 錯誤 |
| `"w"` | `"write"` | 寫入文字 | 將大小設為 0（覆寫） | 新建 |
| `"a"` | `"append"` | 附加寫入文字 | 附加至檔案末尾 | 新建 |

### 二進位存取

| 模式 | 別名 | 動作 | 檔案存在時 | 檔案不存在時 |
|--------|------|------|--------------------|--------------------|
| `"rb"` | `"read_binary"` | 讀取二進位資料 | 成功 | 錯誤 |
| `"wb"` | `"write_binary"` | 寫入二進位資料 | 將大小設為 0（覆寫） | 新建 |
| `"ab"` | `"write_binary_append"` | 附加寫入二進位資料 | 附加至檔案末尾 | 新建 |

### 隨機存取

| 模式 | 別名 | 動作 | 檔案存在時 | 檔案不存在時 |
|--------|------|------|--------------------|--------------------|
| `"r+"` | `"read_random"` | 讀寫文字 | 成功 | 錯誤 |
| `"w+"` | `"write_random"` | 讀寫文字 | 將大小設為 0（覆寫） | 新建 |
| `"a+"` | `"append_random"` | 讀寫文字 | 附加至檔案末尾 | 新建 |
| `"rb+"` | `"read_binary_random"` | 讀寫二進位資料 | 成功 | 錯誤 |
| `"wb+"` | `"write_binary_random"` | 讀寫二進位資料 | 將大小設為 0（覆寫） | 新建 |
| `"ab+"` | `"append_binary_random"` | 讀寫二進位資料 | 附加至檔案末尾 | 新建 |

## Returns

- 1：成功
- 0：失敗
- 2：檔案已開啟

## Description

開啟檔案。

- 讀寫檔案前，必須先使用 `FOPEN` 開啟檔案
- 進行文字存取時，可在執行 `FOPEN` 前執行 [FCHARSET](FCHARSET.md)，變更字元編碼
- 簡言之，這與 C 語言的 `fopen` 相同。YAYA 內部也是以 C 語言的 `fopen` 實作
- 進行文字存取時，讀取前會將 0x0d-0x0a 的序列（CR-LF）轉換為單一的 0x0a。相反地，寫入時會將 0x0a 轉換為 0x0d-0x0a。此外，0x1a 具有 EOF 的特殊意義
- 隨機存取時，可使用 [FSEEK](FSEEK.md) 指定檔案的讀取位置，並使用 [FTELL](FTELL.md) 取得位置

## Compatibility

- YAYA：從首次發布起即可使用（僅限文字存取）
- AYA：版本 5.8 以後（僅限文字存取）
- TC529-2：新增二進位存取與隨機存取
