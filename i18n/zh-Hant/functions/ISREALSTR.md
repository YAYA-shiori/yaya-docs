# ISREALSTR
**Category:** 文字列操作

## Signature
```
ISREALSTR(string)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| string | 要判定的字串 |

## Returns
- 1：可解讀為實數
- 0：無法解讀為實數

## Description
判定給定的字串能否解讀為實數。

## Compatibility
- YAYA: 從初期版本起即可使用
- AYA: 5.8 以後即可使用
