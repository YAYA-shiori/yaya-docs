# GETDELIM
**Category:** 配列操作

## Signature
```
GETDELIM( var )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| var | 要查詢分隔符號的簡易陣列變數 |

## Returns
指定變數所設定的分隔符號字串。

## Description
取得變數所設定分隔符號（簡易陣列的分隔字元）的函式。預設分隔符號為逗號（`,`）。

可用來確認透過 SETDELIM 變更的分隔符號。

## Compatibility
- YAYA：從初期版本起即可使用
- AYA：5.8 版以後
