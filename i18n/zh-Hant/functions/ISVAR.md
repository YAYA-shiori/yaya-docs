# ISVAR
**Category:** 型取得/変換

## Signature
```
ISVAR(string)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| string | 要確認變數是否存在的變數名稱字串 |

## Returns
- 0: 變數不存在
- 1: 全域變數存在
- 2: 區域變數存在

## Description
確認指定名稱的變數是否存在。

## Compatibility
- YAYA: 自初期版本起即可使用
- AYA: 5.8 版以上即可使用
