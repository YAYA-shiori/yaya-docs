# LOG10
**Category:** 数学関数

## Signature
```
LOG10(val)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| val | 要計算常用對數的實數值 |

## Returns
- 成功：val 的常用對數（底數為 10，實數）
- 失敗：0.0

## Description
傳回常用對數（底數為 10）。

## Compatibility
- YAYA：從初始版本起可使用
- AYA：版本 5.8 以後可使用
