# ISINTSTR
**Category:** 文字列操作

## Signature
```
ISINTSTR( string )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| string | 要驗證能否解讀為整數的字串 |

## Returns
- 1：字串可解讀為整數
- 0：字串無法解讀為整數

## Description
驗證指定的字串能否解讀為整數。此函式與 ISREALSTR 相對，可用來區分整數與浮點數的字串表示形式。

## Compatibility
- YAYA: 從初期版本起即可使用
- AYA: 5.8 以後
