# ARRAYDEDUP

**Category:** 配列操作

## Signature

```
ARRAYDEDUP(array)
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| array | 通用陣列 |

## Returns

傳回排除重複元素後的通用陣列。

## Description

被視為相同的元素會保留最前面的項目。結果的排列順序不會沿用原本順序，而是與[雜湊的鍵](../grammar/12-hash.md#並び順)相同。

Tc600-3 以後，元素相等與排列順序的規則改為與雜湊的鍵相同。

- 整數、實數及表示正規形式整數的字串，只要值相同就會視為相同元素（`1`、`1.0`、`"1"` 相同）
- 依數值 < 字串的順序排列
- 陣列或雜湊元素會依內容比較。內容相同的雜湊會合併成一個，內容不同的雜湊則會保留
- VOID 彼此視為相同元素

型別一致的陣列（只有整數、只有實數或只有字串）的結果與之前相同。

## Example

```
ARRAYDEDUP((3, 1, 2, 1))                    // 1,2,3
ARRAYDEDUP((10, "9", 9, "a", 1.0, 1, "1"))  // 1.000000,9,10,a （Tc600-3以降）
```

## Compatibility

- YAYA: Tc568-1 以後
- Tc600-3: 修正混合型別陣列的結果會依排列方式而異的問題，改為依照與雜湊的鍵相同的規則比較
