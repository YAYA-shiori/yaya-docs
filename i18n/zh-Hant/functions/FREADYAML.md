# FREADYAML
**Category:** ファイル操作

## Signature
```
FREADYAML( path [, charset] )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| path | 要讀取的 YAML 檔案路徑（相對於 yaya.dll 的路徑，或絕對路徑） |
| charset | 檔案的字元編碼（可省略）。以字串（`"UTF-8"` `"Shift_JIS"` 等。[字元編碼名稱](../grammar/11-character-encoding.md#文字コードの名前)）或數值指定。省略時使用 UTF-8 |

## Returns
- 成功時：轉換 YAML 後的值（如下方的[值的對應](#値の対応)）
- 失敗時：空（VOID）

## Description
讀取並解析整個 YAML 檔案，轉換為雜湊、陣列等值後傳回。不必先以 [FOPEN](FOPEN.md) 開啟檔案。

YAYA 會自行解析 YAML。支援設定檔等常用範圍（如下方的[支援的寫法](#対応している書き方)），但不完全符合 YAML 規格。

- 忽略開頭的 UTF-8 BOM。換行可以是 CRLF 或 LF
- 空檔案或只有註解的檔案會成為空（VOID），不會發生錯誤

### 支援的寫法

| 寫法 | 範例 |
|--------|----|
| 區塊形式的對應與序列 | `key: value`、`- item`。也可在 `key:` 下方以相同縮排排列 `- item` |
| 流程形式 | `[1, 2]`、`{a: 1, b: 2}`。也支援巢狀結構和跨多行的寫法 |
| 不加引號的字串 | 可跨多行（換行會變成空格，空白行則會變成換行） |
| 加上引號的字串 | `'...'`（以 `''` 表示 `'`）、`"..."`（可使用 `\n` `\t` `\"` `\\` `\x41` `あ` `\U0001F600` 等跳脫字元） |
| 區塊純量 | `\|`（保留換行）、`>`（將換行轉為空格）。也支援指定末尾換行的處理方式 `\|-` `\|+`，以及指定縮排 `\|2` |
| 註解 | 從 `#` 到行尾（在值後方撰寫時，`#` 前必須有空格） |
| 錨點與別名 | 以 `*name` 參照加上 `&name` 的值（複製值） |
| 合併鍵 | 以 `<<: *name` 或 `<<: [*a, *b]` 合併對應。明確指定的鍵，以及較早寫入的鍵具有優先權 |
| 文件分隔符 | 開頭的 `---`（以及前面的 `%YAML` 等指示詞）、結尾的 `...` |
| 標籤 | `!!str`（以及 `!`）會將值設為字串。`!!int` `!!float` `!!bool` `!!null` 即使加上引號也會決定型別。其他標籤則會忽略 |

不支援下列寫法。使用時會產生 W0026。

- 單一檔案包含多份文件（第二個 `---`）
- 複合鍵（以 `? ` 開頭的鍵，或以流程形式撰寫的鍵）
- 使用定位點字元進行縮排（值中可以使用定位點字元）

### 值的對應

型別依照 YAML 1.2 Core Schema 的規則決定。

| YAML | YAYA |
|------|------|
| 對應 | 雜湊。鍵一律為字串 |
| 序列 | 通用陣列（可巢狀包含陣列或雜湊作為元素） |
| 整數（`123` `-4` `0o17` `0x1F`） | 整數。超出十進位整數範圍的值會成為實數 |
| 實數（`1.5` `1e3` `.5` `.inf` `-.inf` `.nan`） | 實數 |
| `true` / `false`（也包括 `True` `TRUE` 等） | 整數 1 / 0 |
| `null` / `~` / 無值 | 空（VOID） |
| 其他值、加上引號的值、區塊純量 | 字串 |

- 與 YAML 1.1 的處理器有以下差異。`yes` `no` `on` `off` 會是字串，`017` 會是十進位的 17，`1_000` 會是字串，`2001-12-14` 這類日期也會是字串
- 不會保留對應中鍵的排列順序，而會依照雜湊鍵的順序排列（請參閱 [HASH_KEYS](HASH_KEYS.md)）。`1` 這類正規形式的整數鍵，可以用 `h[1]` 或 `h["1"]` 取得
- 若同一個鍵出現兩次，會採用後寫入的值
- 巢狀結構過深（超過 256 層），或別名的複製總數超過 100 萬個元素時，會發生錯誤（避免惡意檔案耗盡記憶體）

### 錯誤
| 狀況 | 警告 | [GETLASTERROR](GETLASTERROR.md) |
|------|------|------|
| 沒有引數 | W0008 | 8 |
| path 不是字串 | W0009 | 9 |
| charset 無效 | W0012 / W0009 | 12 / 9 |
| 無法開啟檔案 | W0025 | 25 |
| 無法解析為 YAML，或使用了不支援的寫法 | W0026（也會輸出行號和原因） | 26 |

## Example
config.yaml:
```yaml
# ゴーストの設定
name: さくら
age: 17
height: 158.5
visible: true
memo: ~
tags: [ghost, shell]
talk:
  greeting: |
    こんにちは。
    今日もいい天気ですね。
  random:
    - おはよう
    - こんばんは
defaults: &defaults
  volume: 80
  speed: 2
voice:
  <<: *defaults
  speed: 3
```

```
_y = FREADYAML("config.yaml")
_y["name"]                   // さくら
_y["tags"][1]                // shell
_y["height"]                 // 実数の 158.5
_y["visible"]                // 1
_y["memo"]                   // 空（VOID）
_y["talk"]["greeting"]       // "こんにちは。" + 改行 + "今日もいい天気ですね。" + 改行
_y["talk"]["random"][0]      // おはよう
_y["voice"]["volume"]        // 80（defaults から取り込んだもの）
_y["voice"]["speed"]         // 3
```

## Compatibility
- YAYA：Tc602-5 以降
- Tc603-1：傳入未知的字元編碼名稱時，會顯示警告 W0012 並失敗（在此之前不會顯示警告，而是使用作業系統預設值）
