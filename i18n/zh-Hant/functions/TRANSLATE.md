# TRANSLATE
**Category:** 文字列操作

## Signature
```
TRANSLATE( text, format_from, format_to )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| text | 要替換的字串 |
| format_from | 替換前的字元清單（具有格式，詳見下文） |
| format_to | 替換後的字元清單。指定空字串時會刪除字元 |

## Returns
- 成功：替換後的字串
- 失敗：-1

## Description
以字元為單位快速替換字串。提供相當於 Perl 的 tr///（不含選項）的功能。

### 格式

**簡單列舉**：將字元一對一對應。清單中沒有的字元不會變更。
```
TRANSLATE('ぬるぽガッ', 'ぽガ', 'りゴ') // 'ぬるりゴッ'
```

**指定範圍**：使用「-」指定字元碼範圍，並一次替換範圍內的字元。使用的字元碼為 UCS-2（Unicode），建議將 IME 的字元面板切換至 Unicode 模式確認。
```
TRANSLATE('123456789', '1-9', '①-⑨') // '①②③④⑤⑥⑦⑧⑨'
```

**跳脫字元**：使用 `\-` 指定連字號字元本身，使用 `\\` 指定反斜線字元本身。

```
TRANSLATE('\-\-\-', '\\', '\-') // '------'
```

**刪除**：將第 3 個引數指定為空字串，即可刪除符合的字元。
```
TRANSLATE('46cm三連装砲', '0-9a-z', '') // '三連装砲'
```

## Example

將平假名轉換為片假名，並將片假名轉換為平假名。

```
_wokyu = TRANSLATE('ティータイムは大事にしないとネー', 'ぁ-ゖァ-ヶ', 'ァ-ヶぁ-ゖ')
// _wokyu の中身 = てぃーたいむハ大事ニシナイトねー
```

Unicode 表中指定片假名與平假名重疊的範圍「ァ-ヶ」。如果辭典是以 Shift_JIS 編寫，字元「ゖ」會變成亂碼；遇到這種情況時，請改為如下寫法。

```
_wokyu = TRANSLATE('ティータイムは大事にしないとネー', 'ぁ-んァ-ン', 'ァ-ンぁ-ん')
```
