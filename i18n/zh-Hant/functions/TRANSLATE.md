# TRANSLATE
**Category:** 文字列操作

## Signature
```
TRANSLATE( text, format_from, format_to )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| text | 要置換的字串 |
| format_from | 置換前的字元清單（有格式，詳見下文） |
| format_to | 置換後的字元清單。指定空字串時會刪除字元 |

## Returns
- 成功：置換後的字串
- 失敗：-1

## Description
以字元為單位快速置換字串。提供相當於 Perl 的 tr///（不含選項）的功能。

### 格式

**簡單列舉**：將字元一對一對應。清單中沒有的字元不會變更。
```
TRANSLATE('ぬるぽガッ', 'ぽガ', 'りゴ') // 'ぬるりゴッ'
TRANSLATE('あああいいいううう', 'あい', 'おえ') // 'おおおえええううう'
```

**指定範圍**：使用「-」指定字元碼範圍並一次置換。使用的字元碼為 UCS-2（Unicode），建議將 IME 的字元面板切換為 Unicode 模式後確認。
```
TRANSLATE('123456789', '1-9', '①-⑨') // '①②③④⑤⑥⑦⑧⑨'
```

**跳脫**：使用 `\-` 指定一般連字號，使用 `\\` 指定一般反斜線。

```
TRANSLATE('\-\-\-', '\\', '\-') // '------'
```

**刪除**：將第三個引數指定為空字串，即可刪除符合的字元。
```
TRANSLATE('46cm三連装砲', '0-9a-z', '') // '三連装砲'
```

## Example

將平假名轉換為片假名，並將片假名轉換為平假名。

```
_wokyu = TRANSLATE('ティータイムは大事にしないとネー', 'ぁ-ゖァ-ヶ', 'ァ-ヶぁ-ゖ')
// _wokyu の中身 = てぃーたいむハ大事ニシナイトねー
```

指定了 Unicode 表中片假名與平假名重疊的範圍「ァ-ヶ」。如果辭典以 Shift_JIS 編寫，「ゖ」會產生亂碼，此時請改用以下寫法。

```
_wokyu = TRANSLATE('ティータイムは大事にしないとネー', 'ぁ-んァ-ン', 'ァ-ンぁ-ん')
```
