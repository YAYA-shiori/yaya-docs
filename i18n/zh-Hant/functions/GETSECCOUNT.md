# GETSECCOUNT
**Category:** システム情報

## Signature
```
GETSECCOUNT( [yyyy|datetext [, mm [, dd [, wd [, HH [, MM [, SS [, timezone]]]]]]]] )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| yyyy | 西元年（4 位數） |
| mm | 月（1〜12） |
| dd | 日 |
| wd | 星期（指定 0。任何值都會被忽略） |
| HH | 時 |
| MM | 分 |
| SS | 秒 |
| timezone | （可省略）指定日期時間的時區。省略時使用 OS 的本地時間。寫法與 [GETTIME](GETTIME.md#タイムゾーンの指定) 相同 |
| datetext | 替代指定方式：`'Sun, 06 Nov 1994 08:49:37 GMT'` 或 `'2024-01-01T09:00:00+09:00'` 格式的日期字串 |

## Returns
從 EPOCH（1970/1/1 00:00:00 UTC）到指定日期時間（或目前日期時間）經過的秒數（數值）

## Description
傳回從 EPOCH 到目前時間或指定日期時間經過的秒數。相當於 C 語言的 `time()` 函式。

- 省略所有引數時，使用目前時間
- 省略部分引數時，省略的值會以 `timezone` 中的目前時間值補足
- 值可以超出一般日期範圍（例如：指定月份為 13 時，會成為隔年的 1 月）
- 年月日等會以本地時間解讀。若要指定 UTC 或其他時區的日期時間，請使用第 8 個引數 `timezone`（`GETSECCOUNT(2024,1,1,0,0,0,0,'UTC')`）。本地時間的日光節約時間會依指定日期時間當時的規則判定

### 日期字串
`datetext` 可以讀取以下格式。HTTP 格式的星期可以省略。

```
Sun, 06 Nov 1994 08:49:37 GMT      RFC 822 / RFC 1123
Sunday, 06-Nov-94 08:49:37 GMT     RFC 850（年が2桁のときは 70-99 が19xx、00-69 が20xx）
Sun Nov  6 08:49:37 1994           C の asctime
2024-01-01T09:00:00+09:00          ISO 8601
```

ISO 8601 可以讀取以下形式。

| 形式 | 範例 |
|----|----|
| 日期 | `2024-01-01`（時刻為 00:00:00） |
| 日期和時間 | `2024-01-01T09:30`、`2024-01-01T09:30:15`、`2024-01-01 09:30:15`（`T` 也可以是小寫或空白） |
| 小數秒 | `2024-01-01T09:30:15.123`（小數秒會被捨去） |
| 時區 | `Z`、`+09:00`、`+0900`、`+09`、`-05:00` |
| 基本格式 | `20240101`、`20240101T093015Z` |

無法讀取不存在的日期（`2024-02-30`）或超出範圍的時間（`25:00`）。`24:00:00` 會視為隔天的 0 時，秒數 `60` 會視為閏秒。

- 若末尾有時區（HTTP 格式的 `GMT`、`+0900`、`+09:00`、`-0500`、`JST` 等，或 ISO 8601 的 `Z`、`+09:00`），就會以該時區讀取日期時間。範例中的 `GMT` 字串不受執行環境時區影響，結果會是 `784111777`
- 未指定時區的日期字串（例如 asctime 格式、`2024-01-01T09:00:00`）會以本地時間讀取
- 無法讀取的字串、無法辨識的月份名稱或不存在的日期，會發出警告 W0012（[GETLASTERROR](GETLASTERROR.md) 為 12）並傳回 `-1`。超出範圍的值也會如此處理

## Example
```
// 2006年14月25日 15:56:40 のEPOCH秒を取得し、GETTIMEで日付に変換する例
// （月14 = 翌年2月）
_array = GETTIME(GETSECCOUNT(2006, 14, 25, 0, 15, 56, 40))
"%(_array[1])月%(_array[2])日"
// 結果: "2007年2月25日" のように表示される

// UTCの日時から求める
_sec = GETSECCOUNT(2024, 1, 1, 0, 0, 0, 0, 'UTC')   // 1704067200

// ISO 8601 の文字列から求める
_sec = GETSECCOUNT('2024-01-01T09:00:00+09:00')     // 1704067200
```

## Compatibility
- 可從 YAYA 初期版本開始使用
- Tc606-1 之後：新增第 8 個引數 `timezone` 和 ISO 8601 日期字串
- Tc606-1：修正日期字串中記載的時區被當成當地時間讀取，導致日本時間相差 9 小時的問題（如 `-0500` 這類負偏移，以及 RFC 850 格式的兩位數年份也無法正確讀取）。無法讀取的字串會回傳 `-1` 並顯示警告。也修正了 2100 年以後被計為閏年，以及在有夏令時間的時區中，日期時間會依照目前的夏令時間規則轉換的問題
