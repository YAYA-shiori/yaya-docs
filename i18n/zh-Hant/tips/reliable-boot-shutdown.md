# 確實在人格啟動與結束時執行處理

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

以下介紹在人格載入與結束時確實執行處理的方法，例如載入常駐型 SAORI、初始化變數等。

### 先從簡單的做法開始……

做法很簡單。在適當的辭典中寫入

```
OnGhostLoad
{
  起動時のごにょごにょ
}

OnGhostUnload
{
  終了時のごにょごにょ
}
```

這樣就可以了。

請注意，**即使在這裡撰寫腳本，也不會顯示任何內容。**<br>
這裡僅用於基本的初始化處理。對話內容請妥善寫在 OnBoot 等事件中。

### 更可靠的做法

SSP 有一項稱為人格快取機制的功能，會將已載入的人格保留在記憶體中，以便之後重新載入。<br>
若無論如何都要在確實開啟／關閉人格時執行某些處理，除了上述事件之外，還需要在

```
OnCacheSuspend
OnCacheRestore
```

中撰寫處理內容。

……不過，一般來說不太需要在意這件事。
