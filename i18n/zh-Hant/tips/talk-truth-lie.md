# 關於句子的真假

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

整理了使用句子時容易產生誤解的內容，以及一些零碎的技巧。<br>
雖然標題寫著真假，但結果全都是假的（汗

另外，有些內容可能會隨著句子本身改良而有所變化。<br>
請不要忘記，這些內容只適用於**目前的**句子。

#### 區域變數和全域變數用哪一種都沒什麼差別

<span style="font-size:24px"><span style="color:#cc0000">×</span></span> - 錯誤

請積極區分使用這兩種變數。<br>
放著不管的全域變數會原封不動地保存下來，不僅會增加存檔檔案的大小，若任由長期保留的變數數量不斷增加，處理速度也會愈來愈慢。

請積極使用區域變數。

#### 經常使用 ERASEVAR 可以減少記憶體用量

<span style="font-size:24px"><span style="color:#cc0000">×</span></span> - 錯誤

目前的實作中，即使使用 ERASEVAR，也只會加上「刪除標記」，記憶體仍然會被占用。<br>
除非有特別理由，否則經常使用 ERASEVAR 幾乎沒有什麼效果。不僅如此，還得每次搜尋要刪除的變數，會讓執行速度大幅變慢。<br>
最好積極使用區域變數，從一開始就不需要刪除變數。

另外，針對全域變數，在結束前使用 ERASEVAR，可有效避免存檔檔案（???`_variable.cfg`）膨脹。

#### 使用陣列會變慢

<span style="font-size:24px"><span style="color:#cc0000">×</span></span> - 錯誤

**通用陣列**的速度相當快。<br>
有時使用通用陣列來取值，甚至會比建立大量變數更快。

不過，簡易陣列反而會變慢。<br>
若要確保使用通用陣列，請善用 IARRAY 等功能。

#### 傳遞值給函式時，使用回饋運算子會比較快

<span style="font-size:24px"><span style="color:#cc0000">×</span></span> - 大致上錯誤

與 C++ 等語言的參照傳遞不同，目前是透過重新指派計算結果來實現，因此使用回饋運算子也有可能比較慢。

除非確實有必要，否則不必想得太複雜，直接照一般方式傳遞即可。

――ぽな@ばぐとら

#### if 句的條件用"()"括起來會變慢

<span style="font-size:24px"><span style="color:#cc0000">×</span></span> - 錯誤

辭典載入完成後，"()"就會被移除，所以有沒有括號都沒有差別。此外，不論有沒有"()"，內部記憶體的用量也不會改變。

可以依照習慣或外觀上的偏好決定。

――yukaya

#### 不能使用日文函式名稱

<span style="font-size:24px"><span style="color:#cc0000">×</span></span> - 錯誤

可以使用。只是很多人習慣不用而已。<br>
函式名稱和變數名稱都可以使用日文（漢字、平假名等雙位元組字元）。<br>
以下項目則不可使用。

- 以半形數字開頭 - 會被誤認為數字
- 以底線開頭 - 會與區域變數撞名
- 可能與全由半形大寫英文字母組成的系統函式撞名 - 只是最好不要使用，並不會造成錯誤
- 名稱中包含半形的＋−＊／等運算子 - 會被誤認為運算式
