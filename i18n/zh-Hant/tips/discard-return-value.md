# 捨棄函式的傳回值

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

使用函式時，如果不將傳回值存入變數而直接呼叫，傳回值就會成為輸出候選，<br>
可能導致對話中出現莫名的「1」或「0」等問題。

#### 發生問題的範例

例如，以下辭典有一半的機率會讓「0」或「1」顯示在對話方塊中，令人傷透腦筋。

```
OnTestTalk
{
   //乱数のシードを設定
   SRAND( "ほげほげ" ) //SRAND関数は返り値を返すので出力候補になる。

   //サイコロを振る
   _num = RAND(6)

   "\0サイコロを振るよ！\1結果は(_num)だな。\e"
}
```

#### 解決方法範例

SRAND函式會傳回傳回值，因此將它指派給適當的變數，就能讓它不再成為輸出候選。

```
OnTestTalk
{
   //乱数のシードを設定
   _hoge = SRAND( "ほげほげ" ) //SRAND関数の返り値を捨て変数に代入させる。

   //サイコロを振る
   _num = RAND(6)

   "\0サイコロを振るよ！\1結果は(_num)だな。\e"
}
```

#### 使用void的方法

呼叫函式時加上「void」，也可以捨棄傳回值。<br>
請注意，這並不是指派。（不需要「=」）

```
OnTestTalk
{
   //乱数のシードを設定
   void SRAND( "ほげほげ" ) //SRAND関数の返り値を捨てる

   //サイコロを振る
   _num = RAND(6)

   "\0サイコロを振るよ！\1結果は(_num)だな。\e"
}
```
