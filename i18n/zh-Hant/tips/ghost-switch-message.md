# 變更人格切換訊息

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

- 人格 A 說了包含「お料理」這句台詞的句子
- 人格 A 說了包含「薬」這句台詞的句子
- 其他情況

在這些情況下，讓人格做出不同的反應。

```
OnGhostChanged
{
 　if reference0 == "ゴーストA" // （ここでゴースト名を指定）
 　{
 　　if "お料理" _in_ reference1 // （ここでキーワード「お料理」を指定）
 　　{
       "(文章1)"
 　　}
 　　elseif "薬" _in_ reference1 // （ここでキーワード「薬」を指定）
 　　{
 　　  "(文章2)"
 　　}
 　　else // （キーワード「お料理」がなかったときの反応）
 　　{
 　　  "(文章3)"
 　　}
 　}
}
```

要將它加入既有的辭典時，請使用 elseif，而不是 if。

如果想增加能改變反應的關鍵字，請增加第二個 elseif 的部分。
