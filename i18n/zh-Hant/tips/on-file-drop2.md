# OnFileDrop2 的用法

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

將檔案拖放到人格上時，會觸發OnFileDrop2事件。<br>

利用這項功能，可以變更桌布或播放音樂檔案。

[此處提供可直接使用的範例。](../attachment/OnFileDrop2.txt)

<span style="color:Red">※此處將OnChoiceSelect的選項直接寫成獨立函式。請參閱[將選項直接寫成獨立函式](independent-choice-function.md)。</span>

此處使用了[播放音效](play-sound.md)中記載的函式，也請一併參閱。<br>

此外，請事先取得下列SAORI，並將其放在與文法DLL（aya.dll、aya5.dll等）相同的目錄中。<br>
umeici 製作的 [MCIAudioR](http://umeici.hp.infoseek.co.jp/etcetera/)<br>
櫛ヶ浜やぎ 製作的　[set_wallpaper](http://www.geocities.co.jp/SiliconValley-Cupertino/8536/)<br>
橋本孔明 製作的　[PROXY.DLL](http://homepage3.nifty.com/khsoft/cbs/)
