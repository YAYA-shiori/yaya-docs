# 判別星期

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

```
weekj
{
　if weekday == 0
　{
　　// ---- 日曜日
　　"（日）"
　}
　elseif weekday == 1
　{
　　// ---- 月曜日
　　"（月）"
　}
　elseif weekday == 2
　{
　　// ---- 火曜日
　　"（火）"
　}
　elseif weekday == 3
　{
　　// ---- 水曜日
　　"（水）"
　}
　elseif weekday == 4
　{
　　// ---- 木曜日
　　"（木）"
　}
　elseif weekday == 5
　{
　　// ---- 金曜日
　　"（金）"
　}
　else
　{
　　// ---- 土曜日
　　"（土）"
　}
}
```

可以運用這個方法來變更對話題材、限制功能等…。<br>

### 使用陣列的版本

如果只要傳回星期幾，使用陣列……

```
weekj
{
       ("(日)","(月)","(火)","(水)","(木)","(金)","(土)")[weekday];
}
```

或許會比較俐落（不過有點難懂）。<br>
另外，我想這種寫法也能輕鬆套用在其他項目上（例如月份的別稱）。<br>

### 使用簡易陣列，寫得更俐落

雖然速度會比通用陣列慢，

```
weekj
{
  "(日),(月),(火),(水),(木),(金),(土)"[weekday]
}
```

這種寫法也可行。只要用逗號分隔列出項目，應該會更容易應用在其他地方。
