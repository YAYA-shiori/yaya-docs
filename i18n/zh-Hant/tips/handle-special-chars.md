# 處理特殊字元

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

想使用 Unicode 中配置了特殊字元碼的字元，但編輯器只支援 Shift JIS 等，遇到各種難題時可以參考以下解法。

### 不在內部進行處理時

如果只是想顯示出來，

```
\_u[0x2122]
```

之類的寫法就會在對話方塊中顯示。
括號內填入 0x + 十六進位碼（也可以直接填入十進位碼）

### 在內部進行處理時

這種情況下，只要趕快將辭典的字元編碼改為 UTF-8，就能一次解決；但若受到慣用編輯器等的限制，可能無法這麼做。此時可以……

```
CHR(0x2122)
```

基本上只要呼叫 CHR 系統函式即可，因此若要嵌入字串中，例如可以寫成

```
"Enbug Masters%(CHR(0x2122))"
'Enbug Masters' + CHR(0x2122)
```

即可解決。

不過，這樣雖然能在內部進行處理，卻無法正確輸出到對話方塊。此時需要在[基本設定檔](../grammar/01-basic-settings.md)中

```
charset.output, UTF-8
```

寫入這一行（如果已經有這行，請將右側設為 UTF-8）。
