# 同時說出不同內容

> 轉載自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

若要同時說出相同內容，可以使用 `\_s`，但要如何同時說出不同內容？

### 使用 SAORI 的方法

有一個名為 [parallel](http://www.geocities.jp/poskoma/) 的 SAORI。

### 僅使用文字

這是只用文字指令碼實現的範例。&new{2005-4-22};

[可直接使用的辭典檔案](../attachment/aya_parallel.txt)

### 說話內容已預先決定的情況

適合不懂 SAORI 或函式，想用盡可能簡單的方法實現的人。

<http://63factory.jp/~klat/bottle/soft.html>

可以使用 Bottle Tool 中的「ぱたぱたさん」。<br>
如其名稱所示，這是用於 SSTP Bottle 的特殊指令碼編輯工具，但用於一般人格也完全沒有問題。

### 上述內容是對以下問題的回答。

```
Tipsとは違いますが。

他の栞の場合、\0と\1で違うことを同時に喋らせることができますが
文ではできないのでしょうか?

現状では、\_qと\_w[20]前後を用いて擬似的に処理していますが、かなり面倒なので。


どなたかご存じでしたら、このページの編集をお願いいたします。
```
