# 教學 3：試著使用變數

「變數」就像是用來存放字串或數值的容器或盒子。在人格中，「使用者名稱」、「啟動次數」、「啟動時間」、「好感度」等都是變數。YAYA 的變數有各種類型。

## 字串與數值

變數分為「字串」和「數值」兩種（更精確地說，是整數、實數、字串三種類型）。

```
変数 = 1
```

這樣寫的話，變數的內容會是數值 `1`。

```
変数 = "1"
```

像這樣用 `" "` 或 `' '` 括起來再指派，存入的就是字串 `"1"`。像這樣將內容存入變數的動作稱為「指派」。

全形的「１」「２」「３」… 無法作為數值，會被視為字串。**字串型變數無法以數值進行比較或計算。** 例如，將數值 `1` 和 `2` 相加，結果會是 `3`；但將字串 `"1"` 和 `"2"` 相加，則會把 1 和 2 接在一起，變成 `"12"`。此外還有許多差異，請多加留意。

使用 YAYA 的系統函式，可以隨時將變數轉換為字串 ⇔ 數值。

- 將變數轉換為字串變數：`変数 = TOSTR(変数)`
- 將變數轉換為數值變數：`変数 = TOINT(変数)`

也有會自動判斷並轉換為整數、實數或字串的 [TOAUTO](../functions/TOAUTO.md)（稍後會詳細說明系統函式）。

### 全域變數與區域變數

名稱開頭加上 `_` 的是區域變數。

```
_変数名
```

沒有加上則是全域變數。

```
変数名
```

大致而言，「很快就會消失的暫時性資料」是區域變數，「只要不刪除就會一直保留」的是全域變數。為了減輕執行負擔及存檔資料，除了「使用者名稱」或「好感度」等必須一直保留的變數以外，建議盡可能使用區域變數。

### 區域變數的生命週期

（這部分有點複雜，如果看不太懂，現在可以先跳過，之後有疑問時再讀）

區域變數可以使用多久呢？它「只能在目前的 `{ }` 內，以及比目前更深的巢狀層級中使用。生命週期會持續到離開相應的 `{ }` 為止」（參考[值與變數](../grammar/03-values-and-variables.md#スコープとライフタイム)）。

用文字不太容易說明，以下舉例說明。

```
ローカル変数テスト {
	{
		_変数 = 1
	}
	結果 = _変数
}
```

這樣寫的話，`_変数` 從較深層移到較淺層時會消失，因此 `結果` 的內容也會變成空值。不過，

```
ローカル変数テスト {
	_変数 = ""
	{
		_変数 = 1
	}
	結果 = _変数
}
```

這樣一來，`_変数` 會依序經過較淺層 → 較深層 → 較淺層……；由於它一開始是在較淺層建立的，因此即使從較深層移到較淺層也不會消失，仍會保留下來，`結果` 的內容會是 1。關鍵在於 `_変数` 最初建立的位置，是否與 `結果 = _変数` 位於相同（或更淺）的層級。

也就是說，若想讓區域變數存活較久，只要一開始就在最淺層寫下一行 `_○○ = ""` 等內容即可。

## 實際試著使用變數吧

### 準備

開啟 `dic_main.dic`，找到以下行。

```
//クリックされたら「MouseDoubleClick_(キャラ番号)(当たり判定識別子)」イベントにジャンプ
OnMouseDoubleClick{EVAL("MouseDoubleClick_%(reference[3])%(reference[4])")}
```

在這行 `OnMouseDoubleClick` 的最左側加上 `//`，將它註解掉。接著，在其他地方寫入以下 3 行。

```
OnMouseDoubleClick {
	"\0\s[0]変数の実験をやるよー！\e"
}
```

這個事件會在「人格被按兩下滑鼠左鍵」時觸發。一般的人格通常會出現被戳的反應，或是顯示選單。

### 試著使用由 SHIORI 事件產生的變數

`OnMouseDoubleClick` 事件發生時，會自動產生 `reference[0]`、`reference[1]`……等變數。各個變數代表什麼意思，記載於之前也介紹過的[CROW・SSP參考資料 - Shiori](http://crow.aqrs.jp/reference/all/Shiori/index.html)中（其中寫作 `Reference0` 的變數，在 YAYA 中寫作 `reference[0]`）。

試著在對話中加入存有「被點擊的人格編號」的 `reference[3]`。

```
OnMouseDoubleClick {
	"\0\s[0]変数の実験をやるよー！\n\n"
	--
	reference[3]
	--
	"番のキャラがつつかれたよ！\e"
}
```

如果不使用 `" "` 或 `' '` 括起來，變數的內容就會展開並成為對話。真簡單！請試著按兩下主角（0 號角色）和配角（1 號角色），確認是否正常運作。

如果覺得這種寫法不容易理解或書寫，也可以改成以下寫法。

```
OnMouseDoubleClick {
	"\0\s[0]変数の実験をやるよー！\n\n%(reference[3])番のキャラがつつかれたよ！\e"
}
```

**在 `" "` 括起來的內容中使用變數時，請寫成 `%(變數名稱)`。** 順帶一提，若使用 `' '` 而非 `" "` 括起來，變數就不會展開，而會直接顯示。

### 來試著建立原創變數吧

試著送禮物給人格。要將「花束」這個字串放入名為「プレゼント」的變數時，請將一開始說明過的「變數 = 想指派給變數的內容」寫在 `{ }` 中。

```
OnMouseDoubleClick
{
	プレゼント = "花束"

	"\0\s[0]わーい「%(プレゼント)」ありがとう！\e"
}
```

```
【ここ】プレゼント【ここ】=【ここ】1【ここ】
```

【ここ】的部分可以放入空白或定位字元。運算符號（`=` 或 `+` 等符號）只能使用半形。為了提高可讀性，很多人會在運算符號的左右兩側加入半形空白。

在這個例子中，要放入變數的內容「花束」不是數值，因此要用 `" "` 或 `' '` 括起來。和撰寫對話時一樣。

```
OnMouseDoubleClick
{
	プレゼント = 花束

	"\0\s[0]わーい「%(プレゼント)」ありがとう！\e"
}
```

如果不小心這樣寫，變數「プレゼント」的內容就會變成空的。原因是，**YAYA 看到的不是 `"花束"` 而只有 `花束` 時，會將它解讀為「名為『花束』的變數」**。因此會被誤解成「將名為『花束』的變數內容放入名為『プレゼント』的變數」，而名為「花束」的變數並不存在，所以內容就會變成空的。

### 試著計算變數

數值型變數也可以進行計算。

```
OnMouseDoubleClick
{
	好感度 = 好感度 + 1

	"\0\s[0]ユーザーさんだいすき！\n\n（好感度が「%(好感度)」になった！）\e"
}
```

這也很簡單。順帶一提，也可以像下面這樣省略來寫。

```
OnMouseDoubleClick
{
	好感度++

	"\0\s[0]ユーザーさんだいすき！\n\n（好感度が「%(好感度)」になった！）\e"
}
```

`好感度++` 的意思是「好感度增加 1」，和 `好感度 = 好感度 + 1` 的意思相同。`好感度--` 則會減少 1。`好感度 += 2` 和 `好感度 = 好感度 + 2` 相同，`好感度 -= 2` 則和 `好感度 = 好感度 - 2` 相同。其他可在 YAYA 中使用的計算符號，請參閱[運算](../grammar/04-arithmetic.md)。

字串之間也可以相加。

```
プレゼント = "花" + "束"
```

如此一來，變數 `プレゼント` 的內容就會變成 `"花束"`。

### 確認變數是否有正確儲存

先結束人格，再用文字編輯器開啟存檔資料檔案（`yaya_variable.cfg`）。以上面的範例來說，如果看到

```
プレゼント,"花束",",",
```

這一行，就表示已成功儲存。順帶一提，數值型變數的情況下，

```
好感度,1,",",
```

變數內容中的數字不會以 `" "` 括起來。儲存格式的詳細資訊請參閱 [SAVEVAR](../functions/SAVEVAR.md#保存形式)。
