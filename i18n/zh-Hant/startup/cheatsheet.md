# 快速參考表

這是一頁整理 YAYA 寫法的快速參考表。詳細說明請參閱各項目的連結。

## YAYA 的基本概念

- 辭典是**函式的集合**。以 `名稱 { ... }` 的形式定義，若使用 `OnBoot` 之類的事件名稱，就會成為對該事件的回應。
- 函式中的**運算式或字串會逐行成為「輸出的候選項目」**。呼叫函式時，會從候選項目中隨機選出一個並傳回。指派（`_a = 1`）之類的陳述式不會成為候選項目。
- 字串以 `"..."` 括住。Sakura Script 也是字串，因此一定要括住。
- 變數有型別（整數、實數、字串、陣列、雜湊）。不需要宣告。以 `_` 開頭的名稱是區域變數。
- 函式外不能寫陳述式或變數。只有 `#define` 等前置處理器可以寫在函式外。
- `if` `while` 的條件運算式可以用括號括住，也可以不括（`if (_a == 1)` 和 `if _a == 1` 相同）。`for` `foreach` 也可以用 `( )` 括住整個標頭（Tc603-6 以後才支援；更早的版本會發生錯誤）。
- 符號請使用半形（不能使用全形的 `（` 或 `＋`）。

## 函式的寫法

```
OnBoot
{
  _name = "さくら"
  "\0\s[0]こんにちは、%(_name)さん。\e"
  "\0\s[0]起動しましたね。\e"
}
```

- 在上面的範例中，會隨機傳回 `"\0\s[0]こんにちは…"` 或 `"\0\s[0]起動しましたね。\e"`（`_name = …` 不會成為候選項目）。
- 每個候選項目**各占一行**。若像 `"a" "b"` 一樣將多個候選項目寫在同一行，會發生錯誤。`"a" / "b"` 中的 `/` 是除法，不是候選項目的分隔符號。
- 在獨立一行寫上 `--`，會將前後的候選項目分成不同群組，並從各群組中分別選出一個項目後串接（[函式](../grammar/02-functions.md)）。
- `{` 可以和函式名稱寫在同一行，也可以寫在下一行。
- 註解可使用 `// 到行尾` 和 `/* 多行 */`。
- 一行中要寫多個陳述式時，請用 `;` 分隔（`_a = 1 ; _b = 2`）。

### 引數與傳回值

| 寫法 | 意義 |
|--------|------|
| `Func(1, "a")` | 帶引數呼叫。沒有引數時只寫 `Func` 即可 |
| `_argv[0]` `_argv[1]` | 接收到的引數（從 0 開始編號） |
| `_argc` | 引數數量 |
| `Func(&_v)` | 以參照方式傳遞變數。在 `Func` 中執行 `_argv[0] = 99` 時，`_v` 會改變 |
| `return` | 在此結束函式。從目前為止的候選項目中選出一個並傳回 |
| `return 式` | **捨棄所有**目前為止的候選項目，並傳回運算式的值（Tc573-1 以後） |

### 候選項目的選擇方式

在函式名稱後面以 `:` 指定（`Seq : sequential`）。

| 指定 | 動作 |
|------|------|
| （無） | 從候選項目中隨機選出一個 |
| `nonoverlap` | 不會連續選到和上次相同的候選項目 |
| `sequential` | 依序從上往下傳回，到達最後一個後再回到開頭 |
| `array` | 將所有候選項目組成通用陣列後傳回 |
| `void` | 執行內容，但不傳回任何值 |
| `all` | 將所有候選項目串接成一個字串後傳回（Tc567-1 以後） |
| `last` | 傳回最後一個候選項目（Tc567-1 以後） |

除了選擇方式之外，也可以加上以下修飾詞。

| 指定 | 動作 |
|------|------|
| `_pool` | 將內部區塊（包含 `if` 的內容）的候選項目拆開，並以和外部候選項目相同的機率選取 |
| `_pool_nonoverlap` `_pool_sequential` | 對拆開後的所有候選項目使用避免重複或依序選取的方式 |
| `melt_` | 若選出的輸出是通用陣列，則拆開其中的元素，並加入外部區塊的候選項目 |

```
OnTest : _pool
{
  "x"
  {
    "y"
    "z"
  }
}
```

- 若沒有 `_pool`，內部的 `{ }` 整體會視為一個候選項目（`x` 的機率是 1/2，`y` 和 `z` 各為 1/4）。加上 `_pool` 後，`x` `y` `z` 的機率各為 1/3。
- 若 `if` 條件為假，其中的候選項目就不會加入。可以使用 `if 條件 { "b" "c" }`，寫出「只有在條件為真時才增加候選項目」的寫法。
- `while` `for` `foreach` 迴圈中的候選項目會在每次重複時各加入一個。
- 像 `nonoverlap : {` 這樣指定選擇方式的區塊，不會被拆開，而是維持為一個候選項目。

詳細說明請參閱[函式](../grammar/02-functions.md)。

## 值與型別

| 種類 | 寫法 | 範例 |
|------|--------|----|
| 整數 | 十進位、`0b`（二進位）、`0x`（十六進位）。64 位元 | `10` `0b1010` `0xa` |
| 實數 | 加上小數點 | `3.14` |
| 字串 | `"..."`（會展開）、`'...'`（不會展開） | `"a%(_x)"` `'a%(_x)'` |
| 多行字串 | `<<"` … `">>`（會展開）、`<<'` … `'>>`（不會展開） | |
| 通用陣列 | `(1, "a", 2.5)` | [陣列](../grammar/05-arrays.md) |
| 簡易陣列 | 以逗號分隔的字串 `"a,b,c"` | 同上 |
| 雜湊 | `IHASH("キー", 値, …)`（Tc600-3 以後） | [雜湊](../grammar/12-hash.md) |
| VOID | 未定義的變數、超出範圍的元素 | 字串會是空字串，數值會是 0 |

- 字串中的 `"` 要重複書寫（`"1""2"` → `1"2`）。
- 使用 [GETTYPE](../functions/GETTYPE.md) 查詢型別（VOID 為 0、整數為 1、實數為 2、字串為 3、通用陣列為 4、雜湊為 5）。
- 將實數轉換為字串時，小數點後會有 6 位數（`3.0/4*100` → `75.000000`）。
- 整數相除時會無條件捨去小數（`4/3` → `1`）。其中一個數值若為實數，結果就會是實數。

## 變數

| 寫法 | 意義 |
|--------|------|
| `_a = 1` | 區域變數。只在該函式及其內部區塊中有效。離開區塊後便會消失 |
| `a = 1` | 全域變數。可在任何函式中使用。結束時會自動儲存，並在下次啟動時還原 |
| `ERASEVAR("a")` | 刪除全域變數 |
| `_a++` `_a--` `_a += 2` | 加法、減法、複合指派（也有 `-=` `*=` `/=` `%=`） |

- 未定義的變數在計算時會是 0，在字串中會是空字串（`UNDEF + 1` 是 `1`）。
- 名稱不能以數字開頭，也不能和保留字或函式名稱相同（[保留字](../grammar/09-reserved-words.md)）。

## 運算子

依優先順序由高至低排列（[算術運算](../grammar/04-arithmetic.md)）。

| 種類 | 運算子 |
|------|--------|
| 括號・索引 | `( )` `[ ]` |
| 否定 | `!` |
| 遞增遞減 | `++` `--` |
| 乘除 | `*` `/` `%` |
| 加減 | `+` `-` |
| 比較 | `==` `!=` `>=` `<=` `>` `<` `_in_` `!_in_` |
| 邏輯 | `&&` `\|\|` |
| 指派 | `=` `+=` `-=` `*=` `/=` `%=` `,=` |
| 逗號（建立陣列） | `,` |

- `0` 為假，非 0 為真。比較的結果為 `1` 或 `0`。
- `"or" _in_ "World"` 在右側字串包含左側字串時會是 `1`。
- `+` 在其中一方是字串時會進行**串接**（`"5" + 1` 為 `"51"`）。`*` 會以數值進行計算（`"5" * 2` 為 `10`）。
- `==` 會區分大小寫（`"abc" == "ABC"` 為 `0`）。
- 沒有三元運算子（`? :`）。

## 控制結構

```
if _a < 3
{
  "小"
}
elseif _a < 10
{
  "中"
}
else
{
  "大"
}
```

| 想要的功能 | 寫法 |
|--------------|--------|
| 二分支・多分支 | `if` / `elseif` / `else`（除巢狀 `if` 外，只有一個敘述時可省略 `{ }`） |
| 依值分支 | `case 運算式 { when 值 { … } when 值1, 值2 { … } others { … } }` |
| 依位置選擇 | `switch 運算式 { 候選0 候選1 … }`（候選項目每行一個。從 0 開始） |
| 依條件重複 | `while 條件 { … }` |
| 依次數重複 | `for _i = 0 ; _i < 10 ; _i++ { … }`（三個部分都是必要的。Tc603-6 之後可用 `( )` 括住整個標頭） |
| 依序處理陣列 | `foreach 陣列 ; _v { … }` |
| 逐一處理鍵和值 | `foreach 陣列或雜湊 ; _k, _v { … }`（Tc600-3 之後） |
| 跳出迴圈・繼續下一次 | `break` / `continue` |

```
case _name
{
  when "さくら" { "さくらだね" }
  when "うにゅう", "うに" { "うにゅうだね" }
  others { "だれ？" }
}
```

- `case` 的 `when` **只能寫常值**（不可使用變數或運算式）。範圍可寫成 `3-5` 或 `"a"-"d"`。
- `when` 和 `others` 要寫在接續 `case 運算式` 的 `{ }` 內。若未加上 `{` 就接著寫 `when`，載入時會發生錯誤（E0051）。
- 迴圈的重複次數有上限（預設為 1000000 次。`looplimit`）。超過上限時會呼叫 `OnLoopLimit`。
- `while 1` 是無限迴圈。請務必寫上 `break`。

## 字串內嵌入

| 寫法 | 意義 |
|--------|------|
| `"%(_a)"` `"%(1+2)"` | 評估運算式並嵌入（有範圍的展開） |
| `"%_a"` | 以名稱的最長相符項目嵌入。執行時會搜尋名稱，因此速度較慢 |
| `'%(_a)'` | 使用單引號時不會展開 |

詳細說明請參閱[字串嵌入](../grammar/06-string-embedding.md)。

## 陣列

```
_a = (10, 20, 30)
_a[1]            // 20
_a[0,1]          // 範囲（10,20）
_a ,= 40         // 末尾に追加
_a = ("先頭", _a) // 先頭に追加
_a + "!"         // 全要素に演算（10!,20!,…）
ARRAYSIZE(_a)    // 要素数
```

- 超出範圍的元素會是 VOID（`GETTYPE(_a[9])` 為 0）。
- 簡易陣列會以字串形式直接透過索引讀寫（`_s = "a,b,c"` → `_s[1]` 為 `b`）。可像 `_s[1,"|"]` 這樣指定分隔符號。
- 陣列元素請使用 [ARRAYSIZE](../functions/ARRAYSIZE.md)，搜尋請使用 [ASEARCH](../functions/ASEARCH.md)，排序請使用 [ASORT](../functions/ASORT.md)，分割請使用 [SPLIT](../functions/SPLIT.md)。

## 雜湊（Tc600-3 之後）

```
_h = IHASH("name", "さくら", "age", 16)
_h["name"]        // さくら
_h["age"] += 1    // 複合代入も使える
_h["none"]        // VOID（キーが無い）
foreach _h ; _k, _v { … }
```

- 雜湊必須先用 `IHASH()` 建立。
- 元素會依鍵的順序排列（而非加入的順序）。
- 元素也可以放入陣列或雜湊（[值的巢狀](../grammar/13-nesting.md)）。

## 前置處理器

| 寫法 | 意義 |
|--------|------|
| `#define 前 後` | 替換該檔案中此行之後的字串 |
| `#globaldefine 前 後` | 在之後載入的所有辭典中進行替換 |
| `#ifdef 名稱` … `#else` … `#endif` | 若名稱已定義，則載入（Tc574-2 / Tc602-2 之後） |
| `__AYA_SYSTEM_YAYA6__` | 使用 600 系列時會定義（可用於 500 系列共用的辭典） |
| `__AYA_SYSTEM_FILE__` `__AYA_SYSTEM_LINE__` `__AYA_SYSTEM_FUNC__` | 會替換為檔名・行號・函式名稱 |

詳細說明請參閱[前置處理器](../grammar/08-preprocessor.md)。

## 設定檔（yaya.txt）

```
dic, basis.dic
charset, UTF-8
log, executelog.txt
```

| 設定 | 意義 |
|------|------|
| `dic, 檔案` | 載入辭典（`dicif` 僅在檔案存在時載入，`dicdir` 載入資料夾中的所有檔案） |
| `charset, UTF-8` | 字元編碼（也可透過 `charset.dic` 等檔案依用途指定） |
| `log, 檔案` | 輸出執行記錄 |
| `fncdepth, 數值` | 函式呼叫深度上限（預設為 32。設為 0 時深度不受限，但堆疊剩餘空間變少時會停止） |
| `looplimit, 數值` | 迴圈次數上限（預設為 1000000） |
| `embed.lazy, off` | 在載入時決定 `"%名稱"` 的名稱（預設為 on，會在執行時搜尋） |

- 設定檔的名稱是在 DLL 名稱後加上 `.txt`（`yaya.txt`）。可使用 `//` 和 `/* */` 撰寫註解。
- 若沒有設定檔，或沒有任何已載入的辭典，便會進入**外殼模式**。送入的運算式會直接以 `EVAL` 評估後傳回，可用來確認運算式的行為（[基本設定](../grammar/01-basic-settings.md#シェルモード)）。

詳細說明請參閱[基本設定](../grammar/01-basic-settings.md)。
