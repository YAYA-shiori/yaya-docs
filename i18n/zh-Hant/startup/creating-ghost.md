# 使用 YAYA 製作人格

## 1. 選擇範本人格

首先選擇喜歡的範本，試著修改看看。

| 範本 | 說明 |
|-----------|------|
| [哈囉 YAYA 世界（紺野ややめ）](http://ms.shillest.net/yayame.xhtml) | 即使單獨使用，也能當作人格來體驗的範本人格 |
| [SimpleYAYA 範本](../other/simple-yaya-template.md) | 適合想要更簡單範本的人 |
| [紺野りりす](http://ms.shillest.net/yayalilith.xhtml) | 特色是配備了全套不太像 YAYA 風格的強大開發輔助處理。最終目標是打造最強開發環境，在 baseware 作者全力協助下，兼具與 Satori 相當的簡單易用性及強大的擴充性 |

### 除錯器

雖然不是範本，但建議安裝[「玉」下載網站](http://umeici.onjn.jp/)的「tama (debugger for aya)」作為除錯器。使用方法可參考[使用玉檢查辭典錯誤](../tips/tama-error-check.md)等資料。

### 注意

正式開始編輯之前，檔案可能會因網路更新而遭到變更。使用紺野ややめ或紺野りりす時，請停用 `yaya_string.txt` 中的 `homeurl`。

如果想嘗試範本沒有的功能，或是不知道該如何修改範本，請閱讀手冊。

撰寫辭典時所需的 Sakura Script、SHIORI Event 等資訊並未收錄在這份手冊中。請一併參閱以下資料（皆為外部網站）。

- [CROW・SSP 參考資料](http://crow.aqrs.jp/reference/all/)
- [UKADOC Project TOP](https://ssp.shillest.net/ukadoc/manual/index.html)
- [Disc-2 人格製作](http://disc2.s56.xrea.com/manual/)

如果之前使用過其他 SHIORI，閱讀以下內容可以更順利地進行移轉。

- [從 AYA 移轉](migration-from-aya.md)
- [從 Satori 移轉](migration-from-satolili.md)
