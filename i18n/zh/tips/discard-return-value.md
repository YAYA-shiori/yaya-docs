# 丢弃函数的返回值

> 转载自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

调用函数时，如果不把返回值存入变量而直接调用，返回值就会成为输出候选项，<br>
有时会导致对话中显示莫名其妙的「1」或「0」等问题。

#### 问题示例

例如，下面的词典会以 1/2 的概率在对话框中显示「0」或「1」，让人颇为头疼。

```
OnTestTalk
{
   //乱数のシードを設定
   SRAND( "ほげほげ" ) //SRAND関数は返り値を返すので出力候補になる。

   //サイコロを振る
   _num = RAND(6)

   "\0サイコロを振るよ！\1結果は(_num)だな。\e"
}
```

#### 解决示例

SRAND函数会返回一个值，因此可以将其赋给任意变量，使其不再成为输出候选项。

```
OnTestTalk
{
   //乱数のシードを設定
   _hoge = SRAND( "ほげほげ" ) //SRAND関数の返り値を捨て変数に代入させる。

   //サイコロを振る
   _num = RAND(6)

   "\0サイコロを振るよ！\1結果は(_num)だな。\e"
}
```

#### 使用void的方法

调用函数时，也可以在函数前加上「void」来丢弃返回值。<br>
请注意，这不是赋值操作。（不需要「=」）

```
OnTestTalk
{
   //乱数のシードを設定
   void SRAND( "ほげほげ" ) //SRAND関数の返り値を捨てる

   //サイコロを振る
   _num = RAND(6)

   "\0サイコロを振るよ！\1結果は(_num)だな。\e"
}
```
