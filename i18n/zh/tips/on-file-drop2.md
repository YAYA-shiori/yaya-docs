# OnFileDrop2的用法

> 转引自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

将文件拖放到人格上时，会触发OnFileDrop2事件。<br>

利用这一功能，可以更换壁纸或播放音乐数据。

[这里提供了可直接使用的示例。](../attachment/OnFileDrop2.txt)

<span style="color:Red">※这里直接将OnChoiceSelect的选项写成了独立函数。请参阅[直接将选项写成独立函数](independent-choice-function.md)。</span>

本文使用了[播放声音](play-sound.md)中记载的函数，请一并参阅。<br>

另外，请事先获取以下SAORI，并将其放置在与文档DLL（aya.dll、aya5.dll等）相同的目录中。<br>
umeici制作的 [MCIAudioR](http://umeici.hp.infoseek.co.jp/etcetera/)<br>
櫛ヶ浜やぎ制作的　[set_wallpaper](http://www.geocities.co.jp/SiliconValley-Cupertino/8536/)<br>
橋本孔明制作的　[PROXY.DLL](http://homepage3.nifty.com/khsoft/cbs/)
