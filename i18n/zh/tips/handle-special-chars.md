# 想要处理特殊字符

> 转载自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

想使用分配了特殊 Unicode 字符代码的字符，却遇到编辑器只支持 Shift JIS 等问题时，可以用下面的方法解决。

### 不需要在内部进行处理时

如果只想显示字符，

```
\_u[0x2122]
```

这样就会在对话框中显示。
括号内填写 0x + 十六进制代码（也可以直接填写十进制代码）。

### 需要在内部进行处理时

这种情况下，直接将词典的字符编码改为 UTF-8 就能一次解决问题；不过，由于习惯使用的编辑器等工具的限制，有时可能无法这样做。这时可以使用……

```
CHR(0x2122)
```

本质上只是调用 CHR 系统函数，因此，如果要嵌入字符串中，例如可以这样写：

```
"Enbug Masters%(CHR(0x2122))"
'Enbug Masters' + CHR(0x2122)
```

这样就能解决问题。

不过，这样虽然能在内部进行处理，却无法正确输出到对话框。此时需要在[基础设置文件](../grammar/01-basic-settings.md)中写入

```
charset.output, UTF-8
```

（如果已经有这一项，则将右侧的值改为 UTF-8）。
