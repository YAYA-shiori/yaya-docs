# 判别星期几

> 转载自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

```
weekj
{
　if weekday == 0
　{
　　// ---- 日曜日
　　"（日）"
　}
　elseif weekday == 1
　{
　　// ---- 月曜日
　　"（月）"
　}
　elseif weekday == 2
　{
　　// ---- 火曜日
　　"（火）"
　}
　elseif weekday == 3
　{
　　// ---- 水曜日
　　"（水）"
　}
　elseif weekday == 4
　{
　　// ---- 木曜日
　　"（木）"
　}
　elseif weekday == 5
　{
　　// ---- 金曜日
　　"（金）"
　}
　else
　{
　　// ---- 土曜日
　　"（土）"
　}
}
```

可以用它来改变对话内容、限制功能等……。<br>

### 使用数组的版本

如果只是返回星期几，利用数组……

```
weekj
{
       ("(日)","(月)","(火)","(水)","(木)","(金)","(土)")[weekday];
}
```

这样写可能更简洁（不过有点难懂）。<br>
另外，我想这种写法也很容易应用到其他地方（比如月份的别称）。<br>

### 使用简易数组，让写法更简洁

虽然会比通用数组慢一些，

```
weekj
{
  "(日),(月),(火),(水),(木),(金),(土)"[weekday]
}
```

这样写也可以。只需用逗号分隔并列出各项，应该更容易应用到其他地方。
