# 确保在人格启动和结束时执行操作

> 转载自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

介绍一种在加载和结束人格时可靠地执行操作的方法，例如加载常驻型 SAORI、初始化变量等。

### 先从简单的做法开始……

方法很简单。在任意词典中写入：

```
OnGhostLoad
{
  起動時のごにょごにょ
}

OnGhostUnload
{
  終了時のごにょごにょ
}
```

这样就可以了。

请注意，**即使在这里编写脚本，也不会发生任何事情。**<br>
这只用于执行基本的初始化处理。对话等内容请妥善写在 OnBoot 等事件中。

### 更加可靠的做法

SSP 有一种称为人格缓存机制的功能，会将已加载的人格保留在内存中，以备再次加载。<br>
如果无论如何都要确保在人格打开／关闭时执行某些操作，除了上面提到的处理之外，还需要在

```
OnCacheSuspend
OnCacheRestore
```

中编写相应内容。

……不过，通常不太需要在意这些。
