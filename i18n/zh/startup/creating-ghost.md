# 使用YAYA制作人格

## 1. 选择模板人格

首先选择喜欢的模板，试着修改它。

| 模板 | 说明 |
|-----------|------|
| [你好YAYA世界（紺野ややめ (Konnoyayame)）](http://ms.shillest.net/yayame.xhtml) | 即使单独使用，也能作为人格体验的模板人格 |
| [SimpleYAYA模板](../other/simple-yaya-template.md) | 面向想要更简单模板的人 |
| [紺野りりす](http://ms.shillest.net/yayalilith.xhtml) | 特点是包含了全部强大的开发辅助处理，但并不像YAYA。最终目标是打造最强开发环境：在baseware作者的全面协助下，兼具与Satori相当的简单易用性和强大的扩展性 |

### 调试器

它不是模板，但建议安装[「玉」发布网站](http://umeici.onjn.jp/)上的「tama (debugger for aya)」作为调试器。使用方法请参考[使用玉检查词典错误](../tips/tama-error-check.md)等内容。

### 注意

在正式开始编辑之前，文件可能会因网络更新而被更改。如果使用紺野ややめ或紺野りりす，请禁用 `yaya_string.txt` 中的 `homeurl`。

## 2. 阅读手册

如果想尝试模板中没有的功能，或者不知道该如何修改模板，就阅读手册。

- 本[手册](../INDEX.md)

编写词典时需要用到的Sakura Script、SHIORI Event等信息未收录在本手册中。请一并参阅以下资料（均为外部网站）。

- [CROW・SSP参考资料](http://crow.aqrs.jp/reference/all/)
- [UKADOC Project TOP](https://ssp.shillest.net/ukadoc/manual/index.html)
- [Disc-2 人格制作](http://disc2.s56.xrea.com/manual/)

如果之前使用过其他SHIORI，阅读以下内容可以帮助你顺利迁移。

- [从AYA迁移](migration-from-aya.md)
- [从Satori迁移](migration-from-satolili.md)
