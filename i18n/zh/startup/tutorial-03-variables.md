# 教程3：试着使用变量

“变量”是用来存放字符串或数值的容器，就像盒子一样。对于人格来说，“用户名”“启动次数”“启动时间”“好感度”等都是变量。YAYA 的变量有很多种类。

## 字符串和数值

变量分为“字符串”和“数值”两种（准确来说有整数、实数、字符串 3 种）。

```
変数 = 1
```

这样写的话，变量的内容就是数值 `1`。

```
変数 = "1"
```

像这样用 `" "` 或 `' '` 括起来再赋值，就会存入字符串 `"1"`。像这样把内容存入变量，称为“赋值”。

全角的“１”“２”“３”… 不能作为数值，会被视为字符串。**字符串类型的变量不能作为数值进行比较或计算。** 例如，数值 `1` 和 `2` 相加的结果是 `3`，而字符串 `"1"` 和 `"2"` 相加时，1 和 2 会连接起来，变成 `"12"`。还有许多其他区别，请注意。

使用 YAYA 的系统函数，可以随时将变量从字符串转换为数值，或从数值转换为字符串。

- 将变量转换为字符串变量：`変数 = TOSTR(変数)`
- 将变量转换为数值变量：`変数 = TOINT(変数)`

还有可以自动判断并转换为整数、实数或字符串的 [TOAUTO](../functions/TOAUTO.md)（关于系统函数的详细说明稍后介绍）。

### 全局和局部

名称开头带有 `_` 的是局部变量。

```
_変数名
```

没有的话就是全局变量。

```
変数名
```

粗略来说，“很快就会消失的临时变量”是局部变量，“只要不删除就会一直保留”的是全局变量。为了减轻运行和存档数据的负担，除了“用户名”或“好感度”等必须一直保留的变量外，建议尽量使用局部变量。

### 局部变量的生命周期

（这一部分比较复杂，如果不容易理解，可以先跳过，之后感兴趣时再读）

局部变量可以使用多长时间呢？它“只能在当前 `{ }` 内，以及比当前更深的嵌套层级中使用。其生命周期会持续到离开对应的 `{ }` 为止”（摘自[值与变量](../grammar/03-values-and-variables.md#スコープとライフタイム)）。

用语言不太容易说明，下面举个例子。

```
ローカル変数テスト {
	{
		_変数 = 1
	}
	結果 = _変数
}
```

这样写的话，`_変数` 从较深的层级移到较浅的层级时会消失，因此 `結果` 的内容也会变为空。不过，

```
ローカル変数テスト {
	_変数 = ""
	{
		_変数 = 1
	}
	結果 = _変数
}
```

这样写的话，`_変数` 会按照较浅层级 → 较深层级 → 较浅层级… 的顺序移动。由于它最初是在较浅的层级中创建的，因此从较深的层级移动到较浅的层级时也不会消失，`結果` 的内容会变成 1。关键在于，`_変数` 最初创建的位置，是否与 `結果 = _変数` 位于同一层级或更浅的层级。

也就是说，如果想让局部变量的生命周期更长，只需在最浅的层级先写一行 `_○○ = ""` 等内容。

## 实际试着使用变量

### 准备

打开 `dic_main.dic`，找到下面这行。

```
//クリックされたら「MouseDoubleClick_(キャラ番号)(当たり判定識別子)」イベントにジャンプ
OnMouseDoubleClick{EVAL("MouseDoubleClick_%(reference[3])%(reference[4])")}
```

在 `OnMouseDoubleClick` 这一行的最左侧加入 `//`，将它注释掉。然后在任意位置写入下面 3 行。

```
OnMouseDoubleClick {
	"\0\s[0]変数の実験をやるよー！\e"
}
```

这个事件会在“人格被双击”时触发。一般来说，通常会出现戳击反应或显示菜单等行为。

### 试着使用 SHIORI 事件自动生成的变量

触发 `OnMouseDoubleClick` 事件时，会自动生成 `reference[0]`、`reference[1]`… 等变量。各个变量分别代表什么，前面介绍过的[CROW・SSP参考手册 - Shiori](http://crow.aqrs.jp/reference/all/Shiori/index.html)中有说明（其中写作 `Reference0` 的变量，在 YAYA 中写作 `reference[0]`）。

试着在对话中加入存有“被点击角色编号”的 `reference[3]`。

```
OnMouseDoubleClick {
	"\0\s[0]変数の実験をやるよー！\n\n"
	--
	reference[3]
	--
	"番のキャラがつつかれたよ！\e"
}
```

如果不使用 `" "` 或 `' '` 括起来，变量的内容就会展开并成为对话。很简单！请试着双击主角色（0 号角色）和副角色（1 号角色），确认它是否正常运行。

如果觉得这种写法难以理解或难以书写，可以这样写：

```
OnMouseDoubleClick {
	"\0\s[0]変数の実験をやるよー！\n\n%(reference[3])番のキャラがつつかれたよ！\e"
}
```

**在 `" "` 括起来的内容中使用变量时，要写成 `%(変数名)`。** 顺带一提，如果用 `' '` 而不是 `" "` 括起来，变量就不会展开，而是原样显示。

### 试着创建自定义变量

试着给人格送礼物。当要把“花束”这个字符串存入名为“プレゼント”的变量时，在 `{ }` 中写入前面介绍过的“变量 = 要赋给变量的内容”。

```
OnMouseDoubleClick
{
	プレゼント = "花束"

	"\0\s[0]わーい「%(プレゼント)」ありがとう！\e"
}
```

```
【ここ】プレゼント【ここ】=【ここ】1【ここ】
```

【ここ】的位置可以填入空格或制表符。运算符号（例如 `=` 或 `+` 这样的符号）只能使用半角字符。为了便于阅读，很多人会在运算符左右加入半角空格。

在这个例子中，要存入变量的内容“花束”不是数值，所以要用 `" "` 或 `' '` 括起来。和写对话时一样。

```
OnMouseDoubleClick
{
	プレゼント = 花束

	"\0\s[0]わーい「%(プレゼント)」ありがとう！\e"
}
```

如果不小心这样写，“プレゼント”的内容就会变为空。原因是，**YAYA 会把 `花束`（而不是 `"花束"`）解释为“名为‘花束’的变量”**。因此，它会被误解为“把名为‘花束’的变量的内容存入名为‘プレゼント’的变量”，而由于不存在名为“花束”的变量，内容就会变为空。

### 试着计算变量

数值类型的变量也可以进行计算。

```
OnMouseDoubleClick
{
	好感度 = 好感度 + 1

	"\0\s[0]ユーザーさんだいすき！\n\n（好感度が「%(好感度)」になった！）\e"
}
```

这也很简单。顺带一提，还可以像下面这样省略写法。

```
OnMouseDoubleClick
{
	好感度++

	"\0\s[0]ユーザーさんだいすき！\n\n（好感度が「%(好感度)」になった！）\e"
}
```

`好感度++` 的意思是“好感度增加 1”，与 `好感度 = 好感度 + 1` 意思相同。`好感度--` 则会减少 1。`好感度 += 2` 与 `好感度 = 好感度 + 2` 意思相同，`好感度 -= 2` 与 `好感度 = 好感度 - 2` 意思相同。其他可用于计算的 YAYA 符号请参阅[运算](../grammar/04-arithmetic.md)。

字符串之间也可以相加。

```
プレゼント = "花" + "束"
```

这样写的话，变量 `プレゼント` 的内容会变成 `"花束"`。

### 确认变量是否已正确保存

先关闭人格，然后用文本编辑器打开存档数据文件（`yaya_variable.cfg`）。以上面的例子来说，如果有下面这一行，

```
プレゼント,"花束",",",
```

就表示保存成功。顺带一提，数值类型的变量会像下面这样，变量内容中的数字不会用 `" "` 括起来。

```
好感度,1,",",
```

关于保存格式的详细信息，请参阅 [SAVEVAR](../functions/SAVEVAR.md#保存形式)。
