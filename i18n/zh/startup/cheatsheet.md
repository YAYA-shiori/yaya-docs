# 速查表

本页汇总了 YAYA 的书写方式，供快速查阅。详细说明请参阅各项链接。

## YAYA 的基本概念

- 词典是**函数的集合**。以 `名称 { ... }` 的形式定义函数；如果使用 `OnBoot` 这样的事件名，函数就会成为对该事件的响应。
- 函数中的**表达式和字符串会逐行成为“输出候选项”**。调用函数时，会从候选项中随机选择一个并返回。赋值（`_a = 1`）之类的语句不会成为候选项。
- 字符串用 `"..."` 括起来。Sakura Script 也是字符串，因此必须括起来。
- 变量有类型（整数、实数、字符串、数组、哈希）。无需声明。以 `_` 开头的名称是局部变量。
- 函数外不能写语句或变量。只有 `#define` 等预处理指令可以写在函数外。
- `if` `while` 的条件表达式可以加括号，也可以不加（`if (_a == 1)` 和 `if _a == 1` 相同）。`for` `foreach` 也可以用 `( )` 括住整个头部（Tc603-6 及之后版本支持；更早的版本会报错）。
- 符号请使用半角字符（不能使用全角的 `（` 或 `＋`）。

## 函数的写法

```
OnBoot
{
  _name = "さくら"
  "\0\s[0]こんにちは、%(_name)さん。\e"
  "\0\s[0]起動しましたね。\e"
}
```

- 在上面的例子中，会随机返回 `"\0\s[0]こんにちは…"` 和 `"\0\s[0]起動しましたね。\e"` 中的一个（`_name = …` 不会成为候选项）。
- **每行只能有一个候选项**。如果像 `"a" "b"` 这样在同一行排列多个候选项，会报错。`"a" / "b"` 中的 `/` 是除法运算符，不是候选项分隔符。
- 单独一行写 `--`，就会将前后的候选项分成不同的组，并从每组中各选一个，然后连接起来（[函数](../grammar/02-functions.md)）。
- `{` 可以和函数名写在同一行，也可以写在下一行。
- 注释可以写成 `// 到行末` 或 `/* 多行 */`。
- 在一行中写多个语句时，用 `;` 分隔（`_a = 1 ; _b = 2`）。

### 参数和返回值

| 写法 | 含义 |
|--------|------|
| `Func(1, "a")` | 带参数调用。没有参数时只写 `Func` 即可 |
| `_argv[0]` `_argv[1]` | 接收到的参数（从 0 开始编号） |
| `_argc` | 参数的数量 |
| `Func(&_v)` | 通过引用传递变量。在 `Func` 中执行 `_argv[0] = 99` 时，`_v` 会发生变化 |
| `return` | 在此处结束函数。从此前的候选项中选择一个并返回 |
| `return 表达式` | **舍弃此前的所有候选项**，并返回表达式的值（Tc573-1 及之后版本） |

### 候选项的选择方式

在函数名后用 `:` 指定（`Seq : sequential`）。

| 指定 | 行为 |
|------|------|
| （无） | 从候选项中随机选择一个 |
| `nonoverlap` | 不连续选择与上次相同的候选项 |
| `sequential` | 按顺序从上往下返回，到末尾后再回到开头 |
| `array` | 将所有候选项组成通用数组并返回 |
| `void` | 执行函数体，但不返回任何内容 |
| `all` | 将所有候选项连接成一个字符串并返回（Tc567-1 及之后版本） |
| `last` | 返回最后一个候选项（Tc567-1 及之后版本） |

除了选择方式外，还可以添加以下修饰符。

| 指定 | 行为 |
|------|------|
| `_pool` | 将内层代码块（包括 `if` 的内容）中的候选项拆开，使它们与外层候选项的选择概率相同 |
| `_pool_nonoverlap` `_pool_sequential` | 对拆开的所有候选项使用避免重复或按顺序选择的方式 |
| `melt_` | 如果选中的输出是通用数组，就将其中的元素拆开并加入外层代码块的候选项 |

```
OnTest : _pool
{
  "x"
  {
    "y"
    "z"
  }
}
```

- 不加 `_pool` 时，内层的 `{ }` 整体是一个候选项（`x` 的概率为 1/2，`y` 和 `z` 的概率各为 1/4）。添加 `_pool` 后，`x` `y` `z` 的概率各为 1/3。
- 如果 `if` 条件为假，就不会加入其中的候选项。可以通过 `if 条件 { "b" "c" }` 的写法，实现“仅当条件为真时才增加候选项”。
- `while` `for` `foreach` 中的候选项会在每次循环时各加入一个。
- 像 `nonoverlap : {` 这样指定了选择方式的代码块，不会被拆开，而是作为一个候选项。

详情请参阅[函数](../grammar/02-functions.md)。

## 值和类型

| 类型 | 写法 | 示例 |
|------|--------|----|
| 整数 | 十进制、`0b`（二进制）、`0x`（十六进制）。64 位 | `10` `0b1010` `0xa` |
| 实数 | 添加小数点 | `3.14` |
| 字符串 | `"..."`（会展开）、`'...'`（不会展开） | `"a%(_x)"` `'a%(_x)'` |
| 多行字符串 | `<<"` … `">>`（会展开）、`<<'` … `'>>`（不会展开） | |
| 通用数组 | `(1, "a", 2.5)` | [数组](../grammar/05-arrays.md) |
| 简易数组 | 以逗号分隔的字符串 `"a,b,c"` | 同上 |
| 哈希 | `IHASH("キー", 値, …)`（Tc600-3 及之后版本） | [哈希](../grammar/12-hash.md) |
| VOID | 未定义的变量、超出范围的元素 | 字符串中为空，数值中为 0 |

- 字符串中的 `"` 需要连续写两次（`"1""2"` → `1"2`）。
- 使用 [GETTYPE](../functions/GETTYPE.md) 查询类型（VOID 为 0，整数为 1，实数为 2，字符串为 3，通用数组为 4，哈希为 5）。
- 将实数转换为字符串时，小数点后会有 6 位（`3.0/4*100` → `75.000000`）。
- 整数相除时会向下取整（`4/3` → `1`）。其中一个数为实数时，结果也为实数。

## 变量

| 写法 | 含义 |
|--------|------|
| `_a = 1` | 局部变量。只在该函数内部（以及内层代码块中）有效。离开代码块后会消失 |
| `a = 1` | 全局变量。可以在任何函数中使用。退出时会自动保存，并在下次启动时恢复 |
| `ERASEVAR("a")` | 删除全局变量 |
| `_a++` `_a--` `_a += 2` | 加法、减法和复合赋值（还包括 `-=` `*=` `/=` `%=`） |

- 未定义的变量在计算时视为 0，在字符串中视为空字符串（`UNDEF + 1` 为 `1`）。
- 不能使用以数字开头的名称，也不能使用与保留字或函数名相同的名称（[保留字](../grammar/09-reserved-words.md)）。

## 运算符

按优先级从高到低排列（[算术运算](../grammar/04-arithmetic.md)）。

| 类型 | 运算符 |
|------|--------|
| 括号・下标 | `( )` `[ ]` |
| 否定 | `!` |
| 自增自减 | `++` `--` |
| 乘除 | `*` `/` `%` |
| 加减 | `+` `-` |
| 比较 | `==` `!=` `>=` `<=` `>` `<` `_in_` `!_in_` |
| 逻辑 | `&&` `\|\|` |
| 赋值 | `=` `+=` `-=` `*=` `/=` `%=` `,=` |
| 逗号（创建数组） | `,` |

- `0` 为假，非 0 为真。比较结果为 `1` 或 `0`。
- `"or" _in_ "World"` 在右侧字符串包含左侧字符串时，结果为 `1`。
- `+` 在任一操作数为字符串时表示**连接**（`"5" + 1` 为 `"51"`）。`*` 则按数值计算（`"5" * 2` 为 `10`）。
- `==` 区分大小写（`"abc" == "ABC"` 为 `0`）。
- 没有三元运算符（`? :`）。

## 控制结构

```
if _a < 3
{
  "小"
}
elseif _a < 10
{
  "中"
}
else
{
  "大"
}
```

| 要实现的功能 | 写法 |
|--------------|--------|
| 二分支・多分支 | `if` / `elseif` / `else`（除嵌套的 `if` 外，单条语句可以省略 `{ }`） |
| 按值分支 | `case 式 { when 值 { … } when 值1, 值2 { … } others { … } }` |
| 按位置选择 | `switch 式 { 候选0 候选1 … }`（每个候选占一行。从 0 开始计数） |
| 按条件重复 | `while 条件 { … }` |
| 按次数重复 | `for _i = 0 ; _i < 10 ; _i++ { … }`（三个部分均为必填。Tc603-6 及以后版本可以用 `( )` 括住整个头部） |
| 依次遍历数组 | `foreach 配列 ; _v { … }` |
| 遍历键和值 | `foreach 配列またはハッシュ ; _k, _v { … }`（Tc600-3 及以后版本） |
| 跳出循环・继续下一轮 | `break` / `continue` |

```
case _name
{
  when "さくら" { "さくらだね" }
  when "うにゅう", "うに" { "うにゅうだね" }
  others { "だれ？" }
}
```

- `case` 的 `when` 中只能写**字面量**（不能写变量或表达式）。范围写作 `3-5` 或 `"a"-"d"`。
- `when` 和 `others` 要写在紧跟 `case 式` 的 `{ }` 中。不加 `{` 就接着写 `when`，读取时会出错（E0051）。
- 循环次数有上限（默认为 1000000 次。`looplimit`）。超过上限时会调用 `OnLoopLimit`。
- `while 1` 是无限循环。务必写上 `break`。

## 字符串嵌入

| 写法 | 含义 |
|--------|------|
| `"%(_a)"` `"%(1+2)"` | 对表达式求值并嵌入（带范围的展开） |
| `"%_a"` | 按名称最长匹配进行嵌入。由于运行时会查找名称，因此速度较慢 |
| `'%(_a)'` | 使用单引号时不展开 |

详情请参阅[字符串嵌入](../grammar/06-string-embedding.md)。

## 数组

```
_a = (10, 20, 30)
_a[1]            // 20
_a[0,1]          // 範囲（10,20）
_a ,= 40         // 末尾に追加
_a = ("先頭", _a) // 先頭に追加
_a + "!"         // 全要素に演算（10!,20!,…）
ARRAYSIZE(_a)    // 要素数
```

- 越界元素为 VOID（`GETTYPE(_a[9])` 为 0）。
- 简易数组会以字符串形式保留，并通过下标读写（`_s = "a,b,c"` → `_s[1]` 为 `b`）。可以像 `_s[1,"|"]` 这样指定分隔符。
- 获取数组元素数请使用 [ARRAYSIZE](../functions/ARRAYSIZE.md)，搜索请使用 [ASEARCH](../functions/ASEARCH.md)，排序请使用 [ASORT](../functions/ASORT.md)，分割请使用 [SPLIT](../functions/SPLIT.md)。

## 哈希（Tc600-3 及以后版本）

```
_h = IHASH("name", "さくら", "age", 16)
_h["name"]        // さくら
_h["age"] += 1    // 複合代入も使える
_h["none"]        // VOID（キーが無い）
foreach _h ; _k, _v { … }
```

- 必须先使用 `IHASH()` 创建哈希。
- 元素按键的顺序排列（而非插入顺序）。
- 元素中也可以存放数组或哈希（[值的嵌套](../grammar/13-nesting.md)）。

## 预处理器

| 写法 | 含义 |
|--------|------|
| `#define 前 後` | 替换该文件中此行之后的字符串 |
| `#globaldefine 前 後` | 替换此后读取的所有词典中的字符串 |
| `#ifdef 名前` … `#else` … `#endif` | 如果名称已定义，则读取（Tc574-2 / Tc602-2 及以后版本） |
| `__AYA_SYSTEM_YAYA6__` | 使用 600 系列时已定义（可用于兼容 500 系列的词典） |
| `__AYA_SYSTEM_FILE__` `__AYA_SYSTEM_LINE__` `__AYA_SYSTEM_FUNC__` | 替换为文件名・行号・函数名 |

详情请参阅[预处理器](../grammar/08-preprocessor.md)。

## 设置文件（yaya.txt）

```
dic, basis.dic
charset, UTF-8
log, executelog.txt
```

| 设置 | 含义 |
|------|------|
| `dic, 文件` | 读取词典（`dicif` 仅在文件存在时读取，`dicdir` 则读取文件夹内的所有文件） |
| `charset, UTF-8` | 字符编码（也可以通过 `charset.dic` 等按用途分别指定） |
| `log, 文件` | 输出执行日志 |
| `fncdepth, 数` | 函数调用深度上限（默认为 32。设为 0 时深度不受限制，但栈空间所剩不多时会停止） |
| `looplimit, 数` | 循环次数上限（默认为 1000000） |
| `embed.lazy, off` | 在读取时确定 `"%名前"` 中的名称（默认为 on，即在运行时查找） |

- 设置文件的名称是在 DLL 名称后加上 `.txt`（`yaya.txt`）。可以用 `//` 和 `/* */` 编写注释。
- 如果设置文件不存在，或没有读取任何词典，则进入**外壳模式**。它会直接对发送的表达式执行 `EVAL` 并返回结果，可用于检查表达式的行为（[基本设置](../grammar/01-basic-settings.md#シェルモード)）。

详情请参阅[基本设置](../grammar/01-basic-settings.md)。
