# 运算符

用于进行计算。

## 算术运算符

也就是加、减、乘、除。

| 运算符 | 说明 | 示例 |
|--------|------|-----|
| `x + y` | 将 x 与 y 相加 | `1+1` → `2` |
| `x - y` | 从 x 中减去 y | `2-1` → `1` |
| `x * y` | 将 x 与 y 相乘 | `6*2` → `12` |
| `x / y` | 将 x 除以 y。余数舍去 | `4/3` → `1` |
| `x % y` | 求 x 除以 y 的余数 | `4%3` → `1` |

计算 `x % 2`，结果为 0 时是偶数，为 1 时是奇数，可以这样使用。

## 逻辑运算符

用于判断是否相等、不相等、大于或小于某个值等，也就是判断条件为“真”还是“假”（正确还是不正确）。大多用于 `if` 语句或 `for` 语句等之后，作为分支或循环的条件。通过条件分支，可以根据切换来源的人格名称、累计启动时间等改变对话。

| 运算符 | 说明 |
|--------|------|
| `x == y` | x 与 y 相同时为真 |
| `x != y` | x 与 y 不同时为真 |
| `x && y` | x 和 y 都为真时为真。`&&` 前后的两者都为真时结果为真（AND） |
| `x \|\| y` | x 或 y 为真时为真。`\|\|` 前后任意一方为真时结果为真（OR） |
| `x > y` | x 大于 y 时为真。不包含相等的情况。`10 > 1` 为真，`10 > 100` 和 `10 > 10` 为假 |
| `x >= y` | x 大于或等于 y 时为真。包含相等的情况。`10 >= 1` 和 `10 >= 10` 为真，`10 >= 100` 为假 |
| `x < y` | 与 `>` 相反。x 小于 y 时为真 |
| `x <= y` | 与 `>=` 相反。x 小于或等于 y 时为真 |
| `!x` | 非 x（取反）。`!(1==1)` 为假。像这个例子一样，通常会写成 `1!=1` |
| `y _in_ x` | 字符串 x 中包含 y 时为真。`"さくら" _in_ "あさくら"` 为真。请注意顺序 |
| `y !_in_ x` | 字符串 x 中不包含 y 时为真。`"さくら" !_in_ "あさくら"` 为假。请注意顺序 |

## 字符串运算

使用 `+` 连接字符串。

```
_c = "さくら" + "と" + "うにゅう"
// 結果: "さくらとうにゅう"
```

## 数组操作

使用 `,` 将 x 和 y 组成一个数组。

```
_array = (_hoge, _fuga, _gonyo)
```

`_array` 中会存入三个值。
