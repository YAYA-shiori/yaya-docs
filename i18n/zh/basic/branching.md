# 分支处理

## 概要

可以根据表达式正确与否来分支处理。几乎总是与[逻辑运算符](operators.md#論理演算子)一起使用。

## if〜else〜 语句

```
if (式)
{
  "正しい"
}
else
{
  "正しくない"
}
```

如果「式」正确，则执行前面的 `{}` 中的处理；如果不正确，则执行 `else` 后面的 `{}`。表达式中可以写 `_name == "さくら"` 这样的比较。

```
_name = "さくら"
if (_name == "さくら")
{
  "さくらです"
}
else
{
  "さくらじゃない！"
}
```

## case〜when 语句

基于标签的分支。执行 `case` 表达式的值与 `when` 的值一致的代码块。

```
case _value
{
  when 1
  {
    // _value が 1 の場合
  }
  when 2, 3
  {
    // _value が 2 または 3 の場合
  }
  others
  {
    // どれにもマッチしない場合
  }
}
```

## switch 语句

按位置（从 0 开始）选择输出候选项。

```
switch _n
{
  "ゼロ番目"
}
{
  "一番目"
}
{
  "二番目"
}
```
