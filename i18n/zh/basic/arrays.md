# 数组

## 概要

数组类似于一组变量。

如果使用普通变量，

```
_a = 1
_b = 2
_c = 3
_d = 4
_e = 5

_sum = _a + _b + _c + _d + _e
```

而使用数组时，

```
_a = (1,2,3,4,5)

_sum = _a[0] + _a[1] + _a[2] + _a[3] + _a[4]
```

就可以这样写。请注意，索引从 0 开始，因此最后一个索引是 4。

将数组与循环结合使用，才能真正发挥它的威力。不必像刚才那样写出 `_a[0]`、`_a[1]`、`_a[2]`、……，也可以这样写。

```
_a = (1,2,3,4,5)

_sum = 0
for _i = 0 ; _i < 5 ; _i++
{
  _sum += _a[_i]
}
```

使用变量 `_i`，也可以取得 `_a` 中各个值，而不必逐一写出 `_a[0]`、`_a[1]`、`_a[2]`、……。在 `for` 循环中，只要 `_i` 小于 5，就会每次递增 1，因此会依次访问 `_a[0]`、`_a[1]`、`_a[2]`、……。

## 使用 ARRAYSIZE 动态获取大小

上面的例子要求事先知道数组的大小是 5。按下面这样写，就不必考虑数组的大小。

```
_a = (1,2,3,4,5)

_sum = 0
for _i = 0 ; _i < ARRAYSIZE(_a) ; _i++
{
  _sum += _a[_i]
}
```

[ARRAYSIZE](../functions/ARRAYSIZE.md) 会判断 `_a` 的数组大小并返回 5。只要 `_a` 是数组，无论其大小是多少都可以这样写。

数组中也可以存放字符串。

```
_sweets = ("プリン", "チョコレート", "クレープ", "甘口いちごスパ")
_talk = ""
for _i = 0 ; _i < ARRAYSIZE(_sweets) ; _i++
{
  _talk += _sweets[_i] + "に"
}
"\1\s[10]\0\s[0]" + _talk + "・・・今日は全部食べちゃうよ！\1なんかまざっとる！\e"
```

## foreach 循环（最简单的方法）

使用 `foreach` 时，不必写 `_i = 0`、`ARRAYSIZE` 或 `_i++`。只需写出相当于 `_a[_i]` 的内容（此处为 `_var`）。

```
_a = (1,2,3,4,5)

_sum = 0
foreach _a ; _var
{
  _sum += _var
}
```

`_var` 会依次取得 `_a` 中的内容。到达数组末尾后，循环会自动结束。
