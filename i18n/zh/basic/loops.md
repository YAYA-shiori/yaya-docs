# 循环

## for 循环

`for` 语句的写法如下。

```
for 初期条件 ; 終了条件 ; 各ループの最後に実行される処理
{
  ...
}
```

例如，要循环 10 次时，

```
for _i = 0 ; _i < 10 ; _i = _i + 1
{
  _i + "回目\n"
}
```

可以这样写。输出结果会从第 0 次到第 9 次，每次换行。请注意，每次循环最后执行的处理（`_i = _i + 1`），会在该次循环的处理，也就是输出 `_i + "回目\n"` 之后执行。

在这个例子中，输出 `"9回目\n"` 后，`_i` 加 1 变为 10，判定条件为假，因此循环结束。从 0 到 9，共循环 10 次。

循环语句中常用的运算符有 `++`、`--`、`+=`、`-=` 等。

| 运算符 | 含义 |
|--------|------|
| `a++` | `a = a+1` |
| `a--` | `a = a-1` |
| `a+=b` | `a = a+b` |
| `a-=b` | `a = a-b` |

因此，上面的 `for` 语句也可以写成下面这样。

```
for _i = 0 ; _i < 10 ; _i++
{
  _i + "回目\n"
}
```

**注意：** 条件表达式通常不加括号，但也可以像 `while (_i < 10)` 这样加上括号。像 `for (_i = 0; _i < 10; _i++)` 这样将整个头部括起来的写法，从 Tc603-6 起可以使用（Tc603-5 及更早版本会报错）。

## while 循环

除了 `for` 语句，也可以使用 `while` 语句编写循环。

```
while ループ継続条件
{
  ...
}
```

前面的 `for` 语句可以写成下面这样。

```
_i = 0
while _i < 10
{
  _i + "回目\n"
  _i++
}
```

如果 `while` 语句的判定表达式始终为真，就会形成无限循环，导致处理无法结束。

```
while 1 == 1
{
  ...
}
```

`1 == 1` 是恒等式，始终成立，因此会形成无限循环。另外，在 YAYA 中，bool 值（布尔值）根据数值是否为 0 来判定，因此下面的写法也会形成无限循环。

```
while 1
{
  ...
}
```

## break 语句

如果想在 `for` 或 `while` 语句执行过程中跳出循环，可以使用 `break`。

```
_i = 0
while 1
{
  if _i >= 10
  {
    break
  }
  _i + "回目\n"
  _i++
}
```

这个处理看起来会形成无限循环，因为 `while` 语句的条件表达式始终为真；但其中包含了“当 `_i` 达到 10 或更大时执行 `break`”的处理，因此最终效果与前面循环 10 次的语句相同。
