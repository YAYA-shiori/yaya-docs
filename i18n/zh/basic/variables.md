# 变量

## 概述

变量就像一个可以保存数值或字符（字符串）的盒子。既然是盒子，就需要放入内容；放入新内容后，原来的内容会被覆盖。

**注意：** 变量只能在函数中声明。

## 基本用法

```
_a = 1
_b = 2
```

将 1 放入 `_a`，将 2 放入 `_b`。放入内容后，就可以使用这些变量。

```
_c = _a + _b
```

这样一来，1 + 2 的结果 3 就会放入 `_c` 中。

## 字符串变量

变量也可以存放字符。

```
_a = "紅茶"
_b = "ケーキ"
```

字符也可以用 `+` 相加。因此，

```
_c = _a + "と" + _b
```

这样写后，`_c` 中的内容会变成 `"紅茶とケーキ"`。

## Sakura Script 的处理

Sakura Script 必须以字符串的形式写出才会执行。例如，

```
\![open,inputbox,OnTest,60000]
```

这样写并不能正常工作。这种情况下，

```
"\![open,inputbox,OnTest,60000]"
```

必须这样写。

## 展开变量

要在对话中显示变量的内容，请写成 `%(变量名)`。

```
_hoge = "紅茶"
"\0\s[0]飲み物なら%(_hoge)をどうぞ\e"
```

这样写后，会显示“飲み物なら紅茶をどうぞ”。
