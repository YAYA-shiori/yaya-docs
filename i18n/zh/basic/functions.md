# 函数

函数名也可以使用全角字符。

## 基本的函数定义

```
Test{
  "Hello World!"
}
```

这个 `Test` 函数会输出字符串 `"Hello World!"`。YAYA 的一个特点是，如果存在不是赋值表达式的普通变量或字符串（此例中的 `"Hello World!"`），它就会被视为返回值。

也就是说，

```
Test{
  _A = 10
  _B = 11+32
  "Hello World!"
}
```

即使这样写，返回值也会是 `"Hello World!"`。

花括号也可以按下面这样书写。

```
Test
{
  "Hello World!"
  "Hallo Welt!"
}
```

## 多个返回值候选项

如果有多个返回值候选项，就会随机选择其中一个。

```
Test{
  A = 10
  "Hello World!"
  "Hallo Welt!"
  10
  11+32
}
```

此例中会返回 `"Hello World!"`、`"Hallo Welt!"`、`10`、`43` 中的任意一个。

## 参数

可以向函数传入参数。接收到的参数会存储在局部变量数组 `_argv` 中，参数个数（`_argv` 的大小）会存储在 `_argc` 中。

```
てすと{
  "入力は「" + _argv[0] + "」だよ"
}
```

定义上述函数后，

```
てすと("うかがか")
```

像这样调用，就会输出 `"入力は「うかがか」だよ"`。

## 当前函数名

局部变量 `_FUNC_NAME_` 中存储着当前正在执行的函数名。随着各种动态定义命令（例如 [APPEND_RUNTIME_DIC](../functions/APPEND_RUNTIME_DIC.md)）的扩充，为了方便而添加了这个变量。

## 变量的定义

可以在函数内自由声明变量。无论是局部变量还是全局变量，都只能在函数内定义。变量名以 `_` 开头时会被视为局部变量，否则会被视为全局变量。

| 类型 | 名称 | 作用域 |
|------|------|---------|
| 局部变量 | 以 `_` 开头 | 仅限定义它的花括号内 |
| 全局变量 | 不以 `_` 开头 | 函数执行并定义一次后，就可以在任何地方使用。即使结束人格也会保留 |

如需删除全局变量，必须使用 [ERASEVAR](../functions/ERASEVAR.md) 函数。

```
テスト2{
  _aa = 200  // これはローカル
  bb = 200   // これはグローバル
}
```

只在函数内使用的变量等，尽量使用局部变量，这样不容易产生错误。例如，循环处理的计数器应像下面这样使用局部变量（`_i`）。

```
テスト2{
  for _i = 0; _i < 10; _i++
  {
    _i + "\n"
  }
}
```

## 调用次数限制

可以通过[基础设置文件中的 `fncdepth`](../grammar/01-basic-settings.md)设置函数调用深度（而非调用次数）。默认值为 32 层。

达到限制时，会调用 [shiori.OnCallLimit](../system/shiori-OnCallLimit.md)(函数名, 行)。执行过程中内存耗尽时会调用 [shiori.OnMemoryLimit](../system/shiori-OnMemoryLimit.md)()，但无法捕获堆栈溢出。
