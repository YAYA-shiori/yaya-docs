# ISREALSTR
**Category:** 文字列操作

## Signature
```
ISREALSTR(string)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| string | 要判断的字符串 |

## Returns
- 1：可以作为实数解释
- 0：不能作为实数解释

## Description
判断给定字符串能否作为实数解释。

## Compatibility
- YAYA: 从初始版本起可用
- AYA: 5.8及之后可用
