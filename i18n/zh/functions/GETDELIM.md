# GETDELIM
**Category:** 配列操作

## Signature
```
GETDELIM( var )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| var | 要查询分隔符的简易数组变量 |

## Returns
指定变量中设置的分隔符字符串。

## Description
获取变量中设置的分隔符（简易数组的分隔字符）的函数。默认分隔符为逗号（`,`）。

用于确认通过 SETDELIM 更改后的分隔符。

## Compatibility
- YAYA：从初始版本起可用
- AYA：5.8 及以后版本可用
