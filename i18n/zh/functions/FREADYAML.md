# FREADYAML
**Category:** ファイル操作

## Signature
```
FREADYAML( path [, charset] )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| path | 要读取的 YAML 文件路径（相对于 yaya.dll 的路径，或绝对路径） |
| charset | 文件的字符编码（可选）。可指定为字符串（`"UTF-8"` `"Shift_JIS"` 等。[字符编码名称](../grammar/11-character-encoding.md#文字コードの名前)）或数值。省略时默认为 UTF-8 |

## Returns
- 成功时：转换 YAML 后得到的值（见下文的[值的对应关系](#値の対応)）
- 失败时：空（VOID）

## Description
读取并解析整个 YAML 文件，将其转换为哈希、数组等值后返回。无需通过 [FOPEN](FOPEN.md) 打开文件。

YAYA 会自行解析 YAML。它支持设置文件等常见场景中经常使用的语法范围（见下文的[支持的写法](#対応している書き方)），但并未完全实现 YAML 规范。

- 忽略开头的 UTF-8 BOM。换行符可以是 CRLF 或 LF
- 空文件或仅包含注释的文件会返回空（VOID），不会报错

### 支持的写法

| 写法 | 示例 |
|--------|----|
| 块格式的映射和序列 | `key: value`、`- item`。也支持在 `key:` 下方以相同缩进排列 `- item` 的写法 |
| 流格式 | `[1, 2]`、`{a: 1, b: 2}`。也支持嵌套和跨多行的写法 |
| 不加引号的字符串 | 可以跨多行（换行会变为空格，空行会保留为换行） |
| 加引号的字符串 | `'...'`（用 `''` 表示 `'`）、`"..."`（支持 `\n` `\t` `\"` `\\` `\x41` `あ` `\U0001F600` 等转义） |
| 块标量 | `\|`（保留换行）、`>`（将换行变为空格）。也支持设置末尾换行的处理方式 `\|-` `\|+`，以及指定缩进 `\|2` |
| 注释 | 从 `#` 到行尾（在值后添加注释时，`#` 前必须有空格） |
| 锚点和别名 | 为值添加 `&name`，然后通过 `*name` 引用该值（复制该值） |
| 合并键 | 使用 `<<: *name` 或 `<<: [*a, *b]` 引入映射。显式指定的键和先写入的键优先 |
| 文档分隔符 | 开头的 `---`（以及其前面的 `%YAML` 等指令）、末尾的 `...` |
| 标签 | `!!str`（以及 `!`）会将值设为字符串。即使值加了引号，`!!int` `!!float` `!!bool` `!!null` 也会指定其类型。其他标签会被忽略 |

以下写法不受支持。使用这些写法时会产生 W0026。

- 一个文件中包含多个文档（第二个 `---`）
- 复合键（以 `? ` 开头的键，或使用流格式书写的键）
- 使用制表符缩进（值中可以使用制表符）

### 值的对应关系

类型按照 YAML 1.2 Core Schema 的规则确定。

| YAML | YAYA |
|------|------|
| 映射 | 哈希。键始终为字符串 |
| 序列 | 通用数组（元素中可以嵌套数组或哈希） |
| 整数（`123` `-4` `0o17` `0x1F`） | 整数。超出十进制整数范围的值会作为实数处理 |
| 实数（`1.5` `1e3` `.5` `.inf` `-.inf` `.nan`） | 实数 |
| `true` / `false`（也包括 `True` `TRUE` 等） | 整数 1 / 0 |
| `null` / `~` / 无值 | 空（VOID） |
| 其他值、加引号的值、块标量 | 字符串 |

- 与 YAML 1.1 的处理程序有以下区别：`yes` `no` `on` `off` 会作为字符串处理，`017` 会作为十进制的 17 处理，`1_000` 会作为字符串处理，`2001-12-14` 这样的日期也会作为字符串处理
- 映射中键的顺序不会保留。键的顺序与哈希相同（参见 [HASH_KEYS](HASH_KEYS.md)）。`1` 这样的规范形式整数键可以通过 `h[1]` 或 `h["1"]` 获取
- 同一个键写了两次时，使用后写入的值
- 嵌套层级过深（超过 256 层），或别名复制的元素总数超过 100 万时，会报错（以防恶意文件耗尽内存）

### 错误
| 情况 | 警告 | [GETLASTERROR](GETLASTERROR.md) |
|------|------|------|
| 未提供参数 | W0008 | 8 |
| path 不是字符串 | W0009 | 9 |
| charset 无效 | W0012 / W0009 | 12 / 9 |
| 无法打开文件 | W0025 | 25 |
| 无法作为 YAML 解析，或使用了不支持的写法 | W0026（同时输出行号和原因） | 26 |

## Example
config.yaml:
```yaml
# ゴーストの設定
name: さくら
age: 17
height: 158.5
visible: true
memo: ~
tags: [ghost, shell]
talk:
  greeting: |
    こんにちは。
    今日もいい天気ですね。
  random:
    - おはよう
    - こんばんは
defaults: &defaults
  volume: 80
  speed: 2
voice:
  <<: *defaults
  speed: 3
```

```
_y = FREADYAML("config.yaml")
_y["name"]                   // さくら
_y["tags"][1]                // shell
_y["height"]                 // 実数の 158.5
_y["visible"]                // 1
_y["memo"]                   // 空（VOID）
_y["talk"]["greeting"]       // "こんにちは。" + 改行 + "今日もいい天気ですね。" + 改行
_y["talk"]["random"][0]      // おはよう
_y["voice"]["volume"]        // 80（defaults から取り込んだもの）
_y["voice"]["speed"]         // 3
```

## Compatibility
- YAYA：Tc602-5 及以后
- Tc603-1：传入未知的字符编码名称时，会发出警告 W0012 并失败（此前不会发出警告，而是按操作系统默认编码处理）
