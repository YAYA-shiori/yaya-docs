# ARRAYDEDUP

**Category:** 配列操作

## Signature

```
ARRAYDEDUP(array)
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| array | 通用数组 |

## Returns

返回去除重复元素后的通用数组。

## Description

被视为相同的元素会保留第一个。结果的顺序并非原数组的顺序，而是与[哈希键](../grammar/12-hash.md#並び順)相同。

从 Tc600-3 起，元素是否相同以及排序顺序改为遵循与哈希键相同的规则。

- 整数、实数以及表示规范形式整数的字符串，如果值相同，就视为相同元素（`1`、`1.0`、`"1"` 相同）
- 按数值 < 字符串的顺序排列
- 数组或哈希的元素按内容比较。内容相同的哈希会合并为一个，内容不同的哈希会保留下来
- VOID 之间视为相同元素

元素类型统一的数组（仅包含整数、仅包含实数或仅包含字符串）的结果与之前相同。

## Example

```
ARRAYDEDUP((3, 1, 2, 1))                    // 1,2,3
ARRAYDEDUP((10, "9", 9, "a", 1.0, 1, "1"))  // 1.000000,9,10,a （Tc600-3以降）
```

## Compatibility

- YAYA：Tc568-1 及更高版本
- Tc600-3：修正了混合类型数组的结果会因排列顺序而异的问题，改为按照与哈希键相同的规则进行比较
