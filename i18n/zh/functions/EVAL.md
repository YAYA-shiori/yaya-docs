# EVAL

**Category:** メタ操作・特殊関数

## Signature

```
EVAL( string )
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| string | 作为 YAYA 脚本执行的文本字符串。可以是一个表达式，或一系列语句（Tc574-6 / Tc602-9 及更高版本） |

## Returns

- 成功时：执行结果。如果只有赋值而没有输出，则为 VOID（无返回值）
- 解析失败时：原样返回参数字符串

## Description

将参数字符串作为 YAYA 脚本执行。可用于展开表达式，或在运行时合成函数名等。

### 一个表达式

如果字符串是一个表达式，则返回该表达式的求值结果。赋值表达式会将值赋给调用方的变量。

```
_x = EVAL('1 + 2')          // 3
EVAL('_name = "Emily"')     // 呼び出し元のローカル変数 _name に代入される
```

### 一系列语句（Tc574-6 / Tc602-9 及更高版本）

如果引号外存在 `;`、`{`、`}` 或换行符，或者首个词是 `return` `if` `while` `for` `foreach` `switch` `void` `parallel` 之一，则会作为一系列语句执行。写法与在函数主体的 `{ }` 内编写相同。

```
_r = EVAL('_a = 1; _b = _a + 2; _b')   // 3

_r = EVAL('if _hour < 12 { "おはよう" } else { "こんにちは" }')

_r = EVAL('_s = 0; foreach _list; _v { _s += _v }; _s')
```

传入包含换行符的字符串，例如通过此处文档传入的字符串，就可以像在词典中编写一样书写。换行符与 `;` 一样用作语句分隔符，也可以使用 `//` 或 `/* */` 注释，以及通过行末的 `/` 连接行。

```
_code = <<'
_s = 0
for _i = 1; _i <= 10; _i++ {
	_s += _i
}
_s
'>>
_r = EVAL(_code)   // 55
```

从 Tc574-8 / Tc603-1 起，也可以在传入的代码中书写此处文档。

返回值遵循与函数返回值相同的规则。如果有多个作为输出的表达式，则会从中选取；可以使用 `--` 连接输出，书写 `return` 则会在该处结束执行并返回其值。

一系列语句的执行方式与在调用方的 `{ }` 中编写一个代码块相同。

- 可以读写调用方的局部变量（包括 `_argv` 和 `_argc`）
- 在其中新建的局部变量会在 EVAL 结束时消失
- `break` / `continue` / `return` 会在 EVAL 内部生效，不会影响调用方的循环或函数

```
Foo
{
	_count = 1
	_r = EVAL('_count += 10; _tmp = _count * 2; _tmp')
	// _r は 22、_count は 11、_tmp はここでは存在しない
}
```

不能书写函数定义或 `#define` 等预处理器指令。要定义函数时，请使用 APPEND_RUNTIME_DIC。

如果只需执行包含控制结构的代码，也可以使用 APPEND_RUNTIME_DIC，但 EVAL 的速度更快。APPEND_RUNTIME_DIC 需要注册到函数表，而 EVAL 只需创建一个执行用代码块并运行即可。

引号中的 `;`、`{`、`}` 和换行符不会被视为分隔符。`EVAL('"a;b"')`，以及用 `"` 括起包含换行符的字符串来展开嵌入元素的用法，仍会像以前一样作为一个表达式求值。

### 在字符串中包含 `"` 或 `%` 时

在要传给 EVAL 的字符串中使用双引号时，请使用 `CHR(34)`。例如，要将 `"test"` 赋给变量 `i`，请按如下方式书写（Tc569-8 及更高版本也可以连续书写两个 `""`。[值和变量](../grammar/03-values-and-variables.md#文字列)）。

```
EVAL("i=%(CHR(34))test%(CHR(34))")
```

如果希望在 EVAL 执行时展开 `%`，也要将 `%` 写为 `CHR(37)`。下面的示例会执行 `"%(foo)"`。

```
EVAL("%(CHR(34))%(CHR(37))(foo)%(CHR(34))")
```

将 EVAL 的结果转换为字符串的 `TOSTR(EVAL("formula"))` 和嵌入展开 `"%(formula)"` 会产生相同的结果。

## Example

```
EVAL("i=1")

EVAL("i=%(CHR(34))test%(CHR(34))")

EVAL("%(CHR(34))%(CHR(37))(foo)%(CHR(34))")

EVAL('_n = 0; while _n < 3 { _n++ }; _n')   // 3
```

## Compatibility

- YAYA：从初始版本起支持
- AYA：5.8 及更高版本
- Tc574-6 / Tc602-9：新增了执行一系列语句的功能（以 `;` 或换行符分隔的多个语句，以及 if/for 等控制语句）（此前只能执行一个表达式，传入一系列语句时会解析失败并原样返回参数字符串）
- Tc574-8 / Tc603-1：新增了在传入的代码中使用此处文档的功能（此前会发生 E0007）
