# ANY

**Category:** 文字列操作

## Signature

```
ANY(var)
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| var | 随机选择的对象。可以是字符串、通用数组、整数或实数 |

## Returns

成功时：随机选中的一个元素
失败时：VOID

将字符串作为简易数组处理时，从中随机返回 1 个元素。如果以变量形式传入，则会考虑该变量的分隔符。对于通用数组，也会随机返回 1 个元素。对于数值类型（整数、实数），则原样返回该值。可以使用 LSO 函数获取所选元素的索引。

## Example

```
_array = ('さくら','まゆら','ねここ')
ANY(_array)  // 「まゆら」などランダムな要素を返す

_str = 'さくら,まゆら,ねここ'
ANY(_str)    // 「ねここ」などランダムな要素を返す

LSO          // 2（「ねここ」のインデックス）を返す
```

## Compatibility

- YAYA：从初始版本起可用
- AYA：5.8 及更高版本
