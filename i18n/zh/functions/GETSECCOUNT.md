# GETSECCOUNT
**Category:** システム情報

## Signature
```
GETSECCOUNT( [yyyy|datetext [, mm [, dd [, wd [, HH [, MM [, SS [, timezone]]]]]]]] )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| yyyy | 公历年份（4位） |
| mm | 月（1〜12） |
| dd | 日 |
| wd | 星期（指定 0。无论指定什么值都会被忽略） |
| HH | 小时 |
| MM | 分钟 |
| SS | 秒 |
| timezone | （可省略）指定日期时间的时区。省略时使用操作系统的本地时间。写法与 [GETTIME](GETTIME.md#タイムゾーンの指定) 相同 |
| datetext | 替代指定：`'Sun, 06 Nov 1994 08:49:37 GMT'` 或 `'2024-01-01T09:00:00+09:00'` 格式的日期字符串 |

## Returns
从 EPOCH（1970/1/1 00:00:00 UTC）到指定日期时间（或当前日期时间）经过的秒数（数值）

## Description
返回从 EPOCH 到当前时间或指定日期时间经过的秒数的函数。相当于 C 语言的 `time()` 函数。

- 省略所有参数时，使用当前时间
- 省略部分参数时，省略的值会使用 `timezone` 中的当前时间值补全
- 值可以超出通常的日期范围（例如：指定月份为 13 时会变成次年的 1 月）
- 年月日等会被解释为本地时间。UTC 或其他时区的日期时间请通过第 8 个参数 `timezone` 指定（`GETSECCOUNT(2024,1,1,0,0,0,0,'UTC')`）。本地时间的夏令时会根据指定日期时间对应的规则判断

### 日期字符串
`datetext` 可以读取以下格式。HTTP 格式中的星期可以省略。

```
Sun, 06 Nov 1994 08:49:37 GMT      RFC 822 / RFC 1123
Sunday, 06-Nov-94 08:49:37 GMT     RFC 850（年が2桁のときは 70-99 が19xx、00-69 が20xx）
Sun Nov  6 08:49:37 1994           C の asctime
2024-01-01T09:00:00+09:00          ISO 8601
```

ISO 8601 可以读取以下形式。

| 形式 | 示例 |
|----|----|
| 日期 | `2024-01-01`（时间为 00:00:00） |
| 日期和时间 | `2024-01-01T09:30`、`2024-01-01T09:30:15`、`2024-01-01 09:30:15`（`T` 也可以是小写字母或空格） |
| 小数秒 | `2024-01-01T09:30:15.123`（小数秒部分会被截去） |
| 时区 | `Z`、`+09:00`、`+0900`、`+09`、`-05:00` |
| 基本格式 | `20240101`、`20240101T093015Z` |

无法读取不存在的日期（`2024-02-30`）或超出范围的时间（`25:00`）。`24:00:00` 会作为次日0时处理，秒数 `60` 会作为闰秒处理。

- 如果末尾带有时区（HTTP 格式如 `GMT`、`+0900`、`+09:00`、`-0500`、`JST` 等，ISO 8601 格式如 `Z` 或 `+09:00`），则会按该日期时间读取。示例中的 `GMT` 字符串无论运行环境的时区如何，都会得到 `784111777`
- 未注明时区的日期字符串（如 asctime 格式、`2024-01-01T09:00:00`）会作为本地时间读取
- 对于无法读取的字符串、无法识别月份名称的字符串或不存在的日期，会发出警告 W0012（[GETLASTERROR](GETLASTERROR.md) 返回 12）并返回 `-1`。超出范围的值也会如此

## Example
```
// 2006年14月25日 15:56:40 のEPOCH秒を取得し、GETTIMEで日付に変換する例
// （月14 = 翌年2月）
_array = GETTIME(GETSECCOUNT(2006, 14, 25, 0, 15, 56, 40))
"%(_array[1])月%(_array[2])日"
// 結果: "2007年2月25日" のように表示される

// UTCの日時から求める
_sec = GETSECCOUNT(2024, 1, 1, 0, 0, 0, 0, 'UTC')   // 1704067200

// ISO 8601 の文字列から求める
_sec = GETSECCOUNT('2024-01-01T09:00:00+09:00')     // 1704067200
```

## Compatibility
- 从 YAYA 的初始版本起即可使用
- Tc606-1 及以后：新增第 8 个参数 `timezone` 和 ISO 8601 日期字符串
- Tc606-1：修正了将日期字符串中写明的时区误读为本地时间的问题，此前会导致日本时间偏差 9 小时（`-0500` 这样的负偏移量和 RFC 850 格式的两位数年份也无法正确读取）。无法读取的字符串会返回 `-1` 并显示警告。此外，还修正了将 2100 年之后的年份计为闰年，以及在采用夏令时的时区中按照当前夏令时规则转换日期时间的问题
