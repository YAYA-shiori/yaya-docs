# FCLOSE

**Category:** ファイル操作

## Signature

```
FCLOSE( path )
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| path | 由 FOPEN 指定的、相对于 yaya.dll 的文件路径 |

## Returns

无返回值（VOID）。

## Description

关闭通过 FOPEN 打开的文件。

## Compatibility

- YAYA: 从初版起支持
- AYA: 5.8 及以上版本
