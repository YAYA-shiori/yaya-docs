# FOPEN

**Category:** ファイル操作

## Signature

```
FOPEN(path, option)
```

## Parameters

| 参数 | 说明 |
|-----------|-------------|
| path | 文件名。可以指定完整路径。相对路径以 DLL 的 load 所传入的位置为基准 |
| option | 指定如何打开文件。指定下方「模式」或「别名」中的字符串 |

### 文本访问

| 模式 | 别名 | 行为 | 文件存在时 | 文件不存在时 |
|--------|------|------|--------------------|--------------------|
| `"r"` | `"read"` | 读取文本 | 正常 | 错误 |
| `"w"` | `"write"` | 写入文本 | 将大小设为 0（覆盖） | 新建 |
| `"a"` | `"append"` | 追加写入文本 | 追加到末尾 | 新建 |

### 二进制访问

| 模式 | 别名 | 行为 | 文件存在时 | 文件不存在时 |
|--------|------|------|--------------------|--------------------|
| `"rb"` | `"read_binary"` | 读取二进制数据 | 正常 | 错误 |
| `"wb"` | `"write_binary"` | 写入二进制数据 | 将大小设为 0（覆盖） | 新建 |
| `"ab"` | `"write_binary_append"` | 追加写入二进制数据 | 追加到末尾 | 新建 |

### 随机访问

| 模式 | 别名 | 行为 | 文件存在时 | 文件不存在时 |
|--------|------|------|--------------------|--------------------|
| `"r+"` | `"read_random"` | 读写文本 | 正常 | 错误 |
| `"w+"` | `"write_random"` | 读写文本 | 将大小设为 0（覆盖） | 新建 |
| `"a+"` | `"append_random"` | 读写文本 | 追加到末尾 | 新建 |
| `"rb+"` | `"read_binary_random"` | 读写二进制数据 | 正常 | 错误 |
| `"wb+"` | `"write_binary_random"` | 读写二进制数据 | 将大小设为 0（覆盖） | 新建 |
| `"ab+"` | `"append_binary_random"` | 读写二进制数据 | 追加到末尾 | 新建 |

## Returns

- 1：成功
- 0：失败
- 2：文件已打开

## Description

打开文件。

- 对文件进行读写之前，必须先用 `FOPEN` 打开文件
- 进行文本访问时，可以在调用 `FOPEN` 之前执行 [FCHARSET](FCHARSET.md) 来更改字符编码
- 简而言之，这与 C 语言的 `fopen` 相同。YAYA 内部也是用 C 语言的 `fopen` 实现的
- 文本访问时，读取前会将 0x0d-0x0a 的序列（CR-LF）转换为单个 0x0a。反之，写入时会将 0x0a 转换为 0x0d-0x0a。此外，0x1a 具有作为 EOF 的特殊含义
- 随机访问时，可以用 [FSEEK](FSEEK.md) 指定文件读取位置，用 [FTELL](FTELL.md) 获取位置

## Compatibility

- YAYA：从首次发布起即可使用（仅限文本访问）
- AYA：5.8 及以上版本（仅限文本访问）
- TC529-2：新增二进制访问和随机访问
