# TRANSLATE
**Category:** 文字列操作

## Signature
```
TRANSLATE( text, format_from, format_to )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| text | 要替换的字符串 |
| format_from | 替换前的字符列表（具有格式，见下文） |
| format_to | 替换后的字符列表。指定空字符串时会删除字符 |

## Returns
- 成功：替换后的字符串
- 失败：-1

## Description
按字符快速替换字符串。提供与 Perl 的 tr///（不带选项）相当的功能。

### 格式

**简单列举**：将字符一对一映射。列表中没有的字符不会改变。
```
TRANSLATE('ぬるぽガッ', 'ぽガ', 'りゴ') // 'ぬるりゴッ'
TRANSLATE('あああいいいううう', 'あい', 'おえ') // 'おおおえええううう'
```

**范围指定**：使用「-」指定字符代码范围并进行批量替换。使用的字符代码为 UCS-2（Unicode），建议将 IME 的字符面板切换到 Unicode 模式后确认。
```
TRANSLATE('123456789', '1-9', '①-⑨') // '①②③④⑤⑥⑦⑧⑨'
```

**转义**：使用 `\-` 指定字面量连字符，使用 `\\` 指定字面量反斜杠。

```
TRANSLATE('\-\-\-', '\\', '\-') // '------'
```

**删除**：将第 3 个参数指定为空字符串时，会删除对应字符。
```
TRANSLATE('46cm三連装砲', '0-9a-z', '') // '三連装砲'
```

## Example

将平假名转换为片假名，将片假名转换为平假名。

```
_wokyu = TRANSLATE('ティータイムは大事にしないとネー', 'ぁ-ゖァ-ヶ', 'ァ-ヶぁ-ゖ')
// _wokyu の中身 = てぃーたいむハ大事ニシナイトねー
```

指定 Unicode 表中平假名和片假名的重叠范围「ァ-ヶ」。如果词典使用 Shift_JIS 编写，「ゖ」会出现乱码，此时请改用以下写法。

```
_wokyu = TRANSLATE('ティータイムは大事にしないとネー', 'ぁ-んァ-ン', 'ァ-ンぁ-ん')
```
