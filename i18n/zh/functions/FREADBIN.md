# FREADBIN

**Category:** ファイル操作

## Signature

```
FREADBIN( path , size [ , char ] )
```

## Parameters

| 参数 | 说明 |
|-----------|-------------|
| path | 由 FOPEN 打开的文件名 |
| size | 要读取的字节数。指定 0 时读取整个文件 |
| char | 替换空字节（0x00）时使用的字符（省略时为空格） |

## Returns

- 成功时：读取到的数据字符串
- 到达文件末尾时：-1
- 失败时：空字符串

不进行字符编码转换，直接读取二进制数据。为避免行末转换，建议预先通过 FOPEN 指定二进制模式。空字节（0x00）会被替换为指定字符（这是因为 YAYA 有一项限制：字符串中不能包含字节值 0）。如果未通过二进制访问模式打开 FOPEN，则会进行换行符转换。

## Compatibility

- YAYA：Tc516-901 及以上版本
- 注意：在 Tc540-3 之前，存在因强制转换错误导致 0x80 以上的字节被错误转换为 0xFF80 区段的错误
