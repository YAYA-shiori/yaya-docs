# ISVAR
**Category:** 型取得/変換

## Signature
```
ISVAR(string)
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| string | 要确认是否存在的变量名字符串 |

## Returns
- 0：变量不存在
- 1：全局变量存在
- 2：局部变量存在

## Description
确认指定名称的变量是否存在。

## Compatibility
- YAYA：从初始版本起可用
- AYA：从版本5.8起可用
