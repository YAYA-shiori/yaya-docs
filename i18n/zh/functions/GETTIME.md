# GETTIME
**Category:** システム情報

## Signature
```
GETTIME( [ sec [, timezone ] ] )
```

## Parameters
| Parameter | Description |
|-----------|-------------|
| sec | （可选）从 EPOCH（1970年1月1日 00:00:00 UTC）起经过的秒数（整数）。省略时返回当前系统时间 |
| timezone | （可选）用于计算日期时间的时区。省略时使用 OS 本地时间（[指定时区](#タイムゾーンの指定)） |

## Returns
返回具有以下结构的通用数组：

| 索引 | 值 | 详情 |
|------------|---|------|
| 0 | 年 | 公历年份 |
| 1 | 月 | 月 |
| 2 | 日 | 日 |
| 3 | 星期 | 0〜6（0=星期日） |
| 4 | 时 | 24 小时制 |
| 5 | 分 | 分 |
| 6 | 秒 | 秒 |
| 7 | 年内经过天数 | 从年初起经过的天数（1月1日为0） |
| 8 | 夏令时标志 | 0=标准时间 / 1=夏令时 |

如果 `sec` 超出可处理范围（约±9亿年），则会发出警告 W0012（[GETLASTERROR](GETLASTERROR.md) 为 12），并返回 `-1`。

## Description
获取当前日期和时间信息。省略 `timezone` 时，其行为与 C 语言的 `localtime` 函数相同。

指定 `sec` 时，会将其解释为从 EPOCH 起经过的秒数，并返回对应的日期时间信息。与 GETSECCOUNT 结合使用，可以用于计算例如 10 天后的日期。

本地时间的夏令时状态根据 `sec` 所在时刻的规则判定（而不是根据当前时刻是否处于夏令时判定）。

### 指定时区
`timezone` 可指定以下任意一种值。

| 指定值 | 含义 |
|------|------|
| 省略、`""`、`"local"` | OS 本地时间 |
| `"UTC"`、`"GMT"`、`"Z"` | UTC |
| `"+09:00"`、`"+0900"`、`"+09"`、`"-5"` | 相对于 UTC 的固定偏移量（小时、分钟。东为正） |
| `"JST"`、`"EST"`、`"EDT"`、`"CST"`、`"CDT"`、`"MST"`、`"MDT"`、`"PST"`、`"PDT"` | 按名称指定的固定偏移量 |
| 整数 | 相对于 UTC 的固定偏移量（**秒**，东为正。`32400` 表示 `+09:00`）。小于±24小时 |

指定固定偏移量时不考虑夏令时，夏令时标志（索引8）始终为0。无法解析指定值时，会发出警告 W0012（GETLASTERROR 为 12），并按本地时间处理。

## Example

当前时间的 `sec` 可通过 [GETSECCOUNT](GETSECCOUNT.md) 获取。利用这一点，可以轻松计算“从现在起○天后 / 之前的时间”。

```
//10日後は何月何日？
_array = GETTIME()
"今は%(_array[0])年%(_array[1])月%(_array[2])日　%(_array[4])時%(_array[5])分%(_array[6])秒／"
--
_array = GETTIME(GETSECCOUNT(_array[0],_array[1],_array[2] + 10,0,_array[4],_array[5],_array[6]))
"10日後は%(_array[0])年%(_array[1])月%(_array[2])日　%(_array[4])時%(_array[5])分%(_array[6])秒\n"
```

```
// UTCでの日時
_utc = GETTIME(GETSECCOUNT(), 'UTC')

// 1970/1/1 00:00:00 UTC は、日本時間（+09:00）では 9時
_jst = GETTIME(0, '+09:00')      // 1970,1,1,4,9,0,0,0,0
```

## Compatibility
- YAYA：从初始版本起即可使用
  - Tc542-1 及之后：新增年内经过天数（索引7）和夏令时标志（索引8）
  - Tc606-1 及之后：新增 `timezone` 参数
- Tc606-1：修正了 Windows 上年内经过天数从1月1日计为1的问题，改为与 `localtime` 相同，从0开始计数。并将夏令时标志，以及夏令时会随时节变化的时区中的时间，改为根据 `sec` 所在时刻而非当前时刻判定
- AYA 5.8：仅支持不带参数的调用
