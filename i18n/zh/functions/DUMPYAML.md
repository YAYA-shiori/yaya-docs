# DUMPYAML
**Category:** 型取得/変換

## Signature
```
DUMPYAML( value [, pretty] )
```

## Parameters
| 参数 | 说明 |
|-----------|-------------|
| value | 要转换为 YAML 的值。哈希和数组（包括嵌套结构）也可以作为一个参数传入 |
| pretty | 为 1 时使用块格式（通过缩进表示结构，便于阅读和编写），为 0 时使用流格式输出为一行。省略时为 1 |

## Returns
- 成功时：YAML 字符串
- 没有参数时：空字符串

## Description
将值转换为 YAML 字符串并返回。这是 [PARSEYAML](PARSEYAML.md) 的逆向转换。

与 [DUMPJSON](DUMPJSON.md) / [DUMPXML](DUMPXML.md) 不同，省略 pretty 时会进行格式化（为 1）。

### 值的对应关系

| YAYA | YAML |
|------|------|
| 哈希 | 映射。键会转换为字符串（`1` 会变成 `"1"`）。顺序与哈希键的顺序一致 |
| 通用数组 | 序列 |
| 整数 | 整数。64 位整数也能无误差地写入 |
| 实数 | 实数。一定会带小数点（`1.0`、`0.1`、`1.0e+300`）。NaN 为 `.nan`，无穷大为 `.inf` / `-.inf` |
| 字符串 | 字符串（见下文） |
| 空（VOID） | `null` |

- 整数 1 / 0 会写成 `1` / `0`，不会写成 `true` / `false`
- 小数点不受区域设置影响，始终为 `.`

如果字符串直接写入后读回仍能得到相同的字符串，就不加引号；否则会用 `"..."` 括起来。以下情况会使用 `"..."`。

- 会被读取为数值、布尔值或 null 的内容（`"123"` `"1.5"` `"true"` `"null"` `"~"`）
- 可能会被其他处理程序（YAML 1.1）读取为数值或布尔值的内容（`"yes"` `"no"` `"on"` `"off"` `"0x1F"` `"2001-12-14"` `"12:30"`）
- 空字符串、开头或结尾带空格的字符串、以符号（`- ? : , [ ] { } # & * ! | > ' " % @` 和 `` ` ``）开头的字符串
- 包含 `: ` 或 ` #` 的字符串，以及包含控制字符（如制表符）的字符串

在 `"..."` 内，只有 `"` `\` 和控制字符会进行转义（换行符为 `\n`）。日文等非 ASCII 字符会原样写入。

### 格式化方式（pretty 为 1）

- 使用两个空格缩进，换行符为 LF。最后一行后也会添加换行符
- 序列会缩进到键的下方，并以 `- ` 列出。序列中的哈希或数组会紧接在 `- ` 后写入
- 空数组和空哈希会写成 `[]` / `{}`
- 包含换行符的字符串会使用块标量（`|`）。末尾没有换行符时使用 `|-`，末尾有两个或更多换行符时使用 `|+`。但是，如果第一行以空格开头、存在仅包含空格的行，或包含 CR 等控制字符，则会使用 `"..."`

pretty 为 0 时使用流格式输出为一行（`{a: 1, b: [x, y]}`），末尾不添加换行符。

使用 [PARSEYAML](PARSEYAML.md) 读回后会还原为原来的值（两种格式均可）。

### 错误
| 情况 | 警告 | [GETLASTERROR](GETLASTERROR.md) |
|------|------|------|
| 没有参数 | W0008 | 8 |

## Example
```
_h = IHASH()
_h["name"] = "さくら"
_h["tags"] = ("ghost", "shell")
_h["height"] = 158.5

DUMPYAML(_h)
// height: 158.5
// name: さくら
// tags:
//   - ghost
//   - shell

DUMPYAML(_h, 0)
// {height: 158.5, name: さくら, tags: [ghost, shell]}

DUMPYAML(("a", 1))          // "- a" + 改行 + "- 1" + 改行
DUMPYAML("123", 0)          // "123"（数値と区別するためクォートされる）
DUMPYAML(未定義の変数, 0)    // null
```
