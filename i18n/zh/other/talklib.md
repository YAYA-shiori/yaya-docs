# 对话直接书写辅助库「Ayari Riris EX」

> 转载自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

每次都要写等待标签，很麻烦？

写 `\s[]` 之类的东西，会不会太费时间？

用 Sakura Script 写文章，之后很难修改，令人头疼？

……那么，就用这个吧。

### 概要

> "`\u\s[10]\0\s[2]`…`\w5`…`\w5`…`\w5`…`\w5`…`\w5\w9\w9\1`怎么了，`\w5`摆出一张蠢得像白痴的脸。`\w9\w9\0\s[7]\n\n`电池都快报废了，`\w9\n`还请不要让电脑一直处于休眠状态！`\w9\n`会变笨的！`\w9\w9\1\n\n`…`\w5`…`\w5`我本来就没聪明过。`\w9\w9\0\s[26]\n\n`…`\w5`…`\w5`…`\w5`…`\w5\e`"

这样的词典……

```
<<"
ま０５：分かりました！分かりましたよ！２０年モノのパソコンがどうなるのか！
し１０：スクラップやのうて？
ま　　：付喪神っていう便利な言葉が、世の中にはあるんですよ！
し１１：…まあ、ゴーストにはなったがな？
">>
```

会变成这样。

**即使导入本库，使用标准 Sakura Script 单行编写的对话也会原样放行（也可以调整为仅对标点添加等待等）。**

**文中的 Sakura Script 会照常执行。需要进行细致调整，或者想在中途调用简单说话以外的功能时，请直接编写 Sakura Script。**

### 前期准备

1. 由于会大量使用最新的系统词典和最新版本的 YAYA 功能，请覆盖更新 yaya.dll 和「系统词典」。
1. 保存 [aya_lilith_ex.dic](http://ms.shillest.net/ghost/mobilemaster/ghost/master/aya_lilith_ex.dic) 和 [aya_lilith_ex_config.dic](http://ms.shillest.net/ghost/mobilemaster/ghost/master/aya_lilith_ex_config.dic)，并将它们放入 ghost/master 目录下。
1. 在 yaya.txt 的 **include, system_config.txt** 后面附近，
dic, aya_lilith_ex.dic<br>
dic, aya_lilith_ex_config.dic<br>
请追加以上内容。

打开 **aya_lilith_ex_config.dic**，分别适当地设置 **あやりりすEXヘッダ0**・**あやりりすEXヘッダ1**。设置方法写在词典内的注释中；通常只需写入多个想要使用的单字符候选项，并用方括号括起来，例如 [まマ]。

※进阶：此处可以使用正则表达式。若想使用两个或更多字符，请尝试想办法实现。

### 用法

使用了 YAYA 较新版本中新增的多行文本编写功能（Here Document）。

用 " " 括起来的文本

```
<<"
">>
```

与用 ' ' 括起来的文本

```
<<'
'>>
```

效果相同。这两种写法的区别仅在于，后者可以直接编写多行文本。

使用此功能，基本上按以下方式编写即可。

```
<<"
ま０５：分かりました！分かりましたよ！２０年モノのパソコンがどうなるのか！
し１０：スクラップやのうて？
ま　　：付喪神っていう便利な言葉が、世の中にはあるんですよ！
し１１：…まあ、ゴーストにはなったがな？
">>
```

开头的第一个字符「ま」「し」请替换为在aya_lilith_ex_config.dic中设置的字符。

其后的全角数字是surface编号（表情ID）。使用半角数字也可以。

标点符号以及换行时的等待时间等会适时自动插入。通常直接编写即可。

如果想实现特殊效果，可以直接使用Sakura Script。此外，也可以像以往一样，与包含Sakura Script的单行文本共存。

### 语法

```
ま０５：てすとてすと
```

「：」前面是定义表情及其他选项的部分，后面是说出的文字。

基本形式是：设定的1个字符＋曲面编号：文本。曲面编号（表情ID）可以使用半角或全角字符；不过，保持日语输入法的转换模式并使用全角字符输入会比较方便。

```
ま０５「かぎかっこでもいけるよ」
```

也可以用引号括起来，不过要记得正确闭合引号。

```
ま消：きゃー消えちゃった―
```

用「消」代替编号，就会隐藏窗口（角色会隐藏起来）。

```
ま　：さっきの表情のままね
```

什么都不写的话，就会保持之前的表情。空格（无论全角还是半角）都会被忽略。

```
二人：バルス！
```

写上「二人」，两个角色就会同时说话。

```
ま０７し１１二人：バルス！
```

这种写法也可以组合多个选项。上面的例子中，会先将两个角色分别切换为7号和11号表情，再让他们同时说话。

```
待ち無しま０５：あまり待たない
待ちゼロま０５：ぜんぜん待たない
待ち多めま０５：ふつうより長めに待つ
```

为了在紧接着插入吐槽，或演出较长时间的思考，可以像这样控制开始说话前的等待时间。此外，**即使完全不写，系统也会自动适当地加入等待时间**。

```
クリック待ちま０７：クリック待ってる
```

写上「クリック待ち」，就会在开始说话前等待用户点击对话框。

```
改行無しま０５：改行しないよ
```

写上「改行無し」，就可以不换行，只改变表情，并接着之前说过的内容显示。

```
改行多めま０８：改行しまくり！
```

会多换几行。适用于分隔段落等情况。

```
ま００：（ユーザ）さん！
```

可以在文字中插入用户名。此设置仅适用于「：」后面的说话文本部分。

```
ま０５：（チョコ｜菓子パン｜ケーキ）食べよう！
```

用「｜」分隔字符串并用括号括起来，就会随机选择其中一个。

```
＃コメントなので無視
```

以＃开头的行会被完全忽略。

```
＠設定：パッシブモード
＠設定：クイックセクション
＠設定：タイムアウト1000「時間切れ」
```

以「＠設定：」开头的行是与后续对话相关的选项设置。上面的示例分别表示：

- 被动模式（忽略除鼠标响应以外的所有内容）
- 快速区段（忽略所有字符等待，一瞬间显示全文）
- 超时（等待后续数字所指定的毫秒数，等待结束后调用用「」括起来的函数）

分别表示如下。

```
＠メニュー：さんぷる１｜Sample1Execute
＠半分メニュー：さんぷる２｜さんぷる２実行
＠改行多めメニュー：さんぷる３｜OnTest3Exec｜R0
＠クリック待ちメニュー：さんぷる４｜さんぷる4実行
```

以「＠～メニュー：」开头的行用于显示菜单。<br>
半幅菜单会在标准尺寸的对话框中横向排列，每行两个选项。<br>
添加“换行较多”后，每次换行会占用一行半的空间。可用于分隔选项等。<br>
添加“点击等待”后，显示菜单后会立即进入点击等待(`\x`)状态。

后面的内容以｜分隔。第一项是显示的文本，第二项及之后是要执行的函数／事件。

另外，**菜单内会自动成为快速区段**，所有内容都会一口气显示，不带任何等待。

### 自动链式对话与随机选择

```
ま０５：ちぇいんてすと。
し１０：うまくいくやろか。
=====
ま０５：ちぇいん2-Aにきたよ。
し１０：成功やね。
-----
ま０５：ちぇいん2-Bにきたよ。
し１０：ここはランダムや。
```

用 =====（5 个以上的 =）分隔时会成为链式对话，用 -----（5 个以上的 -）分隔时会成为随机选择。

例如上面的例子中，说完第一个 ===== 之前的内容后，对话会暂时结束；到下次说随机对话时，会从第二段和第三段对话中随机选择一段。

### 常见问题

**为什么叫 EX？**：以前有个事件处理辅助库叫「あやりりす」，但它还有很多依赖，没法从这里拆分出来……顺带一提，另外还有用于术语解释的库。

**为什么要写这个？**：从 Twitter 等地方收到点子当然很好，但要把「ラ『咕噜咕噜』テ『咕噜咕噜』」这种格式一个个全部改写成 Sakura Script，实在是**非常麻烦**……
