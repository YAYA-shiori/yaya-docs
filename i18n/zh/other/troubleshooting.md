# 遇到问题时的处理方法

> 转自 [AYAYA Wiki](https://emily.shillest.net/ayayaold/)

开发相关的问题请在伺か开发论坛<http://ghost.sakura.tv/fluxbb/viewforum.php?id=4>
中提出

### 运行缓慢

是否仍然启用了运行日志记录？<br>
请重新检查文档设置文件aya.txt。<br>

或者，是否在「`***_shiori3.dic`」中设置了「获取已安装人格列表」？<br>
请尝试减少获取的最大数量。如果完全不使用人格列表，设为0也没有问题。<br>

### 选项有时可以选择，有时无法选择

可能有某处忘记写{}的闭合符号。<br>

### 即使选择了选项，也只会说「1」。

如果文Ver5.0～Ver5.2之前的版本中，OnChoiceSelect指定的函数内可能包含以下字符。

```
(　)　[　]　!　++　--　*　/　%　+　-　&　==　!=　<=　>=　<　>　_in_　!_in_
&&　||　=　:=　+=　-=　*=　/=　%=　+:=　-:=　*:=　/:=　%:=　,=
```

如果修改函数名，使其不包含上述字符，就有可能恢复正常运行。<br>
（转自[:::et cetera. - bbs](http://umeici.hp.infoseek.co.jp/bbs2.html)）。

### 对话中混入了莫名其妙的「0」或「1」

赋值变量时，你是不是本想写「i = 1」，却写成了「i == 1」？

### 不再进行随机对话了

可能是删除了OnSecondChange。<br>
如果删除了它，就不会调用OnAiTalk。<br>
如果OnSecondChange中不执行任何操作，请<br>

```
OnSecondChange{}
```

这样写。（摘自[SatisFactory](http://www5d.biglobe.ne.jp/~satis/)的随笔）<br>

### 无法正常启动

很可能是脚本语法有误。<br>
如果使用文Ver.5，使用文Ver.5发布页面上的语法检查工具「玉」，就能发现大多数语法错误。

[使用玉检查词典错误](../tips/tama-error-check.md)

容易出错的例子。

- 忘记闭合 ' ' 或 " "
- 在 ' ' 中写入了 '，或在 " " 中写入了 "
  - %(CHR(0x22)) = " / %(CHR(0x27)) = '。请灵活运用。
- 把elseif写成了else if
- 没有写if，就直接从elseif开始
- ( ) 或 { } 过多或过少
  - 请寻找能够检查括号是否匹配的文本编辑软件（编辑器）
- 变量名、函数名的大小写
- 尝试使用从未用过的变量
  - 引用从未使用过的变量不会报错。
- 词典的字符编码错误
  - 仅限使用UTF-8词典的情况。当然，如果写成ShiftJIS，就会被大量莫名其妙的错误弄得焦头烂额。反过来也一样。

### 词典中所有特定函数都出现“参数类型不正确”错误

使用函数时，如果需要数值类型参数的位置传入了字符串类型参数，或者反过来，就可能导致包括正确书写的函数在内都出现错误。

即使是“可能传入非数值类型或非字符串类型的参数”，有时也会导致错误。请灵活使用TOINT和TOSTR。<br>

- 示例

```
i = TOSTR( i )
REPLACE( i , "abc" , "bca" )
```

### 执行SAORI时冻结

可能是路径的写法有问题。<br>
请写作"saori`\xxx`.dll"，而不是"saori\\`\xxx`.dll"或"saori/xxx.dll"。

### 想在Sakura Script的[]中写入「]」

请用""括起整个字符串。<br>
用「"」括起的内容中若要写入「"」，请写作「""」。

```
_txt=REPLACE(テキスト,'"','""')
_txt='"' + _txt + '"'
"\![open,input,ID,-1,%(_txt)]"
```

这里提供一个易于使用的函数。

```
ESCAPE_TEXT
{
	_r = _argv[0]
	if RE_SEARCH(_r,'["\[\]]') >= 0 {
		'"' + REPLACE(_r,'"','""') + '"'
	}
	else {
		_r
	}
}
```

把它写在某处，

```
ESCAPE_TEXT(テキスト)
```

这样应该就能正常工作。

### 发布人格时，不知道应该删除哪些文件

如果 ghost`\master` 内有以下文件，请将其移除。
（\*\*\*中的字符串因人格设置而异）

```
***_variable.cfg　（セーブデータ）
***.log　（AYA/YAYA実行ログ）
ssp_shiori_log.txt （SSP実行ログ）
「profile」フォルダまるごと
「var」フォルダまるごと
tama.exe
aycencode.exe
暗号化前の***.dic （※辞書の暗号化をしている場合）
```
