# 正则表达式

以 `RE_` 开头的系统函数可以使用正则表达式搜索、分割和替换字符串。本页介绍从 YAYA 使用正则表达式的基本方法，以及 Tc606-6 及之后版本支持的子例程调用。

Tc606-6 及之后版本使用 伺か 共用的正则表达式引擎 [uka_regexp](https://github.com/ukatech/uka_regexp)。其语法和含义与 PCRE2（Perl 兼容）相近。**语法细节（前瞻、后顾、Unicode 属性、递归、控制动词等）请参阅 [uka_regexp 的 README](https://github.com/ukatech/uka_regexp/blob/main/README.md)。** 本页介绍的基本写法仍可像以前一样使用。

## 函数的选择方法

| 想了解的内容 | 函数 |
|---|---|
| 字符串中是否存在匹配的部分 | [RE_SEARCH](../functions/RE_SEARCH.md) |
| 整个字符串是否匹配 | [RE_MATCH](../functions/RE_MATCH.md) |
| 查找所有匹配的部分 | [RE_GREP](../functions/RE_GREP.md) |
| 按匹配的部分分割字符串 | [RE_SPLIT](../functions/RE_SPLIT.md) |
| 替换匹配的部分 | [RE_REPLACE](../functions/RE_REPLACE.md)（不能使用 `$1` 等），[RE_REPLACEEX](../functions/RE_REPLACEEX.md)（可以使用） |
| 在数组中查找匹配的元素 | [RE_ASEARCH](../functions/RE_ASEARCH.md)（第一个），[RE_ASEARCHEX](../functions/RE_ASEARCHEX.md)（全部） |
| 检查匹配的内容、位置和长度 | [RE_GETSTR](../functions/RE_GETSTR.md)、[RE_GETPOS](../functions/RE_GETPOS.md)、[RE_GETLEN](../functions/RE_GETLEN.md) |
| 更改匹配条件 | [RE_OPTION](../functions/RE_OPTION.md) |

```
if RE_SEARCH(reference[0], 'こんに?ち[はわ]') {
  "こんにちは"
}
```

## 模式的写法

模式以字符串形式传递。**建议用单引号括起来**。双引号字符串中的 `%(...)` 等会作为嵌入内容展开，而单引号字符串不会展开。`\` 在两种字符串中都会原样传递给正则表达式，因此可以写成 `\d`。

```
RE_SEARCH("abc123", '\d+')    // 1
```

### 基本语法

| 写法 | 含义 |
|---|---|
| `abc`、`あ` | 匹配字符本身。具有特殊含义的符号（`.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `^` `$` `\|` `\`）前加 `\` 后，就表示符号本身 |
| `.` | 除换行符以外的任意一个字符 |
| `[abc]`、`[a-z]`、`[^abc]` | 字符集合、范围，以及集合之外的字符 |
| `\d` `\w` `\s` | 数字（`0-9`）、单词字符（`A-Za-z0-9_`）、空白字符（空格、制表符、换行符等） |
| `\D` `\W` `\S` | 除 `\d` `\w` `\s` 以外的字符 |
| `^`、`$` | 字符串的开头、末尾（使用 `m` 选项时为行首、行尾） |
| `\b` | 单词边界 |
| `*`、`+`、`?` | 重复 0 次以上、1 次以上、0 次或 1 次 |
| `{3}`、`{2,4}`、`{2,}` | 重复 3 次、2 到 4 次、2 次以上 |
| `*?`、`+?`、`??` | 尽可能短地匹配的重复（非贪婪匹配） |
| `a\|b` | `a` 或 `b` |
| `(...)` | 分组。可以提取匹配的内容，或在替换字符串中使用 |
| `(?:...)` | 不提取内容的分组 |
| `(?<name>...)` | 命名分组 |

!!! note "`\d` `\w` `\s` `\b` 仅匹配 ASCII"
    `\d` 不匹配全角数字，`\w` 不匹配日文字符。判断日文字符时，请使用 Unicode 属性。平假名使用 `\p{Hiragana}`，片假名使用 `\p{Katakana}`，汉字使用 `\p{Han}`。

    ```
    RE_SEARCH("あ", '\p{Hiragana}')            // 1
    RE_SEARCH("２０２４", '^\d+$')            // 0（全角の数字）
    RE_REPLACEEX("ひらがなカタカナ", '\p{Katakana}+', '[$0]')   // ひらがな[カタカナ]
    ```

可用的语法不止这些。有关前瞻 `(?=...)`、后顾 `(?<=...)`、占有量词、原子组、`\Q...\E` 等详细信息，请参阅 uka_regexp 的 README。

### 选项

可以通过 [RE_OPTION](../functions/RE_OPTION.md) 设置对之后调用的正则表达式函数生效的选项。**默认不启用任何选项。**

| 字符 | 含义 |
|---|---|
| `i` | 不区分大小写 |
| `m` | 使 `^` `$` 匹配行首和行尾（按多行模式处理） |
| `s` | 使 `.` 也匹配换行符 |
| `x` | 忽略模式中的空白，并将从 `#` 到行末的内容视为注释 |

```
RE_OPTION("im")
```

也可以在模式中指定选项。`(?i)` 会使其后内容不区分大小写，`(?i:...)` 只会使括号内的内容不区分大小写。使用 `(?-i)` 可以取消该设置。

```
RE_SEARCH("ABC", '(?i)abc')       // 1
RE_SEARCH("ABC", '(?i:a)BC')      // 1
```

默认情况下，只有 LF（`\n`）会被视为换行符。要将 CR LF 也视为换行符，请在模式开头写入 `(*ANYCRLF)`。

## 检查匹配的内容

匹配成功后，可以通过 [RE_GETSTR](../functions/RE_GETSTR.md)、[RE_GETPOS](../functions/RE_GETPOS.md)、[RE_GETLEN](../functions/RE_GETLEN.md) 以数组形式获取匹配内容、位置（从 0 开始）和长度。下次调用正则表达式函数时，这些结果会被覆盖。

```
_r = RE_SEARCH("abc123def", '(\d+)')
_s = RE_GETSTR()      // ("123", "123")
_p = RE_GETPOS()      // (3, 3)
_l = RE_GETLEN()      // (3, 3)
```

- 数组的第 0 个元素是整个模式匹配的部分。第 1 个及之后的元素是各分组（`(...)`）匹配的部分。命名分组也按编号排列
- **未参与匹配的分组不会放入数组**，因此后面的编号会前移。将 `(a)|(b)` 应用于 `"a"` 时，只会多出 1 个元素（整个匹配和 `(a)` 共 2 个）
- 在 [RE_GREP](../functions/RE_GREP.md) 和 [RE_SPLIT](../functions/RE_SPLIT.md) 中，每个匹配部分各占一个元素。RE_GREP 的返回值是匹配数量

```
_n = RE_GREP("a1b22c333", '\d+')   // 3
_s = RE_GETSTR()                   // ("1", "22", "333")
```

!!! warning "丢弃返回值会将其作为输出候选"
    如果像 `RE_SEARCH(...)` 这样不使用返回值，返回值就会混入函数的输出候选中。只想检查结果时，请将其赋值给变量，例如 `_r = RE_SEARCH(...)`。

## 替换

[RE_REPLACE](../functions/RE_REPLACE.md) 会直接使用替换字符串。[RE_REPLACEEX](../functions/RE_REPLACEEX.md) 的替换字符串可以使用以下写法。

| 写法 | 含义 |
|---|---|
| `$0`、`$&` | 整个匹配部分 |
| `$1`、`$2`、… | 第 1 个、第 2 个……分组。只有存在对应编号的分组时，`$10` 及以上才会作为两位数读取 |
| `${1}`、`${name}` | 按编号或名称指定（后面紧跟数字时很方便） |
| `` $` ``、`$'` | 匹配部分之前、之后的字符串 |
| `$+` | 已匹配分组中编号最大的分组 |
| `$_` | 整个原始字符串 |
| `$$` | 字符 `$` |
| `\1`〜`\9` | 与 `$1`〜`$9` 相同 |
| `\\` `\n` `\r` `\t` `\a` `\e` `\f` `\v` | 反斜杠、换行、回车、制表符等控制字符 |

未参与匹配的分组会变成空字符串。

```
RE_REPLACEEX("2024-05-17", '(\d+)-(\d+)-(\d+)', '$3/$2/$1')    // 17/05/2024
RE_REPLACEEX("abc", '(?<first>a)', '${first}-')               // a-bc
RE_REPLACEEX("aaaa", 'a', 'b', 2)                             // bbaa（2 回まで置換）
```

## 子例程调用（Tc606-6及之后版本）

可以按名称调用正则表达式中的组成部分。即使模式中没有 `(?<date>...)` 这样的定义，也可以**从 YAYA 的变量或函数中查找该名称，并将其作为模式导入**。

调用可以采用以下任意一种写法（含义相同）。

- `(?&name)`
- `(?P>name)`
- `\g<name>`、`\g'name'`
- `(?R<name>)`、`(?R'name')`

在单引号字符串中，包含 `'` 的写法需要将其连续写两次，写成 `''`（`'^\g''name''$'`）；也可以写在双引号字符串中。

```
_date = '\d{4}-\d{2}-\d{2}'
_r = RE_SEARCH("今日は2024-05-17です", '(?&date)')     // 1
```

### 名称的查找顺序

模式中没有定义的名称 `name` 会按以下顺序查找。找到的第一个可用值会成为组成部分。

1. 局部变量 `_name`（名称以 `_` 开头时，查找该名称的局部变量）
2. 全局变量 `name`
3. 函数 `name`（不带参数执行时的返回值）

- **可用值为字符串和数值**。VOID、数组和哈希不可用，因此会继续查找下一个候选项
- 如果找不到任何候选项，或导入的值不是合法模式，就会产生正则表达式错误（W0016）
- 如果找不到变量，就会执行同名函数。为避免意外执行函数，**组成部分的名称应与其他函数或变量的名称不同**
- 组成部分中还可以调用其他组成部分，也可以递归调用自身
- 每次调用正则表达式函数时，都会重新读取变量或函数的值。函数每次都会执行，因此也可以使用内容会因随机数而变化的函数，让模式每次都不同
- 如果模式中定义的命名分组（`(?<name>...)`）与名称相同，则会使用该定义，不会查找变量或函数

```
// 部品を関数で用意する
Digits4 { '\d{4}' }
Digits2 { '\d{2}' }

IsDate
{
  RE_MATCH(reference[0], '(?&Digits4)-(?&Digits2)-(?&Digits2)')
}
```

可以通过组合各个组成部分，让较长的模式更易于阅读。

```
_y = '\d{4}'
_m = '\d{2}'
_date = '(?&y)-(?&m)-(?&m)'
_r = RE_MATCH("2024-05-17", '(?&date)')     // 1
```

使用递归也可以匹配嵌套结构。以下示例会匹配括号成对的字符串。

```
_paren = '\((?:[^()]++|(?&paren))*\)'
_r = RE_MATCH("(a(b)c)", '(?&paren)')     // 1
```

!!! note "组成部分中的分组"
    组成部分中写入的 `(...)` 会在调用返回后从结果中消失。通过 [RE_GETSTR](../functions/RE_GETSTR.md) 等可以提取的只有调用方模式中的分组。此外，组成部分不会继承调用方模式中的 `(?i)` 等选项，而是从通过 [RE_OPTION](../functions/RE_OPTION.md) 设置的选项开始。

## 错误

| 情况 | 结果 |
|---|---|
| 模式语法不正确，或无法解析子例程名称 | 警告 W0016。按未匹配处理（`GETLASTERROR` 为 16） |
| 由于重复嵌套等原因导致回溯次数超过上限，或内存不足 | 警告 W0017。按未匹配处理（`GETLASTERROR` 为 17） |

对于 `(a+)+$` 这样会导致回溯次数呈指数增长的模式，应用于较长字符串时可能会达到上限。达到上限时会产生 W0017，并按未匹配处理。
