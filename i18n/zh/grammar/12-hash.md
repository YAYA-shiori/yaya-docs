# 哈希（Tc600-3 及以后）

从 Tc600-3 开始，值的类型中新增了**哈希**（关联数组）。

哈希的值和键中可以放入数组或哈希（嵌套）。有关嵌套读写和多维赋值，请参阅[值的嵌套与多维赋值](13-nesting.md)。

有关从 500 系列迁移时涉及的兼容性变更，请参阅[600 中的变更](../other/changes-600.md)。

## 创建

使用 [IHASH](../functions/IHASH.md) 创建哈希。键和值交替排列。`IHASH()` 会创建空哈希。

```
_h = IHASH("name", "さくら", "age", 16)
_e = IHASH()
```

从字符串创建时，使用 [HASH_SPLIT](../functions/HASH_SPLIT.md)。

```
_h = HASH_SPLIT("a=1,b=2", ",", "=")
```

哈希变量必须先通过 IHASH 等函数创建为哈希。即使对未定义变量写入 `_x["a"] = 1`，它也会被当作通用数组，而不是哈希（`"a"` 会被解释为数值 0，即第 0 个元素）。

## 元素的读取与赋值

使用 `h[键]` 读取值，使用 `h[键] = 值` 添加或覆盖值。

```
_h = IHASH()
_h["name"] = "さくら"
_h["name"]       // "さくら"
_h["none"]       // VOID （キーが無いときは未定義の変数と同じ）
_h["age"] += 1   // 複合代入も使える
```

- 键不存在时，与未定义变量一样返回 **VOID**（Tc603-1 及以后；截至 Tc602-13，返回的是空字符串）。由于它会被当作空字符串或数值 0，`_h["none"] == ""` 的结果为 1，`_h["none"] + 1` 的结果为整数 1（[超出范围的元素](05-arrays.md#範囲外の要素)）
- 复合赋值（`+=` `-=` `*=` `/=` `%=`）左侧的键不存在时，也会将其作为 VOID 计算（Tc602-10 及以后）。可以通过 `_count[_name] += 1` 计数。键存在但值为空字符串时，仍按原有方式将其作为空字符串计算（`"" + 1` 是 `"1"`）
- 要区分“键不存在”和“值为空字符串或 VOID”的情况，请使用 [HASH_EXIST](../functions/HASH_EXIST.md)
- 值中也可以放入数组或哈希（[嵌套](13-nesting.md)）
- 序数中的第 2 项及之后的内容（范围指定或分隔符）会被忽略。带范围的读取 `h[a, b]` 会返回空字符串

## 键的匹配

标量键分为“数值”和“字符串”进行比较。

- 按数值处理的内容：整数、实数、**表示规范形式整数的字符串**（例如 `"9"`、`"-3"`）
  - `"09"`、`"-0"`、`"+1"`、`" 1"`、无法用 64 位表示的数字序列会作为字符串处理
- 数值之间按数值比较。整数与实数之间也会进行无误差比较
- 字符串之间按字符串比较。VOID 与空字符串会成为相同的键

因此，`h[1]`、`h["1"]`、`h[1.0]` 都会成为**同一个键**。另一方面，`h[1.5]` 与 `h["1.5"]`、`h[0]` 与 `h["-0"]` 会成为不同的键。

如果多次将被视为相同键的值传给 IHASH，则会保留第一个键和值。

```
IHASH(9, "i9", "9", "s9")   // 9=i9 だけ
```

## 排列顺序

哈希的元素按**键的顺序**排列，而不是按插入顺序。[HASH_KEYS](../functions/HASH_KEYS.md)、[HASH_VALUES](../functions/HASH_VALUES.md)、字符串化、foreach 和存档文件中的排列都遵循此顺序。

- 按数值 < 字符串的顺序排列。数值之间按数值大小排列，字符串之间按字符串顺序排列
- 键为数组或哈希时，按标量 < 数组 < 哈希的顺序排列；数组之间和哈希之间则从首个元素开始依次比较

```
_h = IHASH(10,1, 9,1, 100,1, -1,1, "b",1, "B",1, 2.5,1)
HASH_KEYS(_h)   // -1,2.5,9,10,100,B,b
```

## 作为值时的行为

| 操作 | 结果 |
|---|---|
| 真值 | 有一个或多个元素时为真，空哈希时为假 |
| `GETTYPE` / `GETTYPEEX` | 5 |
| 字符串化（`TOSTR` 或与字符串连接） | 将 `键=值` 用 `,` 连接。例：`a=1,b=x` |
| 数值化 | 0 |
| `h1 == h2` | 元素数、键和值全部一致时为真。值有嵌套时，会比较到内部内容 |
| 哈希与非哈希之间的 `==` | 始终为假（即使字符串化结果相同也为假） |
| `+`（另一方是标量或哈希） | 将双方转换为字符串后连接 |
| `+`（另一方是数组） | 将哈希作为字符串，逐个与数组元素连接 |
| `-` `*` `/` `%` | 发出警告 W0024（如下所述） |

```
_h = IHASH("a", 1)
_h + 1        // "a=11"
'z' + _h      // "za=1"
_h + _h       // "a=1a=1"
(1,2) + _h    // ("1a=1","2a=1")
```

当 `-` `*` `/` `%`（包括复合赋值）的任一操作数是哈希时，会发出警告 W0024。结果方面，另一方是标量时会原样返回右侧操作数（`h - 1` 的结果是 `1`，`1 * h` 的结果是 `h`）；另一方是数组时则会逐个元素进行计算。由于结果没有实际意义，请勿使用。另外，数组元素为哈希时（`(h, 1) - 1`），不会发出 W0024。

## 函数参数与 `,` 运算符

通用数组会在参数或 `,` 运算符中展开，而哈希不会展开，会作为一个元素保留。

```
_a = (0, _h, 2)   // 要素数 3。_a[1] はハッシュ
func(_h)          // func の中で _argv[0] がハッシュになる
```

## foreach

哈希也可以用 foreach 遍历。采用单变量形式时，值会按键的顺序依次放入变量。

```
_h = IHASH("a", 1, "b", 2)
foreach _h ; _v
{
  // _v = 1, 2
}
```

写两个变量时，第一个变量接收键，第二个变量接收值。这种形式也适用于数组和简易数组，第一个变量接收从 0 开始的索引。

```
foreach _h ; _k, _v { _s += _k + '=' + _v + ' ' }   // "a=1 b=2 "
foreach ("p", "q") ; _i, _v { ... }                  // _i = 0, 1
foreach "x,y" ; _i, _v { ... }                       // 簡易配列も同じ
```

详情请参阅[流程控制](07-flow-control.md#foreach-ループ)。
