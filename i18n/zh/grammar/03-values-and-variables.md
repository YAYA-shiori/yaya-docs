# 值与变量

## 即值

YAYA 可以处理的值有整数、实数、字符串 3 种。

### 整数 (int)

带符号的 64bit 整数（Tc566-1 扩展。此前为 32bit）。十进制数值直接书写即可。在开头加上 `0b` 可以书写二进制数值，加上 `0x` 可以书写十六进制数值。

下面的函数 `int10` 返回整数 10。因为这 3 种写法的十进制值都是 10。

```
int10
{
    10
    0b1010
    0xa
}
```

### 实数 (double)

带符号的 64bit 浮点数。需要小数位，或者希望处理非常大的数值（即使精度有所下降）时使用。

整数和实数通过有无小数点来区分，YAYA 遇到数值中的小数点时，会将其作为实数处理。例如

```
Test
{
    3/4*100
}
```

这样写时，结果不是 75，而是 0。这是因为计算 `3/4` 时会将其解释为 int，并舍去小数部分（运算符会从左向右依次求值）。若要得到预期结果，需要写成

```
Test
{
    3.0/4*100
}
```

这样写是必要的。求值 `3.0` 时会将其解释为 double 类型，因此结果是实数 `75.0`。将实数转换为字符串时会保留小数点后 6 位，输出为 `75.000000`。若要转换为整数，请使用 [TOINT](../functions/TOINT.md) 函数。

要对变量进行此类运算，需要在声明时赋予实数，或者使用 [TOREAL](../functions/TOREAL.md) 函数。

```
Test
{
    _A = 3
    _B = 4
    TOREAL(_A)/_B*100
}
```

小数点始终使用 `.`，不受 OS 区域设置影响；从字符串转换为实数时，以及词典中书写的实数，也会使用 `.` 读取（即使是德语等以 `,` 作为小数点的区域设置，也同样如此）。

### 字符串

用双引号（`"`）括起来的值是字符串，会展开变量和函数（[展开字符串内嵌入元素](06-string-embedding.md)）。

在行末书写 `/`，即可书写包含换行的字符串。

```
"こん\n/
なかんじに\n/
書いてもＯＫ\n/"
```

也可以使用后文介绍的 Here Document 来书写包含换行的字符串。Sakura Script 必须作为字符串书写才能运行。

在 Tc569-8 之前的版本中，字符串内不能包含双引号。在 Tc569-8 及之后的版本中，连续书写两个双引号，即可在字符串内添加双引号。

```
"1""2"
```

这样书写时，定义的字符串是 `1"2`。

### 字符串（不展开）

用单引号（`'`）括起来的值是不会展开的普通字符串。YAYA 可以在字符串中嵌入变量和函数，但只有用双引号括起来的字符串才会展开这些内容。

在 Tc569-8 之前的版本中，字符串内不能包含单引号。在 Tc569-8 及之后的版本中，连续书写两个单引号，即可在字符串内添加单引号。

```
'1''2'
```

这样书写时，定义的字符串是 `1'2`。

虽然不推荐使用过于复杂的写法，以免之后难以阅读，但下面是同时使用两种引号的例子：

```
'1''2"3'
"1'2""3"
```

这两种写法定义的字符串都相当于 `1'2"3`。

### Here Document

可以书写多行的字符串即值。从 Tc535-1 起可以使用。

```
<<"
行1
行2
">>
```

这样会得到可展开字符串，

```
<<'
行1
行2
'>>
```

这样会得到不展开字符串。虽然可以在 Here Document 前后书写各种表达式，但此功能仅支持在词典文件中使用，即使通过 [EVAL](../functions/EVAL.md) 执行也会发生错误。

## 数组与哈希

除了即值之外，还可以使用**通用数组**（[数组](05-arrays.md)）这种用于集中处理多个值的类型。从 Tc600-3 起，也可以使用**哈希**（关联数组，[哈希](12-hash.md)）。

从 Tc600-3 起，也可以在数组或哈希的元素中放入数组或哈希（形成嵌套）（[值的嵌套与多维赋值](13-nesting.md)）。

## 变量

变量是用于存储值的区域。一个变量可以存储：

- 整数、实数、字符串
- 通用数组，其各元素可以存储上述任意一种类型
- 哈希（Tc600-3 及以上版本）

变量名可以自由指定，但不得违反以下限制：

- 以数字 0〜9 开头
- 包含以下字符：空格　`!`　`"`　`#`　`$`　`%`　`&`　`(`　`)`　`*`　`+`　`,`　`-`　`/`　`:`　`;`　`<`　`=`　`>`　`?`　`@`　`[`　`]`　`` ` ``　`{`　`|`　`}`　`~`
- 与保留字完全一致
- 与函数名完全一致

值的存储（赋值）通过赋值运算符 `=` 完成。要输出变量的内容，只需像函数一样写出变量名。

```
request
{
    str = "こんにちは"

    str
}
```

上面是一个简单的例子：将字符串存入变量 `str`，然后直接输出。

尚未赋值的变量会成为一种称为“未定义类型”的特殊类型。请注意，这并不表示“什么都不输出”。

```
request
{
    "Hello World"
    i
}
```

在这个例子中，由于 `i` 不存在，它会成为“未定义类型”。“未定义类型”在与数值进行运算时会被视为 0，在与字符串进行运算时会被视为 `''`（空字符串）。在上面的例子中，返回“未定义类型”或字符串 `"Hello World"` 的概率各为 1/2。

## 作用域与生命周期

变量根据作用域（有效范围）的不同分为两种。

- 全局变量：可在所有函数中共用的变量。生命周期为永久（除非通过 [ERASEVAR](../functions/ERASEVAR.md) 删除）
- 局部变量：只能在当前 `{ }` 内以及更深层的嵌套层级中使用的变量。生命周期持续到离开对应的 `{ }` 为止

通过变量名区分这两者：变量名以下划线（`_`）开头的变量会被视为局部变量。妥善利用局部变量这种“仅在必要范围内有效的变量”，可以让程序更易于理解。

```
request
{
    _i = "3*2は"

    _j = multi(3)

    _i + _j + "です"
}

multi
{
    _i = _argv[0]
    _i * 2
}
```

`request` 和 `multi` 使用了同名变量 `_i`，但它们会被视为完全不同的变量，不会相互破坏对方的值。用于处理函数参数的变量 `_argc` 和 `_argv` 实际上也是局部变量，因为它们会在各个函数中存储不同的值。

请注意，局部变量并非“可在当前函数内使用的变量”，而是“只能在当前 `{ }` 内以及更深层的嵌套层级中使用的变量”。

```
request
{
    {
        _str = "Hello World"
    }

    _str
}
```

这个程序不会按预期运行。`_str` 仅在 `{ }` 内有效，因此在尝试取出其内容的位置，它已经消失了。因此，这个函数 `request` 会输出空字符串。

全局变量和局部变量的另一个区别是生命周期。正如上面所述，局部变量离开使用它的 `{ }` 后就会消失。相比之下，全局变量可以在任何地方使用，而且其值会在 `unload` 时自动保存到文件，并在 `load` 时恢复。

要删除全局变量，必须使用 [ERASEVAR](../functions/ERASEVAR.md) 函数。此外，考虑到全局变量的这一性质，建议在启动时最先执行的函数（例如 `OnBoot`）中初始化全局变量。
