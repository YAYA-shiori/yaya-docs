# 流程控制

## 条件分支

### if / elseif / else 语法

如果表达式的结果为真，则处理后续 `{ }` 内的内容。条件表达式也可以用 `( )` 括起来。

```
request
{
    if !i {
        "iは0である。"
    }
}
```

可以紧接着添加 `elseif` 子句。只有在 `if` 的判断结果为假时，才会处理该子句。可以连接任意多个子句。此外，也可以在 `if`～`elseif` 的末尾添加 `else` 子句。只有在前面的 `if` 和 `elseif` 判断结果全部为假时，才会处理该子句。

```
request
{
    if !i {
        "iは0である。"
    }
    elseif i == 5 {
        "iは5である。"
    }
    elseif "A" _in_ TOUPPER(i) {
        "iは文字列で、aもしくはAを含んでいる。"
    }
    else {
        "iは0でも5でもaを含む文字列でもない何物かである。"
    }
}
```

如果 `if`、`elseif`、`else` 要处理的 `{ }` 内只有一个脚本，则可以省略 `{ }`。因此，上面的例子可以改写为：

```
request
{
    if !i
        "iは0である。"
    elseif i == 5
        "iは5である。"
    elseif "A" _in_ TOUPPER(i)
        "iは文字列で、aもしくはAを含んでいる。"
    else
        "iは0でも5でもaを含む文字列でもない何物かである。"
}
```

但是，如果 `if` 嵌套，则不能省略 `{ }`。下面的写法在 C 语言中正确，但在 YAYA 中错误（加载时会发生错误）。

```
if i == 0
    if j == 0
        "iとjはともに0である。"
```

此时必须使用 `{ }`，如下所示。

```
if i == 0 {
    if j == 0
        "iとjはともに0である。"
}
```

### case / when 语法

基于标签的分支。`case` 语句对表达式求值，并执行拥有匹配标签值的 `when` 子句。

```
request
{
    case i {
    when 0 {
        "iは0である。"
    }
    when "A"
        "iは文字列Aである。"
    others {
        "iは0でもAでもない。"
    }
    }
}
```

`others` 子句会在没有匹配任何标签时执行。`others` 可以省略；省略时不执行任何操作。

可以用逗号列举要匹配的标签值。此外，也可以用连字符指定匹配范围（例如：`"value1"-"value5"`）。

```
request
{
    case name+(i+1) {
    when "Pentium3","Pentium4"
        "Pen!!!は1999年、Pen4は2000年発売発売。"
    when "Pentium5"-"PentiumX" {
        "まだ無い。"
    }
    others
        "分からない。"
    }
}
```

`when` 中记述的标签值必须是字面值。不能写变量、函数或包含运算符的数学表达式。如果 `when`、`others` 要处理的 `{ }` 内只有一个脚本，则与 `if` 相同，可以省略 `{ }`。

一般形式如下。

```
case 式
{
  when 値1
  {
    // 値1の場合
  }
  when 値2, 値3
  {
    // 値2または値3の場合
  }
  others
  {
    // どれにもマッチしない場合
  }
}
```

`when` 和 `others` 必须写在 `case 式` 后面的 `{ }` 内。如果 `case 式` 后面没有 `{`，而是直接接着写 `when`，则加载时会发生错误（E0051 `case`之后缺少`{`）。也可以像 `case 式 {` 这样把 `{` 写在同一行。

### switch 语法

`{ }` 内的输出候选项会被随机选中；使用 `switch` 可以按位置指定要选择的候选项。

```
request
{
    switch id {
        "idは0である。"
        "idは1である。"
        {
            "idは2である。"
            "idはtwoである。"
        }
        "idは3である。"
    }
}
```

输出的字符串由变量 `id` 的值决定。位置从 0 开始计数。当 `id` 为 2 时，会输出 `"idは2である。"` 或 `"idはtwoである。"`。在这段嵌套的 `{ }` 中，候选项是随机选择的。

如果 `{ }` 内不存在与 `switch` 求值结果对应的候选项，则输出空字符串。例如，在上面的例子中，如果 `id` 为 100，则输出空字符串。

`{ }` 内的候选项每行写一个。`switch 1 { "a" "b" "c" }`（将每个候选项分行书写）会得到 `"b"`。

也可以按候选项的数量排列多个 `{ }`，并让每个代码块按位置对应。在这种情况下，会从与该位置对应的代码块中的候选项里随机选择。

```
switch _n
{
  "ゼロ番目"
}
{
  "一番目"
}
```

如果 `switch` 中有输出确定符（`--`），则会选择各代码块中对应位置的候选项。

```
request
{
    switch 1 {
        "かわいい"
        "天才"
        "サル"
        --
        "とは言い難い"
        --
        "ですね。"
        "かもしれません。"
    }
}
```

`request` 的输出会是 `"天才かもしれません。"`。请注意，中间的代码块在指定位置没有候选项，因此输出为空字符串（[函数](02-functions.md#出力確定子)）。

## 循环结构

共有 `while`、`for`、`foreach` 三种循环结构。

可以在[基础设置文件](01-basic-settings.md#looplimit-count)的 `looplimit` 中设置循环次数上限。如果上限不够，请修改设置。默认值为 1000000 次（Tc574-10 / Tc606-4 及之后的版本；此前为 10000 次）。达到上限时会调用 [shiori.OnLoopLimit](../system/shiori-OnLoopLimit.md)(函数名, 行)。

### while 循环

只要 `while` 求值的表达式为真，就会重复处理 `{ }` 内的内容。条件表达式可以用括号括起来，也可以不括起来（`while (_i < 3)` 和 `while _i < 3` 的行为相同）。

```
while 条件式
{
  // 処理
}
```

```
request
{
    _i = 1
    _j = 0
    while _i < 11 {
        _j += _i
        _i++
    }

    "1から10をすべて足すと%(_j)である。"
}
```

上面的例子简要说明了 `while` 的功能。下面的例子会生成 10 个不同的字符串。`request` 的输出会是报告 1～10 中某个数的平方根的字符串。

```
request
{
    _i = 1
    while _i < 11 {
        "%(_i)の平方根は%(SQRT(_i))である。"
        _i++
    }
}
```

### for 循环

`for` 与 `while` 一样，是先判定循环结构，但它的优点是可以将初始化表达式、退出判定表达式和每次循环执行的表达式集中写在一处。与 C 语言不同，所有部分都是必填的。不能使用 `for ( ; ; )` 这样的无限循环。

```
for 初期化 ; 条件 ; インクリメント
{
  // 処理
}
```

下面是将前文 `while` 示例中报告平方根的例子改写为 `for` 的版本。

```
request
{
    for _i = 1; _i < 11; _i++ {
        "%(_i)の平方根は%(SQRT(_i))である。"
    }
}
```

`_i = 1` 会在循环开始前执行。`_i < 11` 是循环判定表达式，只要它为真，循环就会继续。`_i++` 是每轮循环结束并返回循环开头时执行的表达式。

要创建无限循环，可以写成 `for 1;1;1` 等形式。不过，使用 `while 1` 就可以实现，因此创建无限循环时，无论从可读性还是运行速度来看，都应该使用 `while`。

从 Tc603-6 起，也可以用括号括起整个头部。`foreach` 也一样。

```
for (_i = 0; _i < 3; _i++) { ... }
foreach (_a; _k, _v) { ... }
```

- 头部可以拆分为多行。可以将 `(` 单独放在一行末尾，例如 `for (`，也可以让一行以 `)` 开头，例如 `) {`
- 按每个表达式分别加括号的写法（`for (_i = 0); (_i < 3); (_i++)`）以及不加括号的写法，仍然可以照常使用
- 像 `for (_i = 0; _i < 3); _i++` 这样在最后一个表达式之前闭合括号的写法，仍然会报错
- 如果存在去掉括号后会变为空的部分，例如 `for (; _i < 3; _i++)` 或 `foreach (_a; )`，则只会出现 E0027（不会出现后续的连锁错误）

在 Tc603-5 及更早版本中，包围整个头部的括号被拆分到了不同的表达式中，因此会出现 E0019 等错误。在此版本之前，用 `( )` 括起 `for` 和 `foreach` 的条件表达式会导致错误。

### foreach 循环

按顺序取出简易数组或通用数组中的各个元素值（也能识别通过 `SETDELIM` 设置的自定义分隔符）。

```
foreach 配列 ; 変数
{
  // 変数に要素が格納されて実行
}
```

下面的例子取出简易数组中的元素值，将其转换为数值，并计算总和。

```
request
{
    _str = "1,3,5,7,9"
    _t   = 0
    foreach _str; _i {
        _t += TOINT(_i)
    }
    _t
}
```

在 `foreach` 后面写出处理对象。上面的例子指定了简易数组 `_str`。接下来写出的 `_i` 是用于存储取出的元素值的变量，必须是变量。即使处理对象变量的分隔符通过 [SETDELIM](../functions/SETDELIM.md) 更改过，`foreach` 也能识别该分隔符并正常运行。

`foreach` 也可以处理通用数组。

```
request
{
    _sent = ("I", "am", 31, "years", "old.")
    _t   = ""
    foreach _sent; _i {
        _t += (_i + " ")
    }
    _t
}
```

`request` 会输出 `"I am 31 years old. "`。

在 `foreach` 循环内，可以改写作为元素取出对象的简易数组或通用数组。即使如此，遍历的仍是改写前的数据。

从 Tc600-3 起，也可以用 `foreach` 遍历哈希。变量会按键的顺序依次获得值。如果值是数组或哈希，变量也会是数组或哈希。

#### 双变量 foreach（Tc600-3 起）

用逗号分隔并写出两个变量时，第一个变量获得键，第二个变量获得值。数组和简易数组也可以使用这种写法，此时第一个变量获得从 0 开始的索引（整数）。

```
foreach 配列またはハッシュ ; キー変数, 値変数
{
  // 処理
}
```

```
_h = IHASH("a", 1, "b", 2)
foreach _h ; _k, _v { _s += _k + '=' + _v + ' ' }   // "a=1 b=2 "
foreach ("p", "q") ; _i, _v { ... }                  // _i = 0, 1
foreach "x,y" ; _i, _v { ... }                       // 簡易配列も同じ
```

变量可以是局部变量，也可以是全局变量。变量数量达到 3 个以上（`_a, _b, _c`），或写入的内容不是变量（`_k, 1`、`_a + _b`）时，会发生错误 E0043。

### break

循环中出现 `break` 时，会退出当前最内层的循环。

```
request
{
    _j = 0
    for _i = 0; _i < 100; _i++ {
        _j = _i*_i
        if  _j >= 100
            break
    }
    _i - 1
}
```

上面的例子中，`for` 会尝试循环，直到初始值为 0 的 `_i` 达到 100。但循环中设置了 `break`，使其在「`_i` 的平方达到 100 以上时退出循环」。因此，循环实际上会在 `_i` 为 10 时结束。`request` 会返回 `_i` 减 1 的值，因此这是一个求平方不超过 100 的最大整数（9）的函数。

### continue

循环中出现 `continue` 时，会立即从当前位置返回循环开头，进入下一轮循环。

```
request
{
    _j = ""
    for _i = 0; _i < 3; _i++
    {
        _j += "go "
        if  _i > 0
            continue
        _j += "ahead "
    }
    _j
}
```

`_i` 会依次变为 0、1、2，但在 1 和 2 时会执行 `continue`，因此不会执行向 `_j` 添加 `"ahead "` 的表达式。所以 `request` 的输出为 `"go ahead go go "`。

## 函数的返回值

### return

出现 `return` 时，该函数会在此处结束执行。函数的输出会从此前累积的候选值中选出。

```
to_rad
{
    if GETTYPE(_argv[0]) == 3 {
        -1
        return
    }
    _argv[0]*2.0*3.14/360.0
}
```

函数 `to_rad` 会将角度转换为弧度。如果传入的参数是字符串，程序会通过 `if` 判定发现这一点，并返回 -1。在执行 `return` 时，输出候选值只有 -1，因此会输出该值。

### 带参数的 return（Tc573-1 及以后）

可以使用 `return 表达式` 的形式显式指定返回值。参数不仅可以写常量，也可以写数学表达式。

```
to_rad
{
    if GETTYPE(_argv[0]) == 3 {
        return -1
    }
    return _argv[0]*2.0*3.14/360.0
}
```

带参数的 `return` 会**丢弃所有**此前累积的候选值，并将其替换为指定的值。在下面的示例中，返回值必定是 `"D"`，`"A"` `"B"` `"C"` 会被丢弃。

```
test_func
{
    "A"
    "B"
    "C"
    return "D"
}
```
