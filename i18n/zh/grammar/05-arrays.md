# 数组

## 概述

运算符 `[ ]` 用于访问数组元素。数组分为两种：将字符串拆分并视为数组的**简易数组**，以及处理以逗号分隔列举的元素的**通用数组**。

## 简易数组

将字符串中的逗号解释为分隔符，并像数组一样处理字符串的功能。

```
request
{
    _a = "this,is,a,pen"
    _a[1]
}
```

`request` 会输出 `"is"`。`[ ]` 运算符处理的对象不一定要是变量，也可以是立即值或函数返回值。上面的示例也可以写成下面这样，效果相同。

```
request
{
    "this,is,a,pen"[1]
}
```

### 自定义分隔符

在索引后面以逗号分隔指定分隔符，就可以使用其他字符串而非逗号来分隔简易数组的元素。

```
request
{
    "This is a island."[2,"is"]
}
```

由于使用 `"is"` 进行分隔，字符串会被拆分如下。

| 索引 | 元素 |
|------|------|
| `[0]` | `"Th"` |
| `[1]` | `" "` |
| `[2]` | `" a "` |
| `[3]` | `"land."` |

因此，`request` 会返回 `" a "`。

### 类多维数组访问

善用分隔符指定功能，就可以像访问多维数组一样取出值。

```
request
{
    _ar = "taro|male,ayame|female,hotaru|female"

    _ar[2][1,"|"]
}
```

`_ar[2]` 会得到 `"hotaru|female"`。再将 `|` 解释为分隔符并取出 `[1]`，结果就是 `"female"`。像这样，对每一层应用唯一的分隔符，就能轻松提取任意位置的值。

关于指定超出范围的索引时的输出，请参阅[超出范围的元素](#範囲外の要素)。

### 使用简易数组和通用数组实现多维数组

如果想更直接地处理多维数组，

```
Food = "うどん,ラーメン,おにぎり"
Color = "赤,青,黄"
```

可以先声明简易数组，然后使用通用数组

```
Word = (Food, Color)
```

这样，`Word[0][0]` 会得到「うどん」，`Word[1][2]` 会得到「黄」。

### 赋值

从这里开始介绍仅适用于变量的功能。可以为元素赋值。

```
request
{
    _a = "this,is,a,pen"
    _a[3] = "eraser"
    _a
}
```

这里将 `"pen"` 改写为 `"eraser"`，因此执行 `request` 的结果会是 `"this,is,a,eraser"`。指定分隔符时也可以正常工作。

```
request
{
    _s = "This is a island."
    _s[2,"is"] = " beautiful "
    _s
}
```

`request` 会输出 `"This is beautiful island."`。

当像类多维数组访问那样连续使用 `[ ]` 运算符时，赋值功能从 Tc600-3 起可用（[值的嵌套与多维赋值](13-nesting.md)）。在更早的版本中，只能为一维数组赋值，下面的操作会导致错误。

```
request
{
    _ar = "taro|male,ayame|female,hotaru|female"

    _ar[1][1,"|"] = "male"
}
```

也可以为超出当前元素数量的位置赋值。分隔符会自动添加，元素数量也会扩展。

```
request
{
    _m = "fuji/asama/tanigawa"
    _m[5,"/"] = "daisen"
    _m
}
```

`request` 会输出 `"fuji/asama/tanigawa///daisen"`。

### SETDELIM

使用 [SETDELIM](../functions/SETDELIM.md) 函数，可以将「默认分隔符」从逗号改为其他字符串。下面展示了使用 `SETDELIM` 改写前面示例的写法。

```
request
{
    _m = "fuji/asama/tanigawa"
    SETDELIM(_m, "/")
    _m[5] = "daisen"
    _m
}
```

使用 `SETDELIM` 后，就可以直接写成 `_m[5]`。像类多维数组访问那样连续使用 `[ ]` 运算符时，`SETDELIM` 只对第一个（第一维的）`[ ]` 有效。

## 通用数组

通用数组是一种可以混合存储各种类型值的数组结构。在一般访问场景下，它的运行速度比简易数组更快。

### 初始化

```
i = (100,"test",-1.5)
```

用逗号列举元素。赋值时，如上所示，必须将元素集合用 `( )` 括起来。由于逗号运算符的优先级低于赋值运算符，如果不加括号，

```
i = 100,"test",-1.5
```

会被解释为 `(i = 100),"test",-1.5`，因此 `i` 中只会存入 100。

要将数组初始化为空状态，请使用名为 [IARRAY](../functions/IARRAY.md) 的函数。`IARRAY` 是一个返回「空通用数组」的函数。

```
i = IARRAY
```

如果想在初始化时只赋一个元素，需要稍作处理。例如，直接写成 `i = 100` 的话，赋值的就只是一个数值，而不是数组。应如下所示。

```
i = (IARRAY,100)
```

### 添加元素

```
i = (i,"add")
```

这样会在数组末尾添加 `"add"`。也可以添加数组。

```
i = (i,("add",123,0.0))
```

就像可以将 `a = a + 1` 简写为 `a += 1` 一样，上面的示例也可以写成下面这样。

```
i ,= ("add",123,0.0)
```

也可以用相同的写法在开头插入元素。

```
i = ("first",i)
```

也可以在中间插入元素。

```
i = (100,200,300,400,500,600)
i[2] ,= "insertion"
```

此时 `i` 会变成 `(100,200,300,"insertion",400,500,600)`。请注意，插入位置是 `[3]`，而不是 `[2]`。如果要在 `i[2]` 处插入，请按下面的方式操作。

```
i[2] = ("insertion",i[2])
```

### 删除元素

将 `IARRAY` 赋给要删除的元素。

```
i = (100,200,300,400,500,600)
i[2] = IARRAY
```

300 会被删除，`i` 会变成 `(100,200,400,500,600)`。

### 更新值

可以直接为元素赋值。也可以为超出当前元素数量的位置赋值，元素数量会按需扩展。

### 取出值

与普通变量相同，指定序数后即可直接输出。关于指定超出范围的序数时的输出，请参阅[范围外的元素](#範囲外の要素)。

```
i = (100,200,300,400,500,600)
i[4]
```

会输出 500。`[ ]` 运算符处理的对象不必是变量，也可以是字面值或函数的返回值。

```
(100,200,300,400,500,600)[4]
```

会输出 500。也可以直接将通用数组作为函数的输出。

```
request
{
    river[2]
}

river
{
    ("tenryu","bandou-tarou","ishikari","shimanto")
}
```

`request` 会输出 `"ishikari"`。

### 数组中不能写数组

写在`( )`中的`( )`不会被识别为次级数组，而是会展开并直接连接起来。

```
(100,200,(300,400),500,600)
```

即使这样写，最终也会连接成如下形式。

```
(100,200,300,400,500,600)
```

需要将数组或哈希放入元素时，请参阅下面的“嵌套与多维赋值”。

### 运算

可以像通常那样对各个元素进行运算。

通用数组与单值之间进行运算时，会执行一种特殊的操作：“对所有元素分别应用该单值进行运算”。

```
pref = ("gunnma","ohsaka","hokkaido")
pref += "-ken"
```

`pref` 会变为 `"gunnma-ken","ohsaka-ken","hokkaido-ken"`。

```
answer = (2*(1,2,3))[1]
```

会将 4 赋给 `answer`。这是因为 `2*(1,2,3)` 的计算结果为 `(2,4,6)`。

通用数组之间进行运算时，会输出所有可进行运算的组合。

```
pref1 = ("gunma","osaka","hokkai")
pref2 = ("-ken","-fu","-do")
pref3 = pref1 + pref2
```

`pref3` 会变为 `"gunma-ken","gunma-fu","gunma-do","osaka-ken","osaka-fu","osaka-do","hokkai-ken","hokkai-fu","hokkai-do"`。如果数组中包含数值（整数、实数），减法、除法、乘法等其他运算也有效。

### 元素比较

用 `==` 比较数组时，会逐个比较元素。从 Tc600-3 开始，即使**两边都是 VOID**，也会被视为相等（在此之前结果为假）。

### 函数参数

在 YAYA 中，函数的参数是通用数组。`_argv` 的内容是将调用方传入的参数原样赋值后得到的通用数组。也就是说

```
func(1, 2, "test")
```

这样的函数调用，也可以写成

```
_i = (1,2,"test")
func(_i)
```

这种写法非常巧妙，但可以按预期运行。请注意，即使改写了脚本，参数的数量也不是 1 个，而是 3 个。

善用这种结构，就能轻松地将可变长度的参数传递给其他函数。

```
request
{
    total(1,2,3,4,5,6)
}

total
{
    calc_total(_argv)
}

calc_total
{
    _answer = 0
    foreach _argv; _val { _answer += _val }
    _answer
}
```

`total` 不做任何处理，而是将所有参数原样传递给 `calc_total`。这个例子中只是简单地传递了参数，当然也可以根据需要加工后再传递。

如果参数的指定方式比较复杂，请注意。

```
_i = (1,2,"test")
func("sky", _i, "sun")
```

上面的调用等价于以下写法。请记住，通用数组不能多维化（会被展开）。

```
func("sky", 1, 2, "test", "sun")
```

### 分隔符/获取数量指定

```
_i = (2,"is")
"This is a island."[_i]
```

简易数组中指定分隔符的部分也是通用数组，因此也可以像上面这样操作。这与下面的写法等价。

```
"This is a island."[2,"is"]
```

## 嵌套与多维赋值（Tc600-3 及以后）

可以在数组元素中放入哈希，也可以在哈希的值中放入数组。读取时写作 `_a[1]["x"]`，赋值时写作 `_a[1]["x"] = 5`，连续使用 `[ ]` 即可。

```
_a = (0, IHASH("x", 1), 2)
_a[1]["x"]        // 1
_a[1]["x"] = 5    // 多次元代入
```

多维赋值时，如果中间的元素是字符串，就会将其改写为简易数组：

```
_a = ("p,q", "r")
_a[0][1] = "Q"    // _a[0] は "p,Q"
```

但是，没有办法在通用数组中放入新的通用数组。`,` 运算符和 `_a[1] = (8,9)` 都会展开数组后插入。只有当赋值目标元素已经是数组或哈希时，才会不展开而整体替换（Tc603-1 及以后。[整体改写内部的数组或哈希](13-nesting.md#内側の配列やハッシュを丸ごと書き換える)）。

详情请参阅[值的嵌套与多维赋值](13-nesting.md)。

## 范围指定

简易数组和通用数组都可以通过范围指定序号。既可以获取，也可以赋值。范围使用通用数组指定。例如，`i[a,b]` 表示「`i` 的 a〜b 号元素」。

```
name = ("さくら","せりこ","奈留","まゆら","毒子","美耳")
i = name[1,3]
name[3,4] = "奎子"
j = name
name[0,2] = IARRAY
k = name
```

- `i` 中存储的是 `("せりこ","奈留","まゆら")`
- `j` 将变为 `("さくら","せりこ","奈留","奎子","美耳")`
- `k` 将变为 `("奎子","美耳")`

即使目标是简易数组，写法也相同。

```
name = "さくら,せりこ,奈留,まゆら,毒子,美耳"
i = name[1,3]
name[3,4] = "奎子"
j = name
```

`i` 将变为 `"せりこ,奈留,まゆら"`，`j` 将变为 `"さくら,せりこ,奈留,奎子,美耳"`。

也可以指定分隔符。请紧接在范围指定之后指定。

```
animal = "くま！うさぎ！ねこ！いぬ！わに"
i = animal[0,2,"！"]
animal[2,4,"！"] = "ぶた"
j = animal
```

`i` 将变为 `"くま！うさぎ！ねこ"`，`j` 将变为 `"くま！うさぎ！ぶた"`。

### 范围端点的处理

- 当 `a > b` 时（`i[3,1]`），会交换 a 和 b，因此范围与 `i[1,3]` 相同
- 超出末尾的一端按末尾处理。当 `n = (1,2,3,4)` 时，`n[2,9] = 9` 会使 `n` 变为 `(1,2,9)`
- 负序号按「超出末尾的大数值」处理。不会截断为 0，也不会作为超出范围而忽略。因此，`n[-2,1]` 的范围与 `n[1,末尾]` 相同

```
n = (1,2,3,4)
i = n[-2,1]
n[-2,1] *= 5
```

`i` 将变为 `(2,3,4)`，`n` 将变为 `(1,10,15,20)`。要从开头开始计数，请使用 `n[0,1]` 这样的写法，指定 0 以上的值。

## 越界元素

读取越界元素时，无论是简易数组还是通用数组，都会像未定义变量一样变成 **VOID**（Tc574-8 / Tc603-1 及以后版本）。范围指定读取越界时，会得到空范围（简易数组为空字符串，通用数组为空数组）。

```
_a = (1, 2)
_a[9]            // VOID
_a[9] == ""      // 1
_a[9] == 0       // 1
_a[9] + 1        // 1 （整数）
GETTYPE(_a[9])   // 0
_a[5, 6]         // 空の配列
"a,b"[5, 6]      // ""
```

- VOID 作为字符串时按空字符串处理，作为数值时按 0 处理。`== ""` 或 `if _a[9]` 的结果与值为空字符串时相同
- 即使在函数的最后一行等位置直接写入越界元素，也不会成为输出候选（与未定义变量相同；值为空字符串时，空字符串会成为候选）
- 给数值加上 `[ ]` 时（`5[1]`），会将其视为仅有一个元素的数组。第 0 个元素是该数值，其他位置都是 VOID
- 向末尾之后的元素赋值时（`_a[9] = 1`），中间部分会用 VOID 填充。填充个数上限为 16,777,216 个，超过上限的赋值（如 `_a[2000000000] = 1`）会作为内存不足处理，执行将因 E0100 中断，并调用 `shiori.OnMemoryError`（Tc603-4 及以后版本。此前没有上限，可能会耗尽内存）
- 对越界元素进行复合赋值（`_a[9] += 1`）时，也会将其作为 VOID 进行计算，因此结果为整数 1（600 系列从 Tc602-10 开始；500 系列从 Tc574-8 开始）
- 在 Tc574-7 / Tc602-13 之前，通用数组越界时会得到空字符串，简易数组越界时会得到 VOID，因此结果因数组类型而异。所以 `_a[9] == 0` 为假，`_a[9] + 1` 是字符串 `"1"`，`GETTYPE(_a[9])` 为 3。简易数组的范围指定读取越界时会得到 VOID，数值的范围指定读取越界时也会得到 VOID

## 并行输出

可以在所有表达式 / 值前面写 `parallel`。当输出候选值为通用数组时，`parallel` 会将其中的每个元素分别作为输出候选值。

```
foo0
{
    ("A","B","C")
    "地球"
}

foo1
{
    parallel ("A","B","C")
    "地球"
}
```

`foo0` 的输出可以是 `("A", "B", "C")` 或 `"地球"`。`foo1` 的输出则是 `"A"`、`"B"`、`"C"`、`"地球"` 中的任意一个。

对通用数组以外的值使用 `parallel` 没有意义，效果与不写相同。例如，以下两种写法等价。

```
parallel STRLEN("earth")
STRLEN("earth")
```

利用选择方式 `array` 和 `parallel`，可以将函数的输出候选值与通用数组相互转换。由此可以实现各种应用。例如，下面这个非常简洁的函数 `cyclic` 会按书写顺序从通用数组中取出元素值。

```
cyclic : sequential
{
    parallel _argv
}
```

反过来，在所有表达式 / 值前面写 `void`，也可以丢弃计算结果，使其不成为输出候选值。
